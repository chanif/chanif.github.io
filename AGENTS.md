# Aturan & Panduan Proyek (chanif.github.io)

## 1. Folder Legacy / Kompatibilitas Tautan Lama
Folder-folder berikut sengaja disediakan sebagai fallback / kompatibilitas mundur untuk mengantisipasi tautan lama yang pernah dibagikan ke publik, peserta workshop, atau siswa:
- `karya/`
- `mpi/`
- `learn/`
- `algo/`
- `intel_fti/`

### Panduan untuk Agent / AI Assistant:
- **Abaikan seluruh folder tersebut (`karya/`, `mpi/`, `learn/`, `algo/`, dan `intel_fti/`). Anggap tidak ada dalam cakupan pengembangan proyek ini.**
- **Jangan memodifikasi, me-refactor, atau menambahkan file baru** ke dalam folder-folder tersebut kecuali diminta secara eksplisit oleh pengguna.
- **Jangan menyertakan** folder-folder tersebut dalam perutean aktif, sitemap baru, atau audit struktur web.
- **Pengembangan Aktif:**
  - Materi pembelajaran, modul kurikulum, materi ajar, tutorial, dan workshop berpusat di folder **`edu/`**.
  - Eksperimen media interaktif, web game edukasi, simulasi, dan lab maya berpusat di folder **`lab/`**.
  - Beranda utama, profil, dan navigasi utama berada di root (**`/`**).
