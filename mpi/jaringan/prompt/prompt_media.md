# Prompt Media — Aset Visual MPI Jaringan Komputer

Kumpulan prompt siap-pakai untuk generate gambar/ilustrasi melalui AI image generator (Nano Banana, Midjourney, DALL-E, dsb.). Semua prompt menggunakan gaya **flat illustration / clean vector** dengan palet warna Informatika:

> Palet: `#00ACC1` (Teal), `#4DD0E1` (Cyan medium), `#E0F7FA` (Cyan muda), `#0288D1` (Biru), `#006064` (Teal gelap)

**Catatan:** Logo institusi (kemendikdasmen, sobat+bermutu+ramah, tutwuri, sobat SMP, pendidikan bermutu, ramah) **sudah tersedia** di folder `assets/` — JANGAN digenerate ulang.

## Catatan Umum

- Semua aset dengan ikon/elemen lepas harus memiliki **latar transparan** (PNG-24 atau SVG).
- Aset background (ruang kelas) harus memiliki **latar solid** (tidak transparan).
- Gunakan gaya yang **konsisten** di semua aset: flat illustration, clean vector, palet teal/cyan.
- Ukuran file disarankan dioptimasi (kompresi PNG atau format WebP) untuk performa offline.
- Setelah generate, letakkan semua file di folder `assets/` relatif terhadap `index.html`.
