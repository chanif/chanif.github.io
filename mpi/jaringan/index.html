Cara Menggunakan Media Pembelajaran Interaktif

Selamat datang di Media Pembelajaran Interaktif (MPI) Jaringan Komputer — Perjalanan Paket Data! Ikuti petunjuk berikut agar pengalaman belajarmu optimal:

  1. Tombol MENU (☰) — Tekan tombol ini di pojok kiri atas untuk kembali ke halaman Menu Utama kapan saja.
  2. Tombol BERANDA (🏠) — Tersedia di halaman Cover dan Kredit untuk kembali ke halaman awal.
  3. Tombol ◀ (Kembali) dan ▶ (Lanjut) — Gunakan tombol panah di pojok kiri bawah dan kanan bawah untuk berpindah antar halaman materi secara berurutan.
  4. Tombol MULAI (▶) — Tekan untuk memulai pembelajaran, permainan, atau latihan.

Fitur Interaktif Media

  • 📖 Materi — Pelajari konsep paket data, router, dan rute dinamis melalui penjelasan visual dua kolom.
  • 🔀 Tarik Jawaban — Seret istilah ke definisi yang tepat untuk menguji pemahamanmu (drag and drop).
  • 🎬 Video — Tonton video animasi tentang perjalanan paket data dalam jaringan.
  • 🎲 Permainan — Simulasikan pengiriman paket data: pilih router jalur alternatif yang aman ketika ada server down!
  • 📝 Latihan — Kerjakan soal evaluasi interaktif (Pilihan Ganda, Benar/Salah, Menjodohkan, Mengurutkan, & Praktik) dengan rekap skor 18 poin.
  • 📋 Rangkuman — Baca ringkasan materi, tulis refleksi pribadimu, dan dapatkan badge penghargaan!

💡 Tips: Pelajari seluruh materi terlebih dahulu sebelum mengerjakan permainan dan evaluasi latihan!

Tujuan Pembelajaran

Setelah mengikuti pembelajaran melalui Media Pembelajaran Interaktif ini, peserta didik diharapkan mampu:

  1. Menjelaskan konsep dasar jaringan komputer dan fungsinya dalam kehidupan sehari-hari.
  2. Mendeskripsikan proses pemecahan data menjadi paket-paket kecil untuk dikirimkan melalui jaringan.
  3. Menganalisis peran router sebagai pengarah lalu lintas data dalam jaringan.
  4. Mensimulasikan pengambilan keputusan rute alternatif ketika terjadi gangguan pada jaringan.
  5. Menyimpulkan keunggulan sistem pengiriman berbasis paket (packet switching) dibandingkan pengiriman file utuh.

Materi 1: Konsep Jaringan, Paket Data & Router

🌐 1. Apa Itu Jaringan Komputer?

Jaringan Komputer adalah sistem penghubung perangkat digital (HP, laptop, server) agar dapat saling berbagi koneksi internet, data, pesan, serta video.

📦 2. Mengapa Data Dipecah?

Saat kamu mengirim foto di chat, file tersebut TIDAK dikirim utuh, melainkan dipotong menjadi ribuan serpihan kecil bernama PAKET DATA.

💌 Anatomi Paket Data (Analogi Amplop Surat):

  • 🏷️ HEADER (Kepala Paket): Alamat IP Asal, IP Tujuan, dan Nomor Urut (mis. "Paket 1 dari 4").
  • 📄 PAYLOAD (Isi Paket): Potongan data asli (piksel foto/pesan).

💡 Fungsi Nomor Urut: Agar komputer penerima dapat merakit kembali seluruh potongan menjadi foto asli tanpa tertukar.

🚦 3. Router: Polisi Lalu Lintas Jaringan

Di internet terdapat jutaan persimpangan kabel dan nirkabel. Perangkat bernama ROUTER bertugas mengatur jalur setiap paket data.

🧭 MEMILIH RUTE TERBAIK: Router membaca alamat tujuan dan mencarikan rute tercepat yang tidak macet (mirip navigasi GPS / Google Maps).

🔀 RUTE DINAMIS: Jika salah satu jalur putus atau server bermasalah (Server Down / RTO), router otomatis mengalihkan paket ke jalur alternatif yang lancar.

✨ Prinsip Utama: Berkat paket data dan router, pengiriman data internet tidak akan berhenti total hanya karena satu jalur mengalami gangguan!

Materi 3: Keunggulan Packet Switching
🌐 Packet Switching

4 Tahapan Pengiriman Data & 3 Keunggulan Utamanya

Teknologi pengiriman data di seluruh dunia menggunakan metode Packet Switching dengan 4 tahapan berurutan:

1. Dipecah Menjadi Paket
2. Diberi Header & No. Urut
3. Dirutekan via Router
4. Dirakit Ulang di Tujuan

⚡ 1. Efisiensi Tinggi (Bisa Berbagi Jalur / Multi-User)

Jalur internet tidak dimonopoli satu orang. Ribuan siswa bisa mengirim foto bersamaan karena paket-paket kecil bisa menyelip bergantian di jalur yang sama.

🛡️ 2. Andal & Tahan Gangguan (Fault Tolerance)

Jika ada kabel putus di tengah jalan, hanya paket yang hilang yang perlu dikirim ulang, bukan seluruh file 5 MB dari awal!

🚀 3. Kecepatan Paralel Super Cepat

Paket data dapat dikirim secara bersamaan melalui berbagai rute berbeda, lalu langsung disusun kembali di komputer penerima dalam milidetik.

📝 Bagian A — Pilihan Ganda (5 Soal)
1. Apa fungsi utama jaringan komputer?
A Menyimpan data secara permanen
B Menghubungkan perangkat agar bisa saling bertukar data
C Mempercepat proses booting komputer
D Mengganti fungsi hard disk
2. Saat kamu mengirim foto lewat aplikasi chat, foto tersebut sebenarnya...
A Dikirim utuh dalam satu waktu
B Disimpan dulu di server sebelum dibuka penerima
C Dipecah menjadi paket-paket kecil lalu disusun kembali di penerima
D Diubah menjadi teks lalu dikembalikan jadi gambar
3. Bagian paket data yang berisi alamat pengirim, alamat tujuan, dan nomor urut disebut...
A Payload
B Header
C Router
D Bandwidth
4. Peran router dalam jaringan komputer paling tepat digambarkan sebagai...
A Tempat penyimpanan data sementara
B Perangkat yang mengarahkan paket data ke rute terbaik
C Aplikasi pengirim pesan
D Alat pengukur kecepatan internet
5. Berikut ini yang BUKAN keunggulan sistem packet switching dibanding pengiriman file utuh adalah...
A Lebih efisien karena jalur bisa dipakai bergantian oleh banyak pengguna
B Lebih tahan gangguan karena hanya paket yang terdampak yang perlu dialihkan
C Data pasti terkirim lebih cepat walau tanpa router
D Paket bisa dikirim lewat jalur berbeda secara paralel
✅❌ Bagian B — Benar / Salah (6 Soal)
1. Data yang dikirim melalui jaringan selalu dikirim dalam bentuk utuh tanpa dipecah.
2. Setiap paket data memiliki nomor urut agar bisa disusun kembali di penerima.
3. Router bertugas mengarahkan paket data ke rute tercepat yang tersedia.
4. Jika satu rute mengalami gangguan, seluruh proses pengiriman data akan berhenti total.
5. Payload adalah bagian paket data yang berisi alamat pengirim dan alamat tujuan.
6. Packet switching membuat jaringan lebih tahan terhadap gangguan dibanding mengirim file utuh.
🔗 Bagian C — Menjodohkan (5 Pasangan)

Klik istilah di sebelah kiri, lalu klik definisi yang tepat di sebelah kanan untuk menjodohkan.

📊 Bagian D — Mengurutkan Proses (6 Tahap)

Seret kotak-kotak tahapan berikut ke urutan proses transmisi data yang benar dari awal hingga akhir.

🎮 Bagian E — Simulasi Praktik Autentik

Pilih jalur transmisi yang aman untuk mengirim paket data! (Skor benar pada percobaan pertama = 1 poin)
