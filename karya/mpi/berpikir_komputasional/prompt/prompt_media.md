# Prompt Media — Aset Visual MPI Berpikir Komputasional (Rumah Cerdas / Smart Home IoT)

Kumpulan prompt siap-pakai untuk generate gambar/ilustrasi melalui AI image generator (Nano Banana, Midjourney, DALL-E, Imagen, Flux, dsb.). Semua prompt menggunakan gaya **flat illustration / clean modern vector** dengan palet warna Informatika:

> Palet: `#00ACC1` (Teal), `#4DD0E1` (Cyan medium), `#E0F7FA` (Cyan muda), `#0288D1` (Biru), `#006064` (Teal gelap), aksen `#FF9800` (Oranye)

**Catatan:** Logo institusi (kemendikdasmen, sobat+bermutu+ramah, tutwuri, sobat SMP, pendidikan bermutu, ramah) serta foto pengembang **sudah tersedia** di folder `assets/` — JANGAN digenerate ulang.
