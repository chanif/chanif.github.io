Materi 1: Anatomi Perangkat Keras Komputer

🖥️ 1. Apa Itu Sistem Komputer?

Sistem Komputer adalah kombinasi terpadu dari Perangkat Keras (Hardware), Perangkat Lunak (Software), dan Pengguna (Brainware) yang bekerja sama mengolah data menjadi informasi berharga.

🍳 2. Analogi Dapur Restoran

💡 Bagaimana Komputer Bekerja Mirip Dapur:

  • Masukan (Input): Pelayan mencatat pesanan pelanggan dari meja.
  • Pemroses (CPU): Koki meracik bumbu dan memasak bahan makanan.
  • Penyimpanan (Storage/RAM): Meja racik koki (RAM) dan lemari pendingin bahan baku (SSD/Harddisk).
  • Keluaran (Output): Piring hidangan lezat siap santap yang disajikan ke meja tamu!

✨ Satu Kesatuan: Jika salah satu bagian hilang, komputer tidak dapat beroperasi normal—sama seperti restoran tanpa koki atau tanpa pelayan!

📦 3. Empat Pilar Perangkat Keras

Setiap perangkat fisik komputer dikelompokkan ke dalam salah satu dari 4 pilar fungsi berikut:

⌨️ 1. PERANTI MASUKAN (INPUT):

Memasukkan data, teks, suara, atau perintah manusia ke komputer. Contoh: Keyboard, Mouse, Mikrofon, Scanner, dan Layar Sentuh.

🧠 2. PERANTI PEMROSES (CPU / PROCESSOR):

Otak pengolah yang mengeksekusi perhitungan logika dan instruksi program. Contoh: Processor (Intel/AMD/ARM) dan Motherboard.

💾 3. PERANTI PENYIMPANAN (STORAGE & MEMORY):

Menyimpan berkas data dan instruksi sistem, baik sementara maupun permanen. Contoh: RAM (memori kerja) serta SSD / Harddisk (penyimpanan arsip).

🖥️ 4. PERANTI KELUARAN (OUTPUT):

Menyajikan hasil pengolahan data agar dapat dipahami dan dinikmati manusia. Contoh: Layar Monitor, Speaker, dan Printer.

Materi 2: Otak Komputer & Alur Pemrosesan Data

🧠 1. CPU: Otak Sang Komputer

Central Processing Unit (CPU) mengeksekusi miliaran instruksi setiap detik. Tiga komponen inti di dalamnya:

🧮 ALU (Arithmetic Logic Unit):

Mesin hitung yang melakukan kalkulasi matematika (+, -, ×, ÷) dan perbandingan logika (AND, OR, NOT, >, <).

🚦 CU (Control Unit):

Dirigen pengatur lalu lintas data yang menjemput instruksi dan mengatur sinkronisasi kerja seluruh komponen.

⚡ Register:

Memori kerja internal berkecepatan ultra-tinggi tepat di dalam prosesor untuk menampung data yang sedang dihitung.

🔄 2. Siklus Mesin CPU (Machine Cycle)

Setiap instruksi program dijalankan melalui 4 tahap siklus berulang:

1. Fetch (Jemput): Control Unit mengambil kode instruksi dari memori RAM.

2. Decode (Terjemahkan): Control Unit menguraikan maksud perintah jadi sinyal kontrol.

3. Execute (Eksekusi): ALU menjalankan perhitungan aritmatika/logika instruksi.

4. Store (Simpan): Hasil operasi dituliskan kembali ke register atau RAM.

⚡ 3. Pertarungan: RAM vs SSD

Sering tertukar antara RAM dan Penyimpanan? Kenali perbedaannya:

⚡ RAM (Random Access Memory):

Volatile (Sementara). Tempat meletakkan aplikasi aktif. Bila komputer dimatikan, isi RAM terhapus bersih. Kecepatannya sangat tinggi!

💾 SSD / Harddisk (Penyimpanan Sekunder):

Non-Volatile (Permanen). Lemari arsip tempat sistem operasi, aplikasi, foto, dan berkas tugas tersimpan aman meski tanpa daya listrik.

📖 Analogi Belajar di Meja:
• RAM adalah permukaan mejamu—buku yang sedang terbuka dan dibaca.
• SSD adalah rak bukumu—semua koleksi buku tersimpan rapi di sana.

💡 Tahukah Kamu? — Kecepatan Gigahertz (GHz):
Processor berkecepatan 3.5 GHz mampu mengeksekusi hingga 3,5 miliar siklus perhitungan dalam kurun waktu satu detik saja!

Materi 3: Sistem Operasi & Kolaborasi Sistem

⚙️ 1. Apa Itu Sistem Operasi (OS)?

Jika perangkat keras adalah badan/raga, maka Sistem Operasi (Operating System) adalah jiwa/nyawa yang menggerakkannya. Tanpa OS, laptop tercanggih hanyalah tumpukan logam silikon yang tidak dapat menyala atau menerima perintah.

🎛️ 1. Manajer Sumber Daya Hardware:

Mengatur jatah waktu CPU, pembagian ruang memori RAM, dan akses baca/tulis ke media penyimpanan.

🖼️ 2. Antarmuka Grafis (GUI):

Menyediakan tampilan visual ikon, jendela (windows), dan kursor mouse sehingga komputer ramah digunakan manusia tanpa perlu mengetik baris kode perintah rumit.

📱 3. Contoh Sistem Operasi Terkenal:

Microsoft Windows, Linux (Ubuntu), macOS (untuk komputer/laptop), serta Android dan iOS (untuk ponsel pintar).

🔺 2. Segitiga Emas: Sinergi Sistem Komputer

Sistem komputasi tidak akan pernah berhasil jika salah satu dari 3 pilar ini tidak ada:

💻
1. Perangkat Keras (Hardware)

Penyedia tenaga fisik dan sirkuit listrik pengolah data.

💿
2. Perangkat Lunak (Software)

Sistem Operasi + Program Aplikasi yang memuat logika perintah.

🧑‍💻
3. Pengguna (Brainware)

Manusia berakal yang memberi tujuan instruksi dan memanfaatkan informasi.

🔌 Tahukah Kamu? — Peran Driver Perangkat:
Saat mencolokkan printer atau flashdisk baru, OS membutuhkan program kecil bernama Driver sebagai "penerjemah bahasa" antara sistem operasi dan peranti keras baru tersebut!

📝 Bagian A — Pilihan Ganda (5 Soal)
1. Perbedaan utama antara RAM dan SSD dalam arsitektur sistem komputer adalah...
A RAM bersifat permanen, sedangkan SSD bersifat sementara
B RAM bersifat sementara (volatil), sedangkan SSD bersifat permanen (non-volatil)
C RAM berukuran kapasitas lebih besar daripada penyimpanan SSD
D RAM hanya berfungsi untuk memproses perangkat masukan (input)
2. Komponen di dalam CPU yang bertugas melakukan operasi perhitungan matematika dan logika adalah...
A Control Unit (CU)
B Register Alamat
C Arithmetic Logic Unit (ALU)
D Power Supply Unit
3. Perangkat lunak yang bertindak sebagai jembatan utama pengelola sumber daya perangkat keras dan penghubung dengan program aplikasi adalah...
A Web Browser
B Sistem Operasi (Operating System)
C Aplikasi Pengolah Angka
D Antivirus
4. Manakah kelompok perangkat berikut yang semuanya tergolong sebagai Peranti Masukan (Input Device)?
A Monitor, Speaker, dan Printer
B Keyboard, Mouse, dan Scanner
C Processor, RAM, dan Motherboard
D Harddisk, Flashdisk, dan SSD
5. Urutan siklus mesin (Machine Cycle) CPU dalam mengeksekusi sebuah instruksi yang benar adalah...
A Execute ➔ Fetch ➔ Decode ➔ Store
B Decode ➔ Store ➔ Fetch ➔ Execute
C Fetch ➔ Decode ➔ Execute ➔ Store
D Store ➔ Decode ➔ Execute ➔ Fetch
✅❌ Bagian B — Benar / Salah (5 Soal)
1. Saat komputer dimatikan tiba-tiba, seluruh data dan instruksi yang berada di dalam RAM akan hilang (volatil).
2. Motherboard berfungsi untuk memproses semua komputasi logika secara mandiri tanpa memerlukan CPU.
3. Sistem Operasi (seperti Windows, Linux, atau Android) bertugas mengatur alokasi memori kerja dan waktu prosesor bagi aplikasi yang aktif.
4. Media penyimpanan sekunder SSD memiliki kecepatan transfer data yang lebih tinggi dibandingkan memori kerja RAM.
5. Control Unit (CU) bertugas menjemput instruksi dari RAM dan mengoordinasikan eksekusi data di CPU.
🔗 Bagian C — Menjodohkan (5 Pasangan)

Klik komponen/istilah di sebelah kiri, lalu klik fungsi yang tepat di sebelah kanan untuk menghubungkan garis. Klik kartu/tombol ✕ untuk membatalkan.

📊 Bagian D — Mengurutkan Proses Booting Komputer (5 Tahap)

Seret kotak tahapan berikut ke urutan proses booting komputer yang benar dari awal tombol power ditekan hingga OS siap digunakan.

Rangkuman
🖥️ 4 Pilar Komponen Sistem Komputer: Sistem komputer terdiri dari Perangkat Masukan (Input), Pemroses (CPU), Penyimpanan (Storage/RAM), dan Perangkat Keluaran (Output) yang bekerja saling terhubung.
⚙️ CPU dan Memori bekerja secara harmonis dalam siklus mesin (Fetch, Decode, Execute, Store). RAM menyediakan ruang kerja cepat sementara, dan SSD menyimpan data permanen.
🌐 Sistem Operasi sebagai Nyawa Komputer: Tanpa Sistem Operasi, komputer tidak dapat digunakan. OS menjembatani interaksi antara komponen fisik hardware, program aplikasi, dan pengguna (Brainware).
