Materi 1: Arsitektur & Perangkat Keras Komputer

🖥️ 1. Apa Itu Sistem Komputer?

Sistem Komputer adalah kombinasi terpadu dari Perangkat Keras (Hardware), Perangkat Lunak (Software), dan Pengguna (Brainware) yang bekerja sama mengolah data menjadi informasi berharga.

🏛️ 2. Arsitektur Von Neumann

Hampir seluruh komputer modern (dari laptop hingga smartphone) mengadopsi Model Von Neumann dengan 4 pilar utama:

💡 Analogi Koki Memasak: Bahan mentah masuk melalui Input, dimasak oleh koki di CPU menggunakan meja kerja RAM dan lemari bumbu Storage, lalu disajikan di piring Output!

📦 3. Empat Pilar Perangkat Keras

Berikut adalah 4 kelompok perangkat keras dalam sistem komputasi:

⌨️ 1. INPUT DEVICE (Masukan):

Memasukkan data dan instruksi manusia ke dalam komputer. Contoh: Keyboard, Mouse, Mikrofon, Scanner, dan Layar Sentuh.

🧠 2. PROCESSING DEVICE (Pemroses):

Otak komputer yang melakukan perhitungan logika dan matematika. Contoh: CPU (Processor), ALU, dan Motherboard.

🖥️ 3. OUTPUT DEVICE (Keluaran):

Menyajikan hasil pengolahan data agar dapat dipahami manusia. Contoh: Layar Monitor, Speaker, dan Printer.

🧠 1. CPU: Otak Sang Komputer

Central Processing Unit (CPU) mengeksekusi triliunan instruksi per detik. Di dalamnya terdapat dua unit inti:

• ALU (Arithmetic Logic Unit): Mesin hitung yang melakukan operasi matematika (+, -, x, /) dan logika (AND, OR, NOT).
• CU (Control Unit): Dirigen yang mengatur lalu lintas instruksi antar-komponen.

✨ Kecepatan Gigahertz (GHz): Processor 3.5 GHz mampu melakukan 3,5 miliar siklus instruksi dalam 1 detik!

⚡ 2. Pertarungan: RAM vs SSD / Harddisk

Jangan tertukar! Inilah perbedaan mendasar kedua jenis memori ini:

⚡ RAM (Random Access Memory):

Volatile (Sementara). Tempat menampung aplikasi yang sedang aktif dibuka. Saat komputer dimatikan, seluruh data di RAM hilang seketika. Kecepatannya luar biasa tinggi!

💾 SSD / Harddisk (Penyimpanan):

Non-Volatile (Permanen). Lemari berkas untuk menyimpan file tugas, foto, video, dan sistem operasi. Data tetap tersimpan aman walau listrik mati total.

⚙️ 1. Sistem Operasi (Operating System)

Perangkat keras tanpa software hanyalah tumpukan logam mati. Sistem Operasi (OS) adalah perangkat lunak fondasi yang mengelola perangkat keras dan menyediakan antarmuka bagi pengguna.

🪟 Contoh Sistem Operasi Populer:

• Windows & macOS: Standar di laptop dan komputer meja.
• Android & iOS: Standar sistem operasi pada smartphone dan tablet.
• Linux: Banyak digunakan untuk server internet dan keamanan data.

📱 2. Perangkat Lunak Aplikasi

Program yang dirancang spesifik untuk membantu manusia menyelesaikan pekerjaan tertentu:

🌐 Aplikasi Penjelajah Web (Browser):

Contoh: Chrome, Edge, Firefox untuk berselancar di internet.

📄 Aplikasi Pengolah Kata & Angka:

Contoh: Microsoft Word, Excel, Google Docs untuk mengerjakan tugas sekolah.

🎨 Aplikasi Kreatif & Hiburan:

Contoh: Canva, Photoshop, dan game edukasi interaktif.

Semua potongan piksel disatukan kembali secara presisi menjadi foto kucing yang utuh dan siap ditampilkan di layar!

🎬 Poin Penting Alur Kerja CPU:

📥 1. Fetch & Decode (Ambil & Terjemahkan)

Control Unit (CU) mengambil instruksi dari RAM lalu menguraikan jenis operasinya.

💾 3. Store (Simpan ke Memori)

Hasil perhitungan dituliskan kembali ke RAM atau dikirimkan ke perangkat keluaran (Monitor).

Materi 2: Bahasa Biner & Representasi Data

Transistor, Bit & Byte, serta Nilai Tempat Pangkat 2

Komputer menyimpan seluruh foto, lagu, dan teks menggunakan Bilangan Biner (0 dan 1):

1. Sinyal Listrik: ON/OFF
2. 1 Byte = 8 Bit
3. Bobot Nilai: 128 s.d 1
4. Kode Huruf & Warna

💡 1. Transistor Listrik (0 = Mati, 1 = Hidup)

Di dalam processor terdapat miliaran transistor sakelar listrik mini. Transistor yang mati bernilai 0, dan yang dialiri arus listrik bernilai 1.

🔢 2. Nilai Tempat 8-Bit (Kelipatan 2)

Setiap bit memiliki bobot dari kanan ke kiri: 1, 2, 4, 8, 16, 32, 64, 128. Contoh biner 00001010 = 8 + 2 = 10 desimal!

🎨 3. Mewakili Huruf & Warna Digital

Dalam standar kode ASCII, biner 01000001 mewakili huruf 'A'. Dan perpaduan 3 Byte biner menghasilkan jutaan spektrum warna RGB di layar monitor!

hanya paket yang hilang yang perlu dikirim ulang, bukan seluruh file 5 MB dari awal!

🚀 3. Kecepatan Paralel Super Cepat

Paket data dapat dikirim secara bersamaan melalui berbagai rute berbeda, lalu langsung disusun kembali di komputer penerima dalam milidetik.

📝 Bagian A — Pilihan Ganda (5 Soal)
1. Perbedaan utama antara RAM dan SSD dalam arsitektur sistem komputer adalah...
A RAM bersifat permanen, sedangkan SSD bersifat sementara
B RAM bersifat sementara (volatil), sedangkan SSD bersifat permanen (non-volatil)
C RAM berukuran kapasitas lebih besar daripada penyimpanan SSD
D RAM hanya berfungsi untuk memproses perangkat masukan (input)
2. Komponen di dalam CPU yang bertugas melakukan operasi perhitungan matematika dan logika adalah...
A Control Unit (CU)
B Register Alamat
C Arithmetic Logic Unit (ALU)
D Power Supply Unit
3. Dalam sistem biner, representasi bit '1' dan '0' pada komputer secara fisik diwujudkan melalui...
A Warna kabel dan jalur sirkuit pada motherboard
B Ada atau tidaknya aliran tegangan listrik pada sakelar mikroskopis transistor
C Kecepatan putaran bilah kipas pendingin CPU
D Ketukan mekanik pada papan ketik (keyboard)
4. Bilangan biner 8-bit 00001010 jika dikonversikan ke dalam bilangan desimal bernilai...
A 8
B 10 (karena 8 + 2 = 10)
C 12
D 16
5. Urutan siklus mesin (Machine Cycle) CPU dalam mengeksekusi sebuah instruksi yang benar adalah...
A Execute ➔ Fetch ➔ Decode ➔ Store
B Decode ➔ Store ➔ Fetch ➔ Execute
C Fetch ➔ Decode ➔ Execute ➔ Store
D Store ➔ Decode ➔ Execute ➔ Fetch
✅❌ Bagian B — Benar / Salah (5 Soal)
1. Saat komputer dimatikan tiba-tiba, seluruh data dan instruksi yang berada di dalam RAM akan hilang (volatil).
2. Motherboard berfungsi untuk memproses semua komputasi logika secara mandiri tanpa memerlukan CPU.
3. Satu Byte data digital terdiri dari kombinasi 8 digit biner (Bit).
4. Bilangan biner 00000100 jika dikonversi bernilai desimal 8.
5. Control Unit (CU) bertugas menjemput instruksi dari RAM dan mengoordinasikan eksekusi data di CPU.
🔗 Bagian C — Menjodohkan (5 Pasangan)

Klik komponen/istilah di sebelah kiri, lalu klik fungsi yang tepat di sebelah kanan untuk menghubungkan garis. Klik kartu/tombol ✕ untuk membatalkan.

📊 Bagian D — Mengurutkan Proses Booting Komputer (5 Tahap)

Seret kotak tahapan berikut ke urutan proses booting komputer yang benar dari awal tombol power ditekan hingga OS siap digunakan.

Rangkuman
🖥️ Arsitektur Von Neumann membagi komputer menjadi 3 pilar: Perangkat Masukan (Input), Unit Pemroses (CPU) & Memori Utama, serta Perangkat Keluaran (Output).
⚙️ CPU dan Memori bekerja secara harmonis dalam siklus mesin (Fetch, Decode, Execute, Store). RAM menyediakan ruang kerja cepat sementara, dan SSD menyimpan data permanen.
💡 Dunia Digital Berbasis Biner. Seluruh data kompleks (teks, audio, gambar resolusi tinggi) pada tingkat sirkuit terdalam tersusun dari kombinasi bit 0 dan 1 pada sakelar transistor.
💭 Refleksi: Tuliskan di buku catatanmu — Menurutmu, mengapa komputer modern membutuhkan memori bertingkat (Cache, RAM, dan SSD) alih-alih hanya menggunakan satu jenis media penyimpanan saja?
