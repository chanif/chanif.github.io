Hardware Virtual Sensor HC-SR04

Mengenal Sensor Ultrasonik HC-SR04

Komponen utama yang bertindak sebagai indera penglihatan robot.

📌 4 Pin Utama HC-SR04
1. VCC: Dihubungkan ke sumber daya 5V Arduino.
2. TRIG (Trigger): Pin pengirim sinyal suara (Transmitter).
3. ECHO: Pin penerima pantulan suara (Receiver).
4. GND (Ground): Dihubungkan ke GND Arduino.
Bentuk sensor menyerupai sepasang mata bulat (Transmitter & Receiver).
Fisika & Komputasi Prinsip Kerja

Bagaimana Sensor Mengukur Jarak?

Prinsip Pemantulan Gelombang Suara (Echo & Waktu Tempuh).

📡
HC-SR04
RINTANGAN
🔵 Gelombang Keluar (Trig) 🟠 Gelombang Pantul (Echo)
📐 Rumus Menghitung Jarak

Sensor mengukur waktu tempuh ($t$) gelombang suara bolak-balik dari sensor ke rintangan.

Jarak = (Waktu × Kecepatan Suara) / 2

Mengapa dibagi 2? Karena gelombang suara menempuh perjalanan pergi dan pulang!

Berpikir Komputasional Logika Pengambilan Keputusan

Otak Robot: Logika Kondisional (If-Else)

Bagaimana komputer membuat keputusan berdasarkan data sensor?

🧠 Konsep Dasar If-Else

Robot tidak bisa berpikir sendiri. Kita harus memberikan aturan keputusan yang jelas:

JIKA (Kondisi Terpenuhi)
→ Lakukan Aksi A
JIKA TIDAK (Kondisi Lain)
→ Lakukan Aksi B
🚗 Contoh Kasus Robot Kita

Kondisi batas jarak aman kita tentukan pada 15 cm:

🛑 JIKA Jarak < 15 cm:
Robot dalam bahaya! → Berhenti & Belok Kanan.
🟢 JIKA TIDAK (≥ 15 cm):
Jalan aman! → Maju Lurus Terus.

Platform Praktik Tinkercad Circuits

Mengenal Simulator Tinkercad

  4. Beri nama project: Robot_Penghindar_Kelompok_XX.

Pseudocode Logika Program

Pseudocode: Menulis Logika Robot

Sebelum mengetik kode asli, mari pahami alur dalam bahasa manusia.

📝 Pseudocode Bahasa Indonesia
// Inisialisasi pin SET trigPin = 9 SET echoPin = 8 SET jarakBatas = 15 cm // Alur Program Berulang (Loop) FUNGSI loop(): jarak = ukurJarakUltrasonik() JIKA (jarak < jarakBatas) MAKA: cetak("Awas Rintangan! Belok!") nyalakanLEDMerah() gerakkanMotorBelokKanan() JIKA TIDAK: cetak("Jalan Bebas! Maju!") matikanLEDMerah() gerakkanMotorMajuLurus()
💡 Poin Penting Pemrograman
  • Trigger Pulse: Arduino mengirim sinyal HIGH singkat (10 mikrodetik) ke pin TRIG.
  • Echo Reading: Menghitung durasi pin ECHO menerima pantulan dengan pulseIn().
  • Batas Jarak: Nilai 15 cm adalah threshold aman agar robot tidak menabrak.
Kode Arduino Implementasi C++

Struktur Kode di Editor Tinkercad

Potongan kode utama yang akan kita masukkan ke panel Code Tinkercad.

const int trigPin = 9; const int echoPin = 8; void setup() { pinMode(trigPin, OUTPUT); pinMode(echoPin, INPUT); Serial.begin(9600); } void loop() { // 1. Kirim gelombang ultrasonik digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); // 2. Hitung jarak (cm) long durasi = pulseIn(echoPin, HIGH); int jarak = durasi * 0.034 / 2; // 3. Logika Keputusan If-Else if (jarak < 15) { Serial.println("Rintangan Terdeteksi! Belok."); // Aksi manuver belok } else { Serial.println("Jalan Aman: Maju Lurus."); // Aksi maju } delay(100); }
🔍 Bagian Kunci Kode
Serial.begin(9600):
Mengaktifkan komunikasi data ke Serial Monitor untuk memantau angka jarak secara realtime.
durasi * 0.034 / 2:
Kecepatan suara di udara adalah 0.034 cm/mikrodetik.
if (jarak < 15):
Pengecekan logika kondisi apakah jarak objek lebih kecil dari batas toleransi tabrakan.

Checkpoint 1 / 9 Tahap Merakit

Checkpoint 1: Setup Kanvas & Komponen

Tarik komponen utama dari sidebar kanan Tinkercad ke area kerja.

📋 Instruksi Kerja
1
Tarik 1x Arduino Uno R3 ke tengah kanvas.
2
Tarik 1x Breadboard Mini di samping Arduino.
3
Cari "Ultrasonic Distance Sensor" yang memiliki 4 PIN. Pasang di breadboard.
⚠️ Peringatan Penting

Di Tinkercad terdapat 2 jenis sensor ultrasonik:

❌ 3 Pin (SIG): Bukan yang ini!
✅ 4 Pin (VCC, TRIG, ECHO, GND): Gunakan yang ini!

Pastikan pin sensor tertancap rapi pada lubang breadboard.

Checkpoint 2 / 9 Tahap Wiring

Checkpoint 2: Wiring Sensor ke Arduino

Hubungkan pin sensor ke Arduino dengan panduan tabel berikut.

🔌 Tabel Pin Connection
Pin Sensor Pin Arduino Warna Kabel
VCC 5V 🔴 Merah
TRIG Pin D9 🔵 Biru
ECHO Pin D8 🟡 Kuning
GND GND ⚫ Hitam
💡 Tips Kerapian Kabel
  • Klik pada jalur kabel untuk membuat belokan kabel yang rapi bersudut 90 derajat.
  • Pewarnaan kabel standar internasional mempermudah pencarian kesalahan (debugging).
Checkpoint 3 / 9 Tahap Aktuator

Checkpoint 3: Menambahkan Indikator / Motor

Pasang LED dan Motor DC untuk melihat aksi fisik saat rintangan terdeteksi.

💡 Memasang LED Bahaya
  1. Pasang 1x LED Merah di breadboard.
  2. Hubungkan kaki panjang (Anoda) ke Pin D13 Arduino melalui resistor 220 Ω.
  3. Hubungkan kaki pendek (Katoda) ke jalur GND.
⚙️ Memasang Motor Penggerak

Tarik DC Motor / Micro Servo:

  • Pin kontrol motor dihubungkan ke Pin D5 & D6 Arduino.
  • Motor akan berputar penuh saat jalan aman, dan berhenti/berbalik saat mendeteksi rintangan < 15 cm.
Checkpoint 4 / 9 Tahap Koding

Checkpoint 4: Input Kode Inisialisasi

Buka panel Code (ubah mode ke Text) dan ketik fungsi pembacaan.

📝 Langkah Buka Editor
  1. Klik tombol Code di kanan atas Tinkercad.
  2. Ubah dropdown dari Blocks menjadi Text.
  3. Klik Continue jika muncul kotak dialog konfirmasi.
  4. Hapus kode bawaan, lalu masukkan fungsi pembacaan pulsa.
// Fungsi mengukur jarak dalam cm int bacaJarakCM() { digitalWrite(trigPin, LOW); delayMicroseconds(2); digitalWrite(trigPin, HIGH); delayMicroseconds(10); digitalWrite(trigPin, LOW); long waktu = pulseIn(echoPin, HIGH); return waktu * 0.034 / 2; }
Checkpoint 5 / 9 Tahap Logika

Checkpoint 5: Menanamkan Logika If-Else

Lengkapi blok void loop() dengan kondisi ambang batas 15 cm.

void loop() { int jarak = bacaJarakCM(); Serial.print("Jarak objek: "); Serial.print(jarak); Serial.println(" cm"); // KONDISIONAL IF-ELSE if (jarak < 15) { // TERLALU DEKAT: Bahaya! digitalWrite(13, HIGH); // LED Nyala // Instruksi belok... } else { // AMAN: Maju terus digitalWrite(13, LOW); // LED Mati // Instruksi maju... } delay(100); }
🎯 Uji Pemikiran Siswa

Diskusikan dengan teman sekelompok:

"Apa yang terjadi jika angka 15 kita ubah menjadi 50? Apakah robot akan bereaksi lebih cepat atau lebih lambat?"
Checkpoint 6 / 9 Tahap Uji Coba

Checkpoint 6: Uji Coba Simulasi Virtual

Jalankan simulator dan geser bola target sensor ultrasonik.

▶️ Cara Menjalankan Uji Coba
  1. Klik tombol hijau Start Simulation di kanan atas.
  2. Buka Serial Monitor di bagian bawah panel Code.
  3. Klik pada komponen sensor ultrasonik di kanvas → akan muncul lingkaran hijau (objek rintangan).
  4. Geser lingkaran hijau mendekat (< 15 cm) dan menjauh (> 15 cm).
👀 Apa yang Harus Terjadi?
🟢 Saat Jarak > 15 cm:
LED padam, Serial Monitor menampilkan teks jarak aman, motor berputar maju.
🔴 Saat Jarak < 15 cm:
LED menyala terang, Serial Monitor memberikan peringatan bahaya, motor merespons manuver belok!
Checkpoint 7 / 9 Troubleshooting

Checkpoint 7: Mengatasi Masalah (Debugging)

Simulasi tidak berjalan sesuai rencana? Cek daftar kendala umum berikut.

❌ Masalah & Gejala
1. Jarak di Serial Monitor selalu 0 atau angka acak:
Kabel TRIG dan ECHO tertukar.
2. Muncul error saat Start Simulation:
Periksa tanda titik-koma (;) atau kurung kurawal ({}) di kode.
3. LED tidak mau menyala:
Kaki anoda/katoda terbalik atau kabel GND belum tersambung.
🔧 Solusi Cepat
  • Stop simulasi terlebih dahulu sebelum mengedit rangkaian atau kode.
  • Periksa kecocokan nomor pin di kode C++ dengan posisi kabel di papan Arduino.
  • Gunakan fitur zoom dan pan di Tinkercad untuk melihat sambungan pin dengan teliti.
Checkpoint 8 / 9 Uji Manuver

Checkpoint 8: Optimasi Respon Manuver
