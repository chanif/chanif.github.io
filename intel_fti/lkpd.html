Modul Starter Pack: Robot Penghindar Rintangan (Obstacle Avoiding Robot)
Tinkercad Circuits

🎯 1. Tujuan Pembelajaran

  1. Peserta didik mampu menjelaskan prinsip kerja sensor ultrasonik dalam mendeteksi jarak objek melalui pemantulan gelombang suara.
  2. Peserta didik mampu menyusun logika kondisional (If-Else) untuk mengendalikan arah dan manuver gerak robot.
  3. Peserta didik mampu merangkai dan mensimulasikan robot penghindar rintangan menggunakan simulator Tinkercad Circuits.

🛠️ 2. Alat & Bahan Praktik

📡 3. Kegiatan 1 — Mengenal Sensor Ultrasonik

Jawablah pertanyaan berikut berdasarkan materi paparan dan diskusi di kelas.

a. Pertanyaan Pemantik: Sebutkan 1 contoh alat di sekitarmu yang menggunakan prinsip sensor jarak!

b. Pemahaman Konsep: Jelaskan dengan kata-katamu sendiri bagaimana sensor ultrasonik (HC-SR04) mengukur jarak sebuah rintangan!

💻 5. Kegiatan 3 — Langkah Praktik di Tinkercad

Ikuti langkah-langkah praktikum virtual berikut secara berurutan bersama kelompokmu:

  1. Buka tinkercad.com → Masuk ke menu Designs → + Create → Circuit.
  2. Ambil 1 Arduino Uno R3, 1 Breadboard Mini, dan 1 Ultrasonic Distance Sensor (4 Pin).
  3. Hubungkan Pin VCC ke 5V, GND ke GND, TRIG ke Pin D9, dan ECHO ke Pin D8.
  4. Tambahkan 1 Motor DC / Micro Servo dan 1 LED Merah (Pin D13) sebagai indikator aksi robot.
  5. Buka panel Code (pilih mode Text), masukkan program pembacaan jarak dan logika kondisional if-else.
  6. Klik Start Simulation, buka Serial Monitor, lalu geser rintangan sensor untuk menguji respon robot.
