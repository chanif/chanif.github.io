# Personal Website & Learning Portal
## by Ach. Chanifuddin Fanani

Welcome to my repository. This is the source code for my personal website and portfolio, hosted at [fanani.my.id](https://fanani.my.id/).

## What is this?

This site has two main sections:
* **My Portfolio (Root)**: A showcase of my work as a full-stack developer since 2013, including projects in enterprise CRM, gamification platforms, messaging bots, and educational tools.
* **Learning Portal (`/learn`)**: A resource hub in Bahasa Indonesia ("Belajar Bareng Pak Fanani") built for my junior high students and primary school teachers. It contains materials for Informatics, Coding, and Artificial Intelligence (AI) classes.

## Project Directory

* `index.html`: The main portfolio landing page.
* `learn/`: The learning section for classes and teacher workshops.
  * `coding/`: Step-by-step tutorials for Scratch, Web Dev, Python, C++, App Inventor, and MySQL.
  * `informatika/`: Informatics curriculum resources.
  * `kka/`: Coding and AI (Kecerdasan Artifisial) curriculum resources.
  * `workshop/`: Lesson plans, templates, and reference materials from my teacher workshops.
* `assets/`: Images and gallery screenshots of my projects.

## Technology Stack

The site is built as a static webpage using HTML5, Tailwind CSS (via CDN), vanilla JavaScript, and local JSON files for interactive quizzes.
