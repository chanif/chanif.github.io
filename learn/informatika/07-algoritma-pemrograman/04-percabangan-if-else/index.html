3 Pola Percabangan dalam Python & Scratch

Bentuk struktur pengambilan keputusan dari sederhana hingga bertingkat

if kondisi:

1. Percabangan Tunggal (If)

Instruksi hanya dikerjakan jika syarat terpenuhi. Jika tidak terpenuhi, program langsung melompat ke baris berikutnya.

if - else:

2. Percabangan Ganda (If-Else)

Memberikan jalur alternatif pasti: Jika syarat True jalankan blok A, jika False jalankan blok B (Contoh: Lulus vs Remedial).

if - elif - else:

3. Multi-Kondisi (Elif)

Menguji opsi secara berurutan: jika kondisi 1 gagal, uji kondisi 2 (elif), dan seterusnya sampai blok else terakhir.

2

Operator Logika Majemuk (AND, OR, NOT)

Menggabungkan dua syarat atau lebih dalam satu pernyataan if

Operator AND (Dan)

Bernilai True HANYA JIKA semua syarat terpenuhi.
Contoh: if nilai >= 75 and kehadiran >= 80:

Operator OR (Atau)

Bernilai True jika salah satu syarat saja sudah terpenuhi.
Contoh: if punya_kartu_member or belanja > 500000:

Operator NOT (Bukan)

Membalikkan status logika: True menjadi False, dan False menjadi True.
Contoh: if not game_over:
