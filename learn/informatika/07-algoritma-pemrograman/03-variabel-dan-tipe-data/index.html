Variabel & Tipe Data: Wadah Penyimpan Memori Komputer

Bagaimana game mengingat skor skormu dan program menghitung total belanjamu? Kenali konsep Variabel sebagai wadah berlabel di RAM, 4 jenis tipe data dasar (Integer, Float, String, Boolean), dan operasi aritmatika-logika!

⏱️ Waktu: 45 Menit 🐍 Bahasa: Scratch & Python 3 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Konsep Dasar Variabel Memori

Memahami variabel sebagai kotak berlabel di RAM yang nilainya dapat diubah-ubah (reassignment) selama program berjalan.

02.
Membedakan 4 Tipe Data Utama

Mengidentifikasi tipe data Integer (bilangan bulat), Float (desimal), String (teks petik dua), dan Boolean (True/False).

03.
Operator Aritmatika, Relasional & Logika

Menggunakan operator matematika (+, -, *, /, %, **), perbandingan (==, !=, >=), dan logika (and, or, not).

04.
Input & Output Dinamis

Menerima masukan pengguna (input()) dan mengonversi tipe data (int(), str()) di Python serta blok Scratch.

1

Analogi Kotak Variabel dalam Memori

Memberi nama label unik untuk menyimpan data yang sewaktu-waktu bisa diperbarui

🏷️

1. Deklarasi & Nama Variabel

Nama variabel harus deskriptif dan tidak boleh diawali angka atau spasi. Contoh: skor_pemain = 100, nama_siswa = "Budi".

🔄

2. Pembaruan Nilai (Update)

Nilai lama akan ditimpa jika kita mengisi nilai baru: skor = skor + 10 (di Scratch: change skor by 10).

🧩

3. Dynamic Typing di Python

Python otomatis mengenali jenis data tanpa kita perlu mengetikkan tipe data secara manual.

2

4 Tipe Data Fundamental Pemrograman

Mengenali perbedaan format data angka, teks, dan status logika

🔢 Integer (int)

Bilangan bulat positif/negatif tanpa koma. Contoh: umur = 14, nyawa = 3, poin = -5.

📏 Float (float)

Bilangan desimal dengan tanda titik pecahan. Contoh: tinggi = 158.5, phi = 3.14.

🔤 String (str)

Teks karakter yang diapit tanda kutip. Contoh: pesan = "Selamat Pagi!", kelas = '8A'.

🔘 Boolean (bool)

Status kebenaran biner yang hanya bernilai True (Benar) atau False (Salah).
