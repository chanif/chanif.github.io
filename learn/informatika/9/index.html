HTML Materi 1

Membuat Website dengan HTML

Pelajari tag-tag HTML dasar: heading, paragraf, gambar, link, dan tabel. Bangun kerangka website pertamamu!
🎨
CSS Materi 2

Mempercantik Web dengan CSS

Beri warna, font, dan layout yang keren pada websitemu menggunakan CSS. Tampilan kamu, tampilanmu!

Desain Materi 3

UI/UX Dasar: Desain yang Nyaman

Apa yang bikin aplikasi enak dipakai? Belajar prinsip UI/UX dasar dengan Canva atau Figma online gratis.

Buat aplikasi Android sendiri menggunakan MIT App Inventor! Blok coding yang mudah, hasil nyata di HP.
