# Analisis Data

## Deskripsi
Modul yang mengajarkan siswa cara mengumpulkan, mengolah, menganalisis, dan menyajikan data untuk mengambil keputusan yang tepat. Siswa belajar bahwa data ada di mana-mana dan memiliki kekuatan besar jika diolah dengan benar.

## Capaian Pembelajaran (CP)
- Memahami konsep data, informasi, dan pengetahuan
- Merancang instrumen pengumpulan data sederhana
- Mengolah data menggunakan spreadsheet (fungsi, rumus, sorting, filtering)
- Membuat visualisasi data yang informatif (grafik, diagram, infografis)
- Menginterpretasi data dan menarik kesimpulan yang valid
- Melaksanakan proyek analisis data dari awal sampai akhir

## Daftar Sub-Materi

### 01. Pengantar Data
- **Tujuan Pembelajaran**: Siswa memahami apa itu data, perbedaannya dengan informasi, dan mengapa data penting.
- **Materi Pokok**:
  - Definisi data, informasi, dan pengetahuan (piramida DIKW)
  - Jenis data:
    - Kuantitatif (angka): diskrit vs kontinu
    - Kualitatif (kategori): nominal vs ordinal
  - Sumber data: primer (survei, eksperimen) vs sekunder (buku, internet)
  - Data terstruktur (tabel) vs tidak terstruktur (teks, gambar)
  - Big data: volume, velocity, variety
  - Data di kehidupan sehari-hari: nilai ujian, data cuaca, statistik YouTube
  - Pentingnya data: "Without data, you're just another person with an opinion"
- **Aktivitas**:
  - [ ] Unplugged: Kumpulkan data kelas (tinggi badan, hobi, warna favorit) — identifikasi jenis datanya
  - [ ] Plugged: Eksplorasi dataset publik (BPS, WHO) — apa yang bisa kita pelajari dari data ini?
- **Evaluasi / Quiz**:
  - [ ] Quiz: Klasifikasi jenis data (10 soal)
  - [ ] Essay: Berikan 5 contoh data yang kamu hasilkan setiap hari

### 02. Pengumpulan Data
- **Tujuan Pembelajaran**: Siswa mampu merancang dan melaksanakan pengumpulan data secara sistematis.
- **Materi Pokok**:
  - Metode pengumpulan data:
    - Survei/kuesioner: online (Google Forms) dan offline
    - Observasi: pengamatan langsung
    - Wawancara: terstruktur dan tidak terstruktur
    - Eksperimen: variabel kontrol dan uji
    - Data sekunder: web scraping sederhana, dataset publik
  - Merancang kuesioner yang baik:
    - Pertanyaan tertutup vs terbuka
    - Skala Likert (1-5)
    - Hindari bias pertanyaan
    - Urutan pertanyaan yang logis
  - Sampling: populasi vs sampel, ukuran sampel
  - Etika pengumpulan data: informed consent, privasi, anonimitas
- **Aktivitas**:
  - [ ] Plugged: Buat survei kelas menggunakan Google Forms (minimal 10 pertanyaan campuran)
  - [ ] Plugged: Kumpulkan data dari survei, download sebagai spreadsheet
  - [ ] Unplugged: Observasi dan catat data (misal: jumlah kendaraan lewat dalam 15 menit)
- **Evaluasi / Quiz**:
  - [ ] Quiz: Identifikasi metode pengumpulan data yang tepat untuk skenario tertentu (8 soal)
  - [ ] Praktik: Review dan perbaiki kuesioner yang bermasalah

### 03. Pengolahan Data dengan Spreadsheet
- **Tujuan Pembelajaran**: Siswa mampu mengolah data menggunakan spreadsheet secara efektif.
- **Materi Pokok**:
  - Pengenalan spreadsheet: cell, row, column, sheet, workbook
  - Input dan format data:
    - Tipe data: number, text, date, currency, percentage
    - Format angka dan mata uang
    - Freeze panes dan split view
  - Rumus dan fungsi dasar:
    - Aritmatika: +, -, *, /
    - SUM, AVERAGE, MIN, MAX, COUNT
    - COUNTIF, SUMIF, AVERAGEIF
    - IF (logika kondisional)
    - VLOOKUP (cari data di tabel lain)
    - CONCATENATE / & (gabung teks)
  - Sorting dan filtering data
  - Pivot table (dasar): merangkum data besar
  - Conditional formatting: warnai cell berdasarkan nilai
  - Data validation: membatasi input yang boleh dimasukkan
- **Aktivitas**:
  - [ ] Plugged: Olah data survei kelas — hitung rata-rata, modus, median
  - [ ] Plugged: Buat tabel nilai siswa dengan rumus otomatis (rata-rata, kelulusan)
  - [ ] Plugged: Gunakan COUNTIF untuk menganalisis jawaban survei
- **Evaluasi / Quiz**:
  - [ ] Quiz: Identifikasi rumus spreadsheet yang tepat (12 soal)
  - [ ] Praktik: Diberikan dataset mentah, olah dan analisis menggunakan rumus
- **Referensi & Link**:
  - Halaman interaktif: `03-pengolahan-spreadsheet/index.html` (sudah ada)

### 04. Visualisasi Data
- **Tujuan Pembelajaran**: Siswa mampu memilih dan membuat visualisasi data yang tepat dan informatif.
- **Materi Pokok**:
  - Mengapa visualisasi penting? "A picture is worth a thousand words"
  - Jenis grafik dan kapan menggunakannya:
    - Bar chart: membandingkan kategori
    - Line chart: menunjukkan tren waktu
    - Pie chart: menunjukkan komposisi/proporsi (max 5-6 kategori)
    - Scatter plot: menunjukkan korelasi 2 variabel
    - Histogram: distribusi data numerik
    - Area chart: volume data seiring waktu
  - Prinsip visualisasi yang baik:
    - Judul dan label yang jelas
    - Skala yang tepat (jangan manipulasi!)
    - Warna yang bermakna dan konsisten
    - Sumber data dicantumkan
    - Hindari chart junk (dekorasi berlebihan)
  - Visualisasi yang menyesatkan: contoh grafik yang manipulatif
  - Tools visualisasi: Google Sheets charts, Canva, Datawrapper
  - Infografis: menggabungkan data, teks, dan desain visual
- **Aktivitas**:
  - [ ] Plugged: Buat 3 jenis grafik berbeda dari data survei kelas
  - [ ] Plugged: "Spot the Lie" — identifikasi visualisasi data yang menyesatkan
  - [ ] Plugged: Buat infografis data kelas menggunakan Canva
- **Evaluasi / Quiz**:
  - [ ] Quiz: Pilih jenis grafik yang tepat untuk dataset tertentu (10 soal)
  - [ ] Quiz: Identifikasi kesalahan dalam visualisasi data
  - [ ] Proyek: Buat dashboard data kelas (3+ grafik)
- **Game Interaktif**:
  - [ ] Chart picker: Diberikan data, pilih grafik yang paling tepat

### 05. Interpretasi dan Kesimpulan
- **Tujuan Pembelajaran**: Siswa mampu membaca, menginterpretasi, dan menarik kesimpulan dari data dan visualisasi.
- **Materi Pokok**:
  - Membaca grafik: apa cerita yang disampaikan data?
  - Statistik deskriptif:
    - Rata-rata (mean), median, modus
    - Range, varians (konsep sederhana)
    - Frekuensi dan distribusi
  - Korelasi vs kausalitas: "correlation ≠ causation"
    - Contoh: penjualan es krim vs kasus tenggelam (keduanya naik di musim panas)
  - Menarik kesimpulan yang valid:
    - Berdasarkan bukti data, bukan opini
    - Mencatat keterbatasan data
    - Menghindari generalisasi berlebihan
  - Data storytelling: menceritakan insight dari data
  - Bias dalam data: selection bias, confirmation bias, survivorship bias
- **Aktivitas**:
  - [ ] Plugged: Diberikan dataset dan grafik — tuliskan 5 insight/temuan
  - [ ] Plugged: Analisis data statistik sekolah (kehadiran, nilai) — buat laporan singkat
  - [ ] Unplugged: Debat: "Korelasi atau Kausalitas?" — diberikan contoh, tentukan mana yang benar
- **Evaluasi / Quiz**:
  - [ ] Quiz: Interpretasi grafik dan data (10 soal)
  - [ ] Essay: Analisis dan interpretasi dataset yang diberikan

### 06. Proyek Analisis Data
- **Tujuan Pembelajaran**: Siswa melaksanakan proyek analisis data end-to-end.
- **Materi Pokok**:
  - Panduan proyek (tahapan lengkap):
    1. Tentukan pertanyaan penelitian
    2. Rancang metode pengumpulan data
    3. Kumpulkan data
    4. Bersihkan dan olah data
    5. Analisis dan visualisasikan
    6. Interpretasi dan tarik kesimpulan
    7. Presentasikan temuan
  - Contoh topik proyek:
    - "Apakah siswa yang tidur lebih awal mendapat nilai lebih tinggi?"
    - "Apa jajanan paling populer di kantin?"
    - "Bagaimana pola penggunaan HP siswa kelas 7-9?"
  - Rubrik penilaian proyek
- **Aktivitas**:
  - [ ] Proyek kelompok (3-4 siswa) selama 2-3 minggu
  - [ ] Milestone: proposal → pengumpulan data → analisis → presentasi
- **Evaluasi / Quiz**:
  - [ ] Penilaian proyek berdasarkan rubrik
  - [ ] Peer review antar kelompok
  - [ ] Refleksi individu: apa yang dipelajari dari proyek ini?
