Pengolahan Dokumen Digital & Otomasi Surat Massal

Menyusun dokumen bukan hanya sekadar mengetik teks! Pelajari cara menata margin baku, hierarki heading, penomoran romawi/angka otomatis, hingga mencetak ratusan surat undangan instan dengan Mail Merge.

⏱️ Waktu: 45 Menit 💌 Skill: Mail Merge & Layout Standar 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu peroleh setelah menyelesaikan modul ini

01.
Format Dokumen Akademik & Formal

Menguasai pengaturan batas tepi (margin), ukuran kertas (A4/Letter), spasi baris (1.5 line), dan indentasi paragraf.

02.
Heading Hirarki & Daftar Isi Otomatis

Menerapkan Heading 1, Heading 2, dan Navigation Pane untuk navigasi bab dan Daftar Isi otomatis.

03.
Integrasi Surat Massal (Mail Merge)

Menghubungkan template surat di Word dengan tabel data penerima di Excel secara presisi dan cepat.

04.
Manajemen File & Konversi PDF

Mengelola penamaan file terstruktur dan melakukan ekspor PDF tanpa merusak susunan tata letak.

1

Anatomi Dokumen Formal Berstandar

Standar baku penyusunan makalah, laporan karya tulis ilmiah, dan surat resmi

📐

Standar Margin 4-4-3-3

Standar penulisan karya tulis Indonesia: Margin Kiri 4 cm (ruang jilid), Atas 4 cm, Kanan 3 cm, dan Bawah 3 cm pada kertas ukuran A4.

📑

Section Break & Penomoran Halaman

Gunakan Section Break (Next Page) untuk membedakan nomor romawi bawah tengah (i, ii, iii) pada halaman pengantar dan angka arab kanan atas (1, 2, 3) pada bab inti.

🏷️

Tata Nama File (Naming Convention)

Hindari tugas_fix_bgt.docx! Gunakan format baku: [Kelas]_[MataPelajaran]_[Topik]_[Nama]_[Versi], contoh: 8A_Informatika_MakalahTIK_Ahmad_v1.docx.

2

Mail Merge: Menggabungkan Data & Surat

Mencetak 100 surat undangan atau sertifikat dalam sekali klik

📝 1. Main Document

Template surat di Word yang berisi teks utama dan placeholder kolom (misal: «Nama»).

📊 2. Data Source

Tabel data di Excel yang memuat daftar nama, alamat, nomor telepon, dan nilai siswa.

🔗 3. Insert Merge Field

Menyisipkan variabel kolom data ke posisi teks template yang sesuai.

🖨️ 4. Finish & Merge

Menghasilkan dokumen baru atau langsung mencetak semua halaman untuk setiap baris data.

💌

Live Mail Merge Interactive Previewer

Geser data penerima untuk melihat bagaimana Word mengganti placeholder secara otomatis

Evaluasi Formatif: Dokumen Digital & Mail Merge

Uji kemahiran formatting dan otomasi dokumen (Total Skor: 100)

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Mengapa batas tepi (margin) kiri pada karya tulis akademik umumnya diatur lebih lebar (4 cm) dibandingkan sisi kanan (3 cm)?

2. Dua file utama yang wajib dipersiapkan saat akan menjalankan fitur Mail Merge adalah...

3. Fitur di Microsoft Word yang mencatat setiap penambahan, penghapusan, atau pengeditan teks saat dokumen dikoreksi bersama guru disebut...

4. Untuk memisahkan format nomor halaman romawi (halaman pengantar) dengan nomor halaman angka arab (isi makalah), fitur yang harus digunakan adalah...

5. Format berkas yang paling aman digunakan saat mengirimkan CV atau tugas akhir agar font dan tata letak tidak berantakan saat dibuka di HP guru adalah...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Mail Merge memungkinkan kita mencetak 100 surat undangan berbeda tanpa perlu mengetik ulang isi surat 100 kali.
2. Daftar isi otomatis di Word dapat dibuat tanpa perlu menetapkan style Heading pada judul-judul bab.
3. Menekan tombol Enter berkali-kali untuk pindah ke halaman baru adalah praktik mengetik yang sangat rapi dan dianjurkan.
4. Penamaan file tugas sekolah yang baku memudahkan pencarian dan pengarsipan berkas di komputer guru.
5. Format file .PDF dapat dibuka dan dibaca di sistem operasi Windows, macOS, Android, maupun iOS.
Bagian C

Menjodohkan Fitur & Fungsinya (5 Pasangan · Bobot: 25 Poin)

Nama Fitur Pengolah Kata:

1. Heading 1 & Heading 2
2. Mailings $\rightarrow$ Insert Merge Field
3. Review $\rightarrow$ Track Changes
4. Layout $\rightarrow$ Section Break Next Page
5. File $\rightarrow$ Export As PDF

Bagian D

Urutan Prosedur Pembuatan Mail Merge (Bobot: 25 Poin)

Urutkan langkah pembuatan Mail Merge dari awal hingga cetak final:

A. Memilih menu Select Recipients $\rightarrow$ Use an Existing List dan pilih file Excel
B. Menyiapkan tabel data daftar penerima (Nama, Alamat) di Microsoft Excel
C. Mengetik template surat utama di Microsoft Word dengan menyisakan ruang placeholder
D. Klik Finish & Merge $\rightarrow$ Print Documents / Edit Individual Documents
E. Menyisipkan Insert Merge Field pada posisi nama/alamat dan mengecek dengan Preview Results

Rangkuman Materi & Refleksi Belajar

Tuliskan pemahaman dan pengalaman belajarmu pada materi ini

1. Kerapian Tata Letak: Margin 4-4-3-3 pada kertas A4, spasi 1.5, dan Section Break adalah kunci dokumen ilmiah berstandar resmi.

2. Otomasi Mail Merge: Menghubungkan satu template dokumen Word dengan ribuan baris data Excel menghasilkan efisiensi waktu yang luar biasa.

3. Standarisasi PDF: Selalu konversi hasil akhir dokumen ke format .PDF sebelum diserahkan untuk menjamin keaslian tata letak.
