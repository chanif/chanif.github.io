Perangkat Lunak Produktivitas: Senjata Utama Digital

TIK bukan sekadar menghidupkan komputer, tetapi bagaimana memilih dan menguasai *tools* yang tepat untuk mengolah kata, angka, presentasi, dan kolaborasi tim secara efektif!

⏱️ Waktu: 45 Menit 📂 Software Suite: Microsoft vs Google vs OpenSource 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah mempelajari modul ini

01.
Klasifikasi Perangkat Lunak

Membedakan peran Sistem Operasi, Perangkat Lunak Utilitas, dan Perangkat Lunak Aplikasi (Produktivitas).

02.
Perbandingan Ekosistem Office Suite

Membandingkan fitur, kelebihan, dan skenario penggunaan antara Microsoft Office, Google Workspace, dan LibreOffice.

03.
Pilar Aplikasi Produktivitas

Mengidentifikasi fungsi inti Pengolah Kata (Word/Docs), Spreadsheet (Excel/Sheets), dan Presentasi (PowerPoint/Slides).

04.
Pemilihan Tools yang Tepat

Mampu memilih perangkat lunak yang paling efisien untuk tugas akademik dan proyek kolaboratif.

1

Hierarki Perangkat Lunak Komputer

Tiga tingkatan software yang bekerja di dalam sistem komputermu

⚙️

1. Sistem Operasi (OS)

Pondasi utama yang mengelola perangkat keras (CPU, RAM, Storage) dan menjadi jembatan bagi aplikasi. Contoh: Windows 11, macOS, Linux Ubuntu, Android, iOS.

🛡️

2. Software Utilitas

Perangkat lunak pembantu untuk menjaga performa dan keamanan sistem. Contoh: Antivirus (Windows Defender), Pengompres file (WinRAR/7-Zip), Disk Defragmenter.

💼

3. Aplikasi Produktivitas

Program yang dibuat khusus untuk membantu manusia menyelesaikan pekerjaan nyata: mengetik makalah, mengolah anggaran, hingga mendesain slide presentasi.

2

Perbandingan 3 Ekosistem Office Populer

Mengenal keunggulan masing-masing platform office

Kategori Microsoft 365 Google Workspace LibreOffice (Open-Source)
Pengolah Kata Microsoft Word Google Docs LibreOffice Writer
Spreadsheet (Angka) Microsoft Excel Google Sheets LibreOffice Calc
Slide Presentasi Microsoft PowerPoint Google Slides LibreOffice Impress
Model Instalasi Desktop App + Web Browser Cloud Native (Web Browser) Desktop Offline Mandiri
Kekuatan Utama Fitur sangat kaya & format baku industri Kolaborasi real-time & auto-save instan 100% Gratis, bebas lisensi & hemat RAM

Evaluasi Formatif: Perangkat Lunak Produktivitas

Uji pemahaman software produktivitas dan tools digital (Total Skor: 100)

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Manakah di bawah ini yang termasuk ke dalam kategori Perangkat Lunak Aplikasi Produktivitas?

2. Fitur spreadsheet yang berfungsi untuk menampilkan hanya baris data yang memenuhi kriteria tertentu (misal nilai di atas 80) adalah...

3. Keunggulan utama dari Google Docs dibandingkan Microsoft Word versi offline tradisional adalah...

4. Format dokumen digital standar yang dirancang agar tampilan tata letak (layout) dan font tidak berubah saat dibuka di perangkat manapun adalah...

5. Paket office suite yang bersifat Open-Source dan dapat diunduh secara gratis legal tanpa biaya lisensi adalah...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Formula di Microsoft Excel dan Google Sheets selalu wajib diawali dengan tanda sama dengan (=).
2. Slide presentasi yang baik harus memuat seluruh paragraf buku pelajaran agar penonton membaca semuanya sendiri.
3. Fitur Heading (Heading 1, Heading 2) di pengolah kata berguna untuk membuat Daftar Isi (Table of Contents) secara otomatis.
4. Perangkat lunak utilitas seperti antivirus bertugas untuk mengolah tabel neraca keuangan perusahaan.
5. Google Workspace dapat dibuka langsung melalui web browser tanpa perlu menginstal aplikasi berat di hard disk.

Rangkuman Materi & Refleksi Belajar

Tuliskan pemahaman dan pengalaman belajarmu pada materi ini

1. Tiga Pilar Office: Pengolah Kata (narasi dokumen), Spreadsheet (kalkulasi angka & visualisasi grafik), dan Presentasi (komunikasi poin utama visual).

2. Ekosistem Fleksibel: Gunakan Google Workspace untuk kolaborasi tim real-time, MS Office untuk dokumen formal berstandar industri, dan LibreOffice untuk solusi hemat biaya dan open-source.

3. Efisiensi Kerja: Kuasai shortcut, template, dan otomatisasi (seperti Heading & Mail Merge) agar tugas selesai 10x lebih cepat.
