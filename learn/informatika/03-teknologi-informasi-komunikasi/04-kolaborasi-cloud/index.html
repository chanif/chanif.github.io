Kolaborasi Cloud: Bekerja Bersama Tanpa Batas Ruang

Zaman kirim-kiriman file via flashdisk sudah berlalu! Kuasai teknologi *Cloud Computing* untuk mengerjakan dokumen bersama teman secara real-time, mengamankan hak akses, dan memulihkan riwayat editan (version history).

⏱️ Waktu: 45 Menit ☁️ Ekosistem: Google Drive & Workspace 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Memahami Konsep Cloud Computing

Menjelaskan analogi komputasi awan, keuntungan penyimpanan data terpusat, dan sinkronisasi lintas gawai (HP, laptop, tablet).

02.
Manajemen Hak Akses Dokumen

Membedakan peran Viewer (Hanya Lihat), Commenter (Pemberi Komentar), dan Editor (Pengedit Penuh) saat berbagi tautan.

03.
Pemanfaatan Version History

Melihat siapa yang mengubah teks tertentu dan mengembalikan (restore) versi dokumen jika terjadi kesalahan pengetikan kelompok.

04.
Keamanan Akun & Cloud Storage

Menerapkan Autentikasi Dua Faktor (2FA), mengenali bahaya tautan publik sembarangan, dan etika privasi data.

1

Apa Itu Cloud Computing?

Menyimpan data dan menjalankan aplikasi di server internet raksasa

⚡

Analogi Listrik PLN

Dulu setiap rumah harus punya generator sendiri (HDD lokal). Sekarang kita tinggal colok ke PLN (Cloud Server) dan menikmati daya komputasi kapan pun dibutuhkan.

🔄

Sinkronisasi Instan

Ketik makalah di laptop sekolah, lanjut mengedit lewat aplikasi HP saat di perjalanan pulang, dan kirim ke guru via komputer rumah tanpa salin flashdisk.

👥

Kolaborasi Real-Time

5 siswa dapat mengetik di 1 file Google Docs yang sama secara serentak. Kursor masing-masing siswa muncul dengan warna-warni berbeda secara langsung!

2

Tiga Tingkatan Hak Akses File Cloud

Kunci keamanan saat membagikan link dokumen Google Drive

👀 Level 1
Viewer (Pelihat)

Penerima hanya bisa membaca dan mencetak dokumen. Tidak bisa mengedit isi teks atau menambahkan komentar apapun.

💬 Level 2
Commenter (Pemberi Komentar)

Bisa membaca dan menyisipkan catatan revisi (suggesting mode). Teks asli tidak berubah sebelum disetujui pemilik file.

✏️ Level 3
Editor (Pengedit Penuh)

Bisa mengedit teks, menghapus paragraf, membagikan link ke orang lain, dan menyisipkan gambar baru secara bebas.

Evaluasi Formatif: Kolaborasi Cloud

Uji pemahaman komputasi awan dan keamanan data (Total Skor: 100)

Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Fitur di Google Docs yang memungkinkan pemilik dokumen melihat siapa saja yang melakukan pengeditan dan mengembalikan dokumen ke versi kemarin sore adalah...

2. Jika kamu membagikan link formulir pendaftaran OSIS ke seluruh siswa sekolah, hak akses link yang tepat agar siswa lain tidak bisa mengacak-acak soal adalah...

3. Layanan penyimpanan awan (Cloud Storage) milik Microsoft yang terintegrasi langsung dengan Windows 11 adalah...

4. Langkah paling efektif untuk mengamankan akun Google/Cloud dari pembajakan adalah...

5. Keuntungan utama dari penggunaan Google Forms untuk survei tugas sekolah adalah...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Jika laptopmu rusak/hilang, seluruh dokumen yang sudah tersinkron ke Google Drive tetap aman dan bisa dibuka di perangkat lain.
2. Memberikan hak akses "Editor" kepada publik umum di internet sangat aman dan tidak berisiko dokumen dihapus orang tak dikenal.
3. Fitur Commenter memungkinkan guru memberi catatan revisi tanpa merusak teks asli yang ditulis oleh siswa.
4. Google Workspace for Education hanya bisa digunakan saat semua siswa berada di dalam satu ruangan kelas yang sama.
5. Melakukan backup file secara berkala ke cloud storage adalah langkah tepat untuk mencegah kehilangan data akibat serangan virus.

Rangkuman Materi & Refleksi Belajar

Tuliskan pemahaman dan pengalaman belajarmu pada materi ini

1. Kerja Tim Real-Time: Cloud computing menghilangkan hambatan jarak dan waktu dalam mengerjakan proyek sekolah.

2. Keamanan Akses: Selalu periksa kembali apakah link yang kamu bagikan berstatus Viewer, Commenter, atau Editor agar data tetap aman.

3. Riwayat Aman: Fitur Version History adalah penyelamat saat terjadi kesalahan ketik atau penghapusan materi oleh anggota tim.
