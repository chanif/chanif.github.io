Analogi Cetak Biru (Class) & Bangunan Nyata (Object)

Memahami konsep dasar bagaimana objek diciptakan di dalam memori program

📐

1. Class (Cetak Biru / Blueprint)

Kerangka acuan atau cetakan pabrik yang mendefinisikan atribut apa saja yang dimiliki serta aksi (method) apa yang bisa dilakukan.
Contoh: class Mobil: memiliki atribut warna, kecepatan, dan method maju(), rem().

🚗

2. Object / Instance (Benda Nyata)

Hasil cetakan konkret nyata yang menempati ruang memori RAM, dengan nilai atribut yang spesifik dan unik.
Contoh: mobil_andi = Mobil("Merah", 120) dan mobil_budi = Mobil("Hitam", 180).

2

4 Pilar Utama Object-Oriented Programming

Prinsip arsitektur perangkat lunak skala enterprise

🔒 1. Encapsulation

Membungkus data dan menyembunyikan variabel internal agar tidak dimodifikasi langsung dari luar.

🧬 2. Inheritance

Mewariskan properti dan method dari class induk (Parent) ke class turunan (Child).

🎭 3. Polymorphism

Satu nama method yang dapat memiliki perilaku berbeda pada class turunan yang berbeda.

💡 4. Abstraction

Menyembunyikan detail kerumitan internal dan hanya menampilkan fungsi penting kepada pengguna.
