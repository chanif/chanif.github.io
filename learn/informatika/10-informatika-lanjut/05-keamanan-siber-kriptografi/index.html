1

3 Pilar Keamanan Informasi: CIA Triad

Standar baku emas pertahanan siber di seluruh dunia

🤫

1. Confidentiality (Kerahasiaan)

Menjamin data hanya boleh dibaca dan diakses oleh pihak yang berwenang (contoh: pesan chat dienkripsi end-to-end).

🛡️

2. Integrity (Integritas / Keutuhan)

Menjamin data tidak diubah, dimanipulasi, atau disisipi virus oleh hacker saat transit dalam jaringan (contoh: checksum SHA-256).

⚡

3. Availability (Ketersediaan)

Menjamin sistem dan server web tetap aktif dapat diakses kapan saja tanpa tumbang akibat serangan DDoS.

2

Perbandingan Enkripsi Simetris vs Asimetris vs Hashing

Teknologi matematika penjaga keamanan data digital

🔑 Simetris (AES)

Pengirim dan penerima menggunakan 1 kunci rahasia yang sama untuk mengunci dan membuka pesan. Sangat cepat untuk file besar.

🗝️🔒 Asimetris (RSA)

Menggunakan 2 kunci berpasangan: Public Key disebar untuk mengunci, Private Key disimpan rahasia untuk membuka pesan. Digunakan di SSL/TLS.

🥩➡️🌭 Hashing (SHA-256)

Fungsi satu arah matematis (One-Way Function). Menghasilkan sidik jari teks unik yang mustahil dikembalikan ke teks aslinya.

Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Tiga pilar utama dalam keamanan informasi yang dikenal sebagai CIA Triad adalah singkatan dari...

2. Pada sandi Caesar Cipher dengan pergeseran kunci (shift) = 3, huruf 'A' akan dienkripsi menjadi huruf...

3. Jenis kriptografi yang menggunakan dua kunci berbeda (Public Key untuk mengunci dan Private Key untuk membuka) disebut...

4. Alasan utama mengapa database sistem login tidak pernah menyimpan kata sandi asli secara langsung (plain text) melainkan dalam bentuk Hash (seperti SHA-256) adalah...

5. Kompetisi di mana para pakar keamanan siber berlatih memecahkan teka-teki enkripsi dan menambal celah keamanan sistem dikenal dengan nama...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Teks pesan rahasia hasil proses enkripsi disebut sebagai Plaintext.
2. Enkripsi Simetris AES jauh lebih cepat daripada enkripsi Asimetris RSA dalam mengenkripsi volume data berkas yang besar.
3. Sertifikat digital SSL/TLS pada protokol HTTPS digunakan untuk memvalidasi bahwa situs web yang kita buka adalah situs web asli terpercaya.
4. Menambahkan 1 huruf saja pada teks input SHA-256 akan menghasilkan nilai hash keluaran yang berubah secara total drastis (Avalanche Effect).
5. Kunci Private Key pada sistem RSA boleh dibagikan secara bebas ke seluruh publik di internet.
