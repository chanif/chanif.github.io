Basis Data Relasional (RDBMS) & Bahasa SQL

Di balik setiap aplikasi populer (seperti Instagram, YouTube, dan Tokopedia), ada basis data raksasa yang bekerja cepat dan terstruktur. Pelajari konsep tabel, relasi Primary/Foreign Key, dan perintah SQL: SELECT, INSERT, UPDATE, DELETE, hingga agregasi data!

⏱️ Waktu: 45 Menit 🗄️ Standar: SQL (Structured Query Language) 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Anatomi Basis Data Relasional

Struktur penyimpanan data terorganisir yang menjamin integritas informasi

📋

1. Tabel & Baris (Records)

Setiap baris mewakili satu entitas unik (contoh: 1 data siswa lengkap), sedangkan kolom mendefinisikan jenis properti data (Nama, NISN, Kelas).

🔑

2. Primary Key (PK)

Kolom khusus bernilai unik (tidak boleh duplikat dan tidak boleh kosong) yang menjadi tanda pengenal mutlak (contoh: NISN atau User ID).

🔗

3. Foreign Key (FK)

Kolom pada satu tabel yang merujuk ke Primary Key di tabel lain untuk membentuk hubungan relasi (contoh: tabel Nilai merujuk NISN siswa).

2

4 Perintah Inti SQL (CRUD)

Bahasa universal standar internasional untuk mengelola basis data

SELECT

SELECT nama, nilai FROM siswa WHERE nilai >= 80;
Mengambil dan menampilkan data.

INSERT

INSERT INTO siswa (nama, kelas) VALUES ('Ahmad', '8A');
Menambahkan baris baru.

UPDATE

UPDATE siswa SET nilai = 95 WHERE id = 1;
Mengubah data yang sudah ada.

DELETE

DELETE FROM siswa WHERE id = 1;
Menghapus baris dari tabel.

Evaluasi Formatif: Basis Data & SQL

Uji kemampuan merancang tabel dan mengeksekusi query SQL (Total Skor: 100)

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Perintah SQL yang digunakan untuk mengambil data dari satu atau beberapa tabel basis data adalah...

2. Kolom khusus pada tabel yang nilainya wajib unik dan tidak boleh kosong untuk membedakan tiap baris data dinamakan...

3. Klausa SQL yang digunakan untuk menyaring baris berdasarkan kriteria tertentu (misal: mencari siswa yang nilainya di atas 85) adalah...

4. Fungsi agregasi SQL untuk menghitung jumlah total baris record data dalam sebuah tabel adalah...

5. Perintah INNER JOIN dalam query SQL berfungsi untuk...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Menjalankan perintah DELETE FROM siswa; tanpa klausa WHERE akan menghapus seluruh data siswa di dalam tabel tersebut.
2. SQLite adalah basis data ringan tanpa server (serverless) yang menyimpan seluruh database ke dalam satu file tunggal di disk.
3. Klausa ORDER BY nilai DESC akan mengurutkan data nilai siswa dari yang terkecil ke yang terbesar.
4. Perintah CREATE TABLE termasuk ke dalam kelompok Data Definition Language (DDL).
5. Dua orang siswa boleh memiliki nomor NISN Primary Key yang sama persis di dalam satu tabel sekolah.
Bagian C

Menjodohkan Kata Kunci SQL & Fungsinya (5 Pasangan · Bobot: 25 Poin)

Bagian D

Urutan Sintaks Klausa Query SELECT SQL Lengkap (Bobot: 25 Poin)

Urutkan susunan klausa query SQL standar dari awal hingga akhir:

A. SELECT nama, nilai (Menentukan kolom yang dipilih)
B. FROM siswa (Menentukan nama tabel sumber)
C. WHERE nilai >= 75 (Menyaring baris dengan syarat kondisi)
D. ORDER BY nilai DESC (Mengurutkan data dari nilai tertinggi)
E. LIMIT 5; (Membatasi hanya 5 baris data teratas yang tampil)

Rangkuman Materi & Refleksi Belajar

Tuliskan pemahaman dan pengalaman belajarmu pada materi ini

1. Jantung Aplikasi: Data aplikasi tidak akan hilang saat komputer dimatikan berkat basis data relasional RDBMS yang aman.

3. Keamanan Data: Hati-hati saat mengeksekusi perintah UPDATE dan DELETE agar tidak mengubah atau menghapus data yang salah.
