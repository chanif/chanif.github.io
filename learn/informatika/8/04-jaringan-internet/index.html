Jaringan Komputer & Internet 🌐

Bagaimana data bisa sampai dari HP-mu ke seluruh dunia dalam hitungan detik? Kenali cara internet bekerja lewat analogi yang mudah dipahami!

Internet Itu Apa Sih?

Internet adalah jaringan komputer terbesar di dunia — menghubungkan miliaran perangkat dari HP, laptop, server, hingga kulkas pintar. Data bergerak melalui kabel bawah laut, gelombang radio WiFi, dan sinyal 4G/5G.

🌊 Fakta Keren!

Lebih dari 95% data internet dunia berjalan melalui kabel optik bawah laut! Kabel-kabel ini membentang di dasar samudra menghubungkan benua-benua. Total panjangnya bisa mengelilingi bumi lebih dari 30 kali!

Alamat IP — Alamat Rumahmu di Internet

Setiap perangkat yang terhubung ke internet punya IP Address (Internet Protocol Address) — seperti alamat rumah agar data bisa dikirim ke tujuan yang tepat.

IPv4 (versi lama)

192.168.1.1

Format: 4 angka (0-255) dipisah titik. Total bisa ~4 miliar alamat — sekarang sudah hampir habis!

IPv6 (versi baru)

2001:0db8:85a3::8a2e

Format lebih panjang dengan huruf dan angka. Bisa menampung 340 triliun triliun triliun alamat!

DNS — Penerjemah Nama Website

Saat kamu ketik google.com, komputermu tidak langsung tahu ke server mana harus pergi. DNS (Domain Name System) bertugas menerjemahkan nama domain menjadi IP address.

🗺️ Perjalanan Data Saat Buka Website

1 ⌨️ Kamu ketik "google.com" di browser
2 🔍 Komputer tanya ke DNS: "Berapa IP address google.com?"
3 📋 DNS jawab: "IP-nya 142.250.X.X"
4 📤 Browser kirim permintaan ke server Google di IP tersebut
5 📥 Server Google kirim balik halaman web
6 🖥️ Browser tampilkan halaman di layarmu!

Jenis-Jenis Jaringan

🏠

LAN

Local Area Network

WiFi di rumah atau sekolah. Jangkauan pendek, kecepatan tinggi.

🏙️

MAN

Metropolitan Area Network

Jaringan antar gedung pemerintah dalam satu kota.

🌍

WAN

Wide Area Network

Internet itu sendiri! Menghubungkan seluruh dunia.

HTTP vs HTTPS — Aman atau Tidak?

Saat membuka website, perhatikan awalan URL-nya:

🔓 HTTP

Data dikirim tanpa enkripsi. Orang lain di jaringan yang sama bisa "mengintip" data yang kamu kirim. Jangan isi password atau data penting!

🔒 HTTPS

Data dikirim dengan enkripsi SSL/TLS. Meskipun diintersepsi, data tidak bisa dibaca. Aman untuk transaksi dan login!

✅ Kebiasaan Aman di Internet

  • Selalu cek ada gembok 🔒 di browser sebelum isi data penting
  • Hindari WiFi publik tanpa password untuk transaksi online
  • Jangan klik link dari sumber yang tidak dikenal
  • Gunakan password yang berbeda untuk setiap akun

Ringkasan 📝

  • Internet = jaringan komputer terbesar yang menghubungkan seluruh dunia
  • IP Address = alamat unik setiap perangkat di internet
  • DNS menerjemahkan nama domain (google.com) menjadi IP address
  • HTTPS lebih aman dari HTTP karena menggunakan enkripsi
