Sistem Operasi: Konduktor Orkestra Komputer

Tanpa Sistem Operasi (OS), perangkat keras canggih seperti prosesor dan memori hanyalah tumpukan logam mati! Pelajari cara OS mengelola ribuan proses di Task Manager, mengatur sistem berkas, dan menjembatani perintah pengguna.

⏱️ Waktu: 45 Menit ⚙️ OS: Windows, Linux, macOS, Android 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah mempelajari modul ini

01.
Klasifikasi Perangkat Lunak

Membedakan System Software (OS & Driver), Application Software, dan Programming Software (IDE & Compiler).

02.
5 Tugas Pokok Sistem Operasi

Menjelaskan manajemen proses (multitasking), alokasi memori RAM, manajemen berkas (NTFS/FAT32), driver perangkat, dan antarmuka (GUI/CLI).

03.
Perbandingan Sistem Operasi

Membandingkan kelebihan Windows, macOS, Linux (distro Ubuntu/Mint), Android, dan ChromeOS.

04.
Lisensi & Open Source

Memahami filosofi kode sumber terbuka (Open Source vs Proprietary) dan jenis lisensi perangkat lunak.

1

Klasifikasi Perangkat Lunak

Tiga pilar utama pembangun ekosistem digital

⚙️

1. System Software

Pengelola perangkat keras langsung. Terdiri dari Sistem Operasi (Windows/Linux), Device Driver (driver VGA/printer), dan Utilitas (antivirus, disk defrag).

📱

2. Application Software

Aplikasi pengguna akhir untuk tugas produktif atau hiburan: browser Chrome, pemutar media VLC, game Roblox, dan office suite.

💻

3. Programming Software

Perangkat bagi programmer untuk menulis kode: Text Editor (VS Code), Compiler (C++/GCC), dan Interpreter (Python Engine).

2

5 Tugas Inti Sistem Operasi

Bagaimana OS mengendalikan seluruh aktivitas komputermu di balik layar

⚡ 1. Proses

Menjadwalkan eksekusi instruksi CPU (multitasking) ribuan aplikasi secara bergantian sangat cepat.

🧠 2. Memori

Mengalokasikan ruang RAM sementara untuk aplikasi dan mencegah aplikasi saling menimpa data.

📁 3. Berkas (File)

Mengatur struktur folder dan penyimpanan fisik hard disk via sistem berkas (NTFS, ext4, FAT32).

🔌 4. Driver (I/O)

Menerjemahkan bahasa perangkat keras luar (printer, webcam, keyboard) agar dipahami OS.

🖥️ 5. Antarmuka

Menyediakan tampilan visual (GUI) atau baris perintah teks (CLI) untuk memudahkan manusia memberi instruksi.

Evaluasi Formatif: Perangkat Lunak & OS

Uji pemahaman sistem operasi dan manajemen sumber daya komputer (Total Skor: 100)

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Komponen perangkat lunak sistem yang berfungsi sebagai penerjemah instruksi antara sistem operasi dengan perangkat keras luar (seperti printer baru) adalah...

2. Sistem operasi yang bersifat Open-Source dan bebas dimodifikasi kodenya oleh siapa saja di seluruh dunia adalah...

3. Fitur di sistem operasi Windows yang digunakan untuk memantau performa CPU, konsumsi RAM, dan menutup paksa aplikasi yang mengalami Not Responding adalah...

4. Perbedaan utama antara antarmuka GUI (Graphical User Interface) dan CLI (Command Line Interface) adalah...

5. Sistem berkas (File System) standar yang digunakan pada hard disk sistem operasi Windows modern adalah...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Sistem Operasi bertindak sebagai jembatan perantara antara perangkat keras komputer dan aplikasi pengguna.
2. Android adalah sistem operasi perangkat seluler yang dibangun di atas fondasi kernel Linux.
3. Perangkat lunak Open-Source melarang siapa pun untuk melihat atau mempelajari kode sumber programnya.
4. Multitasking adalah kemampuan sistem operasi untuk menjalankan beberapa program secara bersamaan.
5. Jika kapasitas RAM penuh, komputer akan terasa lambat karena OS harus memindahkan data sementara ke virtual memory (paging file).
Bagian C

Menjodohkan Sistem Operasi & Ekosistemnya (5 Pasangan · Bobot: 25 Poin)

Bagian D

Urutan Proses Booting Komputer (Bobot: 25 Poin)

Urutkan proses sejak tombol Power ditekan hingga desktop OS siap dipakai:

A. Pengguna menekan tombol Power pada casing komputer
B. BIOS / UEFI melakukan tes hardware POST (Power-On Self-Test)
C. Bootloader membaca dan memuat Kernel Sistem Operasi dari SSD/HDD ke RAM
D. Sistem Operasi memuat driver perangkat dan layanan latar belakang
E. Tampilan antarmuka Login / Desktop muncul dan siap menerima perintah pengguna

Rangkuman Materi & Refleksi Belajar

Tuliskan pemahaman dan pengalaman belajarmu pada materi ini

1. Pengendali Sumber Daya: OS memastikan CPU, RAM, dan disk storage bekerja seimbang dan tidak terjadi tabrakan antar aplikasi.

2. Beragam Pilihan OS: Windows unggul dalam fleksibilitas & gaming, macOS dalam produktivitas kreatif, dan Linux dalam keandalan server serta kebebasan Open Source.

3. Monitor Kesehatan Sistem: Manfaatkan Task Manager secara bijak untuk mengetahui penyebab komputer lemot atau aplikasi macet.
