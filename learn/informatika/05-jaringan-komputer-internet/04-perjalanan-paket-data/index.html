Konsep Mendalam: Arsitektur Paket Data

Pelajari 4 pilar transmisi data digital modern

✂️

1. Mengapa Data Dipecah?

Packet Switching vs Circuit Switching

Bayangkan kamu ingin mengirim lemari pakaian besar. Jika dikirim utuh, kamu membutuhkan truk raksasa dan jalan tol yang harus dikosongkan. Jika ada 1 batu menghalangi, seluruh pengiriman macet total.

Dalam Packet Switching, lemari dibongkar menjadi papan-papan kayu terpisah (paket), masing-masing diberi nomor urut dan alamat tujuan, lalu dikirim lewat kurir motor berbeda. Di rumah tujuan, lemari dirakit kembali dengan sempurna!

💡 Keuntungan: Jalur kabel internet bisa dipakai bersama jutaan orang sekaligus tanpa saling mengunci!
🏷️

2. Anatomi Amplop Paket Data

Struktur Header & Payload

Setiap paket data terdiri dari 2 bagian utama:

1. Header (Label Amplop):
  • IP Pengirim (Source IP): Alamat asal perangkatmu.
  • IP Tujuan (Destination IP): Alamat server tujuan.
  • Sequence Number: Nomor urut paket (cth: Paket #3 dari 10).
  • TTL (Time To Live): Batas umur maksimal paket di jaringan.
2. Payload (Isi Surat): Potongan data aktual (~1.460 byte).
🧭

3. Peran Router di Internet

Polisi Lalu Lintas Jaringan Global

Internet bukanlah satu garis lurus, melainkan jaring laba-laba raksasa yang menghubungkan miliaran komputer. Router adalah komputer khusus yang membaca alamat IP tujuan pada setiap paket data dan mencarikan rute kabel terpendek serta tercepat (Hop-by-Hop).

🌐 Dinamis: Jika kabel bawah laut antara Singapura - Jakarta putus, router otomatis mengalihkan paket melalui jalur satelit atau rute alternatif!
🤝

4. Protokol TCP vs UDP

Keandalan vs Kecepatan Real-time

TCP (Reliable):

Memastikan paket tidak ada yang hilang. Jika hilang, dikirim ulang otomatis.
Cth: Web HTTPS, Email, Download.

UDP (Fast Streaming):

Mengirim cepat tanpa menunggu konfirmasi.
Cth: Video Call, Game Multiplayer, Live Stream.

Latihan Evaluasi Menyeluruh (18 Poin)

Uji penguasaan konsep jaringan dan transmisi paket melalui 4 bagian evaluasi

Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Mengapa data di internet dipecah menjadi potongan-potongan kecil (paket data)?

2. Perangkat keras jaringan yang bertugas membaca alamat IP tujuan dan memilih rute tercepat untuk paket data adalah...

3. Protokol transmisi yang menjamin tidak ada data yang hilang dengan mengirim ulang paket yang gagal sampai adalah...

4. Informasi pada header paket data yang digunakan oleh komputer penerima untuk menyusun kembali potongan file sesuai urutan aslinya adalah...

5. Fitur enkripsi pada protokol HTTPS berfungsi untuk...

Bagian B

Benar / Salah (5 Soal · Bobot: 25 Poin)

1. Data yang dikirim melalui jaringan selalu dikirim dalam bentuk utuh tanpa dipecah.

2. Setiap paket data memiliki nomor urut agar bisa disusun kembali di komputer penerima.

3. Router bertugas mengarahkan paket data ke rute tercepat yang tersedia.

4. Jika satu rute mengalami gangguan, seluruh proses pengiriman data akan berhenti total.

5. Packet switching membuat jaringan lebih tahan terhadap gangguan dibanding mengirim file utuh.

Bagian C

Menjodohkan (5 Pasangan · Bobot: 25 Poin)

Rangkuman Materi & Refleksi

Poin kunci transmisi jaringan dan catatan refleksimu

📦 Packet Switching: Data dipecah menjadi unit paket kecil agar pengiriman efisien, cepat, dan tidak memonopoli jalur kabel jaringan bersama.
🧭 Router Hop: Router bertindak sebagai penentu arah terbaik yang selalu mencari jalur alternatif jika salah satu rute utama mengalami gangguan.
🤝 Protokol TCP vs UDP: TCP menjamin keutuhan data dengan konfirmasi (3-way handshake), sedangkan UDP mengutamakan kecepatan untuk streaming.
🔒 Enkripsi HTTPS: Mengamankan isi payload paket data dengan kriptografi SSL/TLS sehingga tidak dapat disadap saat melintasi router publik.
