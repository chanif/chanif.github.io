📱 App Inventor · Tutorial 1

Mengenal MIT App Inventor

App Inventor adalah platform dari MIT (Massachusetts Institute of Technology) untuk membuat aplikasi Android dengan cara menyusun blok visual — mirip Scratch, tapi hasilnya bisa diinstall di HP kamu!

1. Apa Itu App Inventor?

✅ Bisa Dilakukan

  • • Bikin app Android (.apk)
  • • Desain UI drag-and-drop
  • • Logika pakai blok visual
  • • Uji coba langsung di HP
  • • Gratis & berbasis browser

ℹ️ Perlu Diketahui

  • • Khusus Android (bukan iOS)
  • • Butuh akun Google
  • • Untuk preview butuh HP Android atau emulator
  • • Cocok untuk app sederhana–menengah
🔗 Buka App Inventor: appinventor.mit.edu → klik "Create Apps!" → login dengan Google

2. Mengenal Antarmuka App Inventor

App Inventor punya dua mode utama yang bisa kamu switch kapan saja:

🎨

Designer Mode

Tempat kamu mendesain tampilan app. Drag komponen dari panel kiri ke layar ponsel di tengah. Atur propertinya di panel kanan.

  • 📦 Palette — daftar komponen tersedia
  • 📱 Viewer — preview layar HP
  • 🔧 Properties — atur warna, ukuran, teks
  • 📋 Components — daftar komponen yang sudah ditambah
🧩

Blocks Mode

Tempat kamu menulis logika/program menggunakan blok visual. Seperti puzzle — susun blok untuk menentukan "apa yang terjadi ketika..."

  • 🎪 Built-in Blocks — blok logika bawaan (if, loop, math)
  • 📱 Component Blocks — blok dari komponen yang kamu tambah
  • 🔄 Event Blocks — "ketika tombol diklik..."

4. Cara Kerja Blok Event

Blok di App Inventor bekerja dengan pola Event → Aksi. "Ketika sesuatu terjadi → lakukan ini".

when Button1.Click do

Jalankan aksi saat tombol ditekan

when TextBox1.TextChanged do

Reaksi real-time saat user mengetik

when Screen1.Initialize do

Setup awal saat app pertama dibuka

when Clock1.Timer do

Update tampilan secara berkala

5. 🏗️ App Pertama: "Klik Sapa!"

Buat app sederhana: ketika tombol diklik, label menampilkan "Halo, Dunia!"

Langkah 1 — Designer Mode

  1. 1. Drag Label ke layar → Properties: Text = "Tekan tombol di bawah!", FontSize = 18
  2. 2. Drag Button ke layar → Properties: Text = "👋 Sapa Dunia!"
  3. 3. Rename komponen: Label1 → LabelHasil, Button1 → TombolSapa

Langkah 2 — Blocks Mode

when TombolSapa.Click do
set LabelHasil.Text to "Halo, Dunia! 🎉"

↑ Inilah tampilannya di Blocks mode — blok disusun seperti puzzle
