⚡ C++ & IoT Arduino

Tutorial C++ & IoT

C++ adalah bahasa yang dipakai untuk mengontrol hardware — dari lampu LED hingga robot. Dengan Arduino, kamu bisa mulai bermain hardware tanpa perlu jadi insinyur elektronik dulu!

⚡ C++

Bahasa yang sangat cepat dan efisien. Dipakai di game engine, sistem operasi, dan mikrokontroler. Lebih ketat dari Python, tapi hasilnya powerful!

🤖 Arduino

Platform mikrokontroler paling populer untuk pemula. Hubungkan sensor, LED, motor — dan program semuanya dari laptopmu!

🛒 Yang Dibutuhkan untuk Belajar Arduino

  • • Arduino Uno — harga sekitar Rp 60–100 ribu
  • • LED + resistor + breadboard + kabel jumper — paket starter ~Rp 50 ribu
  • • Arduino IDE — gratis di arduino.cc
  • • Alternatif online (tanpa hardware): Tinkercad Circuits — simulasi gratis!
