Melatih AI dengan Teachable Machine 📷🤖 🚀

Kini giliranmu menjadi pelatih AI! Gunakan kamera atau mikrofon laptop untuk melatih model AI buatanmu sendiri tanpa perlu koding rumit!

⏱️ Waktu: 40 Menit 💡 Level: Kelas 7 SMP (Seru & Mudah) 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Setelah mempelajari materi ini, kamu akan bisa:

01.
Mengenal Teachable Machine

Platform berbasis web dari Google untuk melatih model Machine Learning dengan mudah.

02.
3 Jenis Model Pembelajaran

Model Gambar (Image Project), Suara (Audio Project), dan Gerakan Tubuh (Pose Project).

03.
3 Langkah Utama Melatih AI

Kumpulkan Sampel (Gather Data) → Latih Model (Train) → Uji Coba Langsung (Preview/Test).

04.
Ekspor Model ke Scratch

Menghubungkan model AI yang sudah terlatih ke dalam game animasi Scratch.

3 Langkah Mudah Menjadi Pelatih AI 🎓

1. Kumpulkan Contoh (Data)

Buka webcam, tahan tombol rekam untuk mengambil 50 foto 'Masker Terpasang' dan 50 foto 'Tanpa Masker'.

2. Klik 'Train Model'

Komputer akan menganalisis perbedaan kedua kelompok foto dan membuat model kecerdasan buatan.

3. Uji Coba (Preview)

Tunjukkan wajahmu lagi ke webcam! AI akan langsung menampilkan bar persentase tebakannya.

🎮 Tantangan: Tips Melatih Model AI Terbaik

Saat merekam sampel foto objek untuk AI, manakah teknik yang membuat model lebih pintar dan akurat?

Evaluasi Formatif: Melatih AI dengan Teachable Machine 📷🤖

Uji pemahamanmu secara mandiri (Total Nilai: 100 Poin)

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Platform Teachable Machine dibuat oleh Google untuk tujuan...

2. Proyek di Teachable Machine yang dapat mendeteksi posisi tangan terangkat atau jongkok adalah...

3. Apa yang terjadi jika Class 1 memiliki 500 foto, sedangkan Class 2 hanya memiliki 5 foto?

4. Perangkat keras laptop yang paling sering dipakai saat melatih Teachable Machine Gambar adalah...

5. Model AI yang sudah diekspor dari Teachable Machine dapat dihubungkan ke proyek...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Teachable Machine dapat diakses secara gratis langsung melalui web browser.
2. Melatih model AI di Teachable Machine membutuhkan penulisan ribuan baris kode C++.
3. Class adalah wadah kategori data yang kita beri nama labelnya.
4. Tahap 'Train Model' adalah saat komputer mempelajari pola dari seluruh sampel yang direkam.
5. Pengujian (Testing) berguna untuk melihat apakah AI bisa menebak objek secara akurat secara realtime.
Bagian C

Menjodohkan Konsep & Penjelasan (5 Pasangan · Bobot: 25 Poin)

Bagian D

Mengurutkan Langkah Alur Kerja (Bobot: 25 Poin)

A. Membuka website Teachable Machine dan memilih jenis 'Image Project'
B. Membuat 2 Class baru dan memberi label nama yang jelas
C. Merekam puluhan sampel foto untuk masing-masing Class menggunakan webcam
D. Menekan tombol 'Train Model' dan menunggu proses pelatihan selesai
E. Menguji tebakan model di panel Preview secara realtime
