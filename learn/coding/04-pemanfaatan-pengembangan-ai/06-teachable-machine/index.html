Praktek: Teachable Machine 📸

Sekarang saatnya kamu latih AI sendiri! Teachable Machine dari Google memungkinkanmu membuat model pengenal gambar, suara, atau pose — tanpa satu baris kode pun!

Apa Itu Teachable Machine?

Teachable Machine adalah alat dari Google yang memungkinkanmu melatih model machine learning sendiri langsung di browser. Cukup tunjukkan contoh gambar, suara, atau gerakan — dan AI akan belajar mengenalinya!

🌐 Akses Gratis

Buka teachablemachine.withgoogle.com — tidak perlu install apapun, tidak perlu akun, dan 100% gratis! Semua proses berjalan di browser-mu.

3 Jenis Model yang Bisa Dibuat

🖼️

Image Project

Latih AI mengenali gambar dari webcam atau file foto

Kucing vs Anjing, Kertas vs Plastik

🔊

Audio Project

Latih AI mengenali suara atau kata-kata tertentu

Tepuk tangan vs Jentik jari

🤸

Pose Project

Latih AI mengenali pose tubuh lewat kamera

Berdiri vs Duduk vs Melambai

Panduan Praktek: Buat Pengenal Ekspresi Wajah

Kita akan melatih AI untuk membedakan ekspresi senang 😊 vs sedih 😢 dari gambar wajah!

1

Buka teachablemachine.withgoogle.com → klik "Get Started"

Pilih "Image Project" → "Standard image model"

2

Ubah nama Class 1 menjadi "Senang"

Klik ikon pensil di sebelah nama kelas untuk mengubahnya

3

Kumpulkan foto kelas "Senang"

Klik "Webcam" → tahan "Hold to Record" sambil senyum. Kumpulkan minimal 50 foto!

4

Ubah nama Class 2 menjadi "Sedih"

Lakukan hal yang sama, kali ini dengan ekspresi sedih atau cemberut

5

Klik "Train Model"

Tunggu proses training selesai — biasanya 10-30 detik

6

Test model-mu!

Di kolom Preview, aktifkan webcam dan coba senyum vs cemberut. Lihat persentase akurasi!

Tips Agar Model Akurat

✅ Rahasia Model AI yang Akurat

  • Banyak data — Minimal 50 sampel per kelas, makin banyak makin baik!
  • Variasi — Rekam dari berbagai sudut, pencahayaan, dan jarak
  • Seimbang — Jumlah data tiap kelas harus kira-kira sama
  • Kualitas — Pastikan foto jelas dan mudah dibedakan oleh manusia terlebih dahulu

⚠️ Kenapa Bisa Salah?

Jika akurasi rendah, coba: tambah lebih banyak foto, pastikan pencahayaan konsisten, atau pastikan perbedaan antar kelas cukup jelas.
