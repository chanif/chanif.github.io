Pengenalan Database & MySQL

Bayangkan sebuah lemari arsip raksasa yang terorganisir — itulah database. Semua aplikasi modern, dari Instagram hingga sistem sekolahmu, menyimpan datanya di database. Mari pelajari dasarnya!

1. Mengapa Perlu Database?

📁

Menyimpan Data

Simpan ribuan data siswa, produk, atau transaksi dengan rapi dan aman

🔍

Mencari Cepat

Cari 1 data dari jutaan record dalam hitungan milidetik

🔗

Hubungkan Data

Relasikan tabel siswa dengan nilai, absensi, dan jadwal

💡 Tanpa database: Data disimpan di file teks/Excel → lambat, tidak aman, sulit dicari. Dengan database: Terstruktur, cepat, bisa diakses banyak user sekaligus!

2. Konsep: Database, Tabel, Baris & Kolom

Struktur database mirip seperti spreadsheet Excel, tapi jauh lebih powerful:

🗃️ Database: sekolah_db

Berisi tabel: siswa, guru, nilai, jadwal

📋 Tabel: siswa

🔵 Kolom = jenis data (nama, kelas, dsb) ➡️ Baris = satu record siswa 🔑 id_siswa = Primary Key (unik)

3. Tipe Data di MySQL

Setiap kolom harus punya tipe data yang sesuai isinya:

Tipe DataUntukContoh
INT Angka bulat id, umur, jumlah
DECIMAL(8,2) Angka desimal presisi harga, nilai ujian
VARCHAR(n) Teks pendek (maks n karakter) nama, kelas, email
TEXT Teks panjang deskripsi, catatan
DATE Tanggal (YYYY-MM-DD) tanggal_lahir, tanggal_daftar
DATETIME Tanggal + waktu created_at, updated_at
BOOLEAN / TINYINT(1) Benar/salah aktif, lulus
ENUM Pilihan terbatas jenis_kelamin: "L","P"

4. Setup MySQL dengan XAMPP

1

Download XAMPP

Unduh di apachefriends.org, pilih versi sesuai OS (Windows/Mac/Linux)

2

Install & Jalankan

Install XAMPP, buka XAMPP Control Panel, klik Start di baris Apache dan MySQL

3

Buka phpMyAdmin

Di browser, ketik http://localhost/phpmyadmin → tekan Enter

4

Buat Database Baru

Klik "New" di panel kiri → ketik nama database (contoh: sekolah_db) → klik Create

5

Mulai Belajar SQL!

Klik database yang dibuat → tab SQL → ketik query → klik Go!

🌐 Alternatif tanpa install: Coba DB Fiddle atau SQLite Online — langsung di browser, tidak perlu install apapun!

5. Buat Tabel Pertama

Query SQL untuk membuat tabel siswa:

-- Buat database
CREATE DATABASE sekolah_db;
USE sekolah_db;

-- Buat tabel siswa
CREATE TABLE siswa (
    id_siswa    INT AUTO_INCREMENT PRIMARY KEY,
    nama        VARCHAR(100) NOT NULL,
    kelas       VARCHAR(10)  NOT NULL,
    jenis_kelamin ENUM('L','P') NOT NULL,
    tanggal_lahir DATE,
    alamat      TEXT,
    nilai_rata  DECIMAL(5,2) DEFAULT 0.00
);

-- Cek struktur tabel
DESCRIBE siswa;
✅ AUTO_INCREMENT = id otomatis bertambah (1, 2, 3, ...)
✅ PRIMARY KEY = kolom unik yang jadi identitas baris
✅ NOT NULL = kolom wajib diisi (tidak boleh kosong)
