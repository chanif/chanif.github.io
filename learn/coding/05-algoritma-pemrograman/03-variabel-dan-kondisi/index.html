Variabel Penyimpan Data & Logika Percabangan

Bagaimana game mengingat sisa nyawamu atau memutuskan kapan kamu naik level? Kuncinya ada pada Variabel sebagai kotak memori dan Percabangan (If-Else) sebagai pengambil keputusan cerdas di dalam kode program!

⏱️ Waktu: 45 Menit 📦 Konsep: Variabel, Operator, & If-Else 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Memahami Konsep Variabel sebagai Wadah Memori

Mampu membuat variabel, memberi nilai awal (set value), dan mengubah nilainya secara dinamis (change by value).

02.
Menggunakan Operator Matematika & Logika

Menerapkan operator perbandingan ($<, =, >$) dan logika boolean ($AND, OR, NOT$) serta fungsi angka acak (pick random).

03.
Menyusun Struktur Percabangan If-Then-Else

Membuat dua jalur keputusan berbeda berdasarkan evaluasi kondisi benar (True) atau salah (False).

04.
Mengenal Sintaks Kondisional di Bahasa Python

Memahami bentuk ekuivalen teks percabangan: if score > 10: print('Level Up!').

1

Analogi Kotak Variabel & Tipe Data

Variabel bekerja persis seperti kotak berlabel yang menyimpan satu nilai pada satu waktu

🔢

1. Tipe Data Angka (Number)

Menyimpan nilai kuantitatif seperti: skor = 100, nyawa = 3, atau kecepatan = 5.5 yang dapat dioperasikan matematika (+, -, ×, ÷).

🔤

2. Tipe Data Teks (String)

Menyimpan deretan karakter huruf seperti: nama_pemain = "Andi" atau nama_kota = "Lamongan".

⚖️

3. Tipe Logika (Boolean)

Hanya memiliki dua kemungkinan status nilai: BENAR (True) atau SALAH (False) sebagai hasil evaluasi syarat kondisi.

2

Struktur Pengambilan Keputusan (If-Else)

Mengarahkan komputer memilih jalur tindakan sesuai syarat kondisi

Percabangan 1 Jalur: If-Then
if <skor > 50> then
  say [Hebat! Skor tinggi!] for 2 secs

Aksi di dalam blok hanya berjalan JIKA kondisi bernilai Benar. Jika salah, kode diabaikan.

Percabangan 2 Jalur: If-Then-Else
if <jawaban = "Jakarta"> then
  say [Jawaban Benar!] (+10 Poin)
else
  say [Jawaban Salah! Coba lagi]

Memberikan aksi alternatif di bagian 'else' jika kondisi awal tidak terpenuhi.

Evaluasi Formatif: Variabel & Kondisi

Uji pemahaman variabel, operator perbandingan, dan percabangan If-Else (Total Skor: 100)

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Balok Scratch yang digunakan untuk menambahkan angka +1 ke dalam nilai variabel skor yang sudah ada adalah...

2. Jika mula-mula skor = 10, lalu dijalankan instruksi set [skor] to (0), maka nilai akhir variabel skor menjadi...

3. Operator logika di Scratch yang hanya bernilai Benar (True) jika KEDUA syarat kondisinya sama-sama terpenuhi adalah...

4. Penulisan kode percabangan ekuivalen di bahasa Python untuk mengecek apakah variabel nyawa == 0 adalah...

5. Balok operator (pick random (1) to (6)) sangat cocok digunakan untuk memprogram fungsi simulasi...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Variabel 'For all sprites' (global) dapat diakses dan diubah oleh semua sprite yang ada di proyek Scratch.
2. Perintah set [var] to [0] dan change [var] by [0] memiliki fungsi kerja yang persis sama.
3. Kondisi <not <skor = 10>> akan bernilai Benar jika nilai skor bernilai 5 atau 20.
4. Pada percabangan If-Then-Else, jika syarat kondisi bernilai False, maka balok di bagian 'else' yang akan dijalankan.
5. Variabel di Scratch hanya bisa menyimpan huruf dan sama sekali tidak bisa menyimpan angka desimal.
Bagian C

Menjodohkan Balok Logika & Hasil Evaluasinya (5 Pasangan · Bobot: 25 Poin)

Bagian D

Urutan Menyusun Program Kuis Tanya Jawab Interaktif (Bobot: 25 Poin)

Urutkan logika saat program menanyakan pertanyaan dan mengecek jawaban:

A. Mengatur inisialisasi variabel nilai awal: [set skor to 0]
B. Menanyakan soal ke pengguna: [ask "Ibukota Indonesia?" and wait]
C. Mengecek jawaban dengan percabangan: [if answer = "Jakarta" or answer = "IKN"]
D. Jika benar jalankan [change skor by 10], jika salah jalankan [say "Salah!" in else]
E. Menampilkan hasil skor akhir: [say (join "Total Skormu: " skor)]
