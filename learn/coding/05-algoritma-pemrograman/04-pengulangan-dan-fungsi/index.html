Pengulangan (Loop) & Pembuatan Fungsi Kustom

Programmer sejati pantang menulis kode yang sama berulang kali! Terapkan prinsip DRY (Don't Repeat Yourself) menggunakan 3 varian Loop Scratch (Repeat N, Forever, Repeat-Until) dan bungkus rangkaian blok menjadi Custom Blocks (Fungsi) modular yang rapi dan efisien.

⏱️ Waktu: 45 Menit 🔁 Kunci: Loop, Pen Extension, & My Blocks 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Menguasai 3 Jenis Struktur Loop Scratch

Membedakan repeat N (pasti), forever (siklus game loop), dan repeat-until (bersyarat henti).

02.
Membuat Seni Geometri dengan Ekstensi Pen

Memadukan langkah gerak dan putaran derajat sudut ($360^\circ / N$) untuk menggambar poligon beraturan.

03.
Membuat Custom Block Berparameter (My Blocks)

Menerapkan prinsip DRY dengan merangkum sub-program menjadi satu balok fungsi modular.

04.
Mengenal Konsep Fungsi (def) di Python

Memahami sintaks fungsi Python: def gambar_persegi(ukuran): untuk kemudahan pemeliharaan kode.

1

3 Varian Pengulangan (Loop) di Scratch

Mengotomasi instruksi yang berulang dengan ringkas dan hemat memori

🔢

1. Repeat [N] (Terhitung)

Mengulang instruksi sebanyak $N$ kali tepat. Sangat ideal untuk menggambar segi empat (repeat 4) atau animasi langkah kaki.

♾️

2. Forever (Tak Hingga)

Siklus abadi tanpa henti. Wajib digunakan untuk Game Loop utama: mendeteksi input tombol pemain dan gerakan musuh.

🛑

3. Repeat Until (Bersyarat)

Mengulang terus sampai kondisi tertentu terpenuhi. Contoh: repeat until .

2

Custom Blocks & Prinsip DRY (Don't Repeat Yourself)

Menciptakan balok fungsi buatan sendiri untuk membuat kode mudah dibaca

Kode Berantakan (Tanpa Fungsi):
// Menggambar 3 kotak (12 baris berulang!)
repeat 4 [move 50, turn 90]
go to x: 50 y: 0
repeat 4 [move 50, turn 90]
go to x: 100 y: 0
repeat 4 [move 50, turn 90]
Kode Bersih (Dengan Custom Block):
define [gambar_kotak (ukuran)]
  repeat 4 [move (ukuran), turn 90]

// Pemanggilan Bersih:
gambar_kotak (50)
gambar_kotak (100)

5. Penulisan sintaks pendefinisian fungsi di bahasa pemrograman Python menggunakan kata kunci...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Balok repeat until <touching [bola]?> akan berhenti mengulang saat sprite menyentuh bola.
2. Menggunakan Custom Blocks membuat program berjalan lebih lambat dan sangat dilarang dalam koding profesional.
3. Nested Loop adalah struktur di mana ada sebuah balok perulangan diletakkan di dalam perulangan lainnya.
4. Untuk menggambar lingkaran penuh, sprite harus memutar total akumulasi sudut $360^\circ$.
5. Di Scratch, balok Custom Block yang sudah dibuat tidak bisa diberi parameter input variabel sama sekali.
