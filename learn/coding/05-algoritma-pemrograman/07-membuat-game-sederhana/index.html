Prinsip Desain & Pembuatan Game Sederhana

Bermain game itu seru, tetapi membuatnya sendiri jauh lebih membanggakan! Integrasikan seluruh konsep komputasi: Game Loop (Input $\rightarrow$ Update $\rightarrow$ Render), sistem nyawa & skor, gravitasi platformer di Scratch, game interaktif teks di Python, hingga pengenalan library grafis Pygame.

⏱️ Waktu: 45 Menit 🎮 Fokus: Game Loop, State & Pygame 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Memahami Arsitektur Siklus Game Loop

Menjelaskan alur 3 tahap berkelanjutan per frame: Tangkap Input Pengguna $\rightarrow$ Update Logika/Fisika $\rightarrow$ Gambar Layar (Render).

02.
Mengelola Status Permainan (Game State Management)

Mengontrol transisi status menu utama, gameplay berlangsung, kondisi kalah (Game Over), dan menang (Victory).

03.
Membangun Game Berbasis Teks di Python

Memprogram game tebak angka (Number Guessing) dan gunting-batu-kertas memanfaatkan modul random dan perulangan while.

04.
Mengenal Dasar Framework Pygame

Mengetahui fungsi inisialisasi jendela game (window surface), event loop, dan rendering audio visual di Python.

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Tiga fase utama yang dijalankan secara terus-menerus di dalam siklus Game Loop adalah...

2. Modul bawaan Python yang wajib diimpor untuk memilih angka acak atau mengacak pilihan komputer adalah...

3. Library open-source paling populer di ekosistem Python untuk merancang game 2D dengan grafika dan kontrol keyboard adalah...

4. Konsep 'Game Balancing' dalam perancangan game memiliki tujuan utama untuk...

5. Pada game Scratch platformer, efek gravitasi jatuh bebas ke tanah diprogram dengan cara...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. State Management mengatur perpindahan status layar dari MENU $\rightarrow$ PLAYING $\rightarrow$ GAMEOVER.
2. Di Python, kode random.randint(1, 10) dapat menghasilkan angka 11.
3. Playtesting (uji coba main oleh teman) sangat penting untuk menemukan bug dan mengukur keseruan game sebelum dirilis.
4. Game petualangan teks (Text Adventure) hanya membutuhkan perpaduan perulangan while, percabangan if-else, dan input teks pemain.
5. Game yang bagus harus selalu dibuat sesulit mungkin agar tidak ada satupun pemain yang bisa menyelesaikannya.
