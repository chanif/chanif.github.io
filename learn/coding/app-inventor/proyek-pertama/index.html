Proyek: Buat App Kalkulator BMI

Kita akan membuat aplikasi Android yang menghitung BMI (Body Mass Index) — indikator kesehatan berdasarkan berat dan tinggi badan. Selesai, kamu bisa install di HP sendiri!

Apa Itu BMI?

Rumus BMI

BMI = Berat (kg) ÷ Tinggi² (m)

Contoh: Berat 50 kg, Tinggi 1.6 m → BMI = 50 ÷ (1.6 × 1.6) = 50 ÷ 2.56 = 19.5

< 18.5

Kurus

18.5 – 24.9

Normal

25 – 29.9

Gemuk

≥ 30

Obesitas

Langkah 1 — Desain UI (Designer Mode)

Buat tampilan seperti ini dengan drag-and-drop komponen:

🏃 Kalkulator BMI

Berat Badan (kg)

55

Tinggi Badan (cm)

165
⚡ Hitung BMI

BMI: 20.2 — Normal ✅

🔄 Reset

Komponen yang dibutuhkan:

Label LabelJudul Text: "Kalkulator BMI", FontSize: 20, Bold: true, TextColor: Teal
Label LabelBeratHint Text: "Berat Badan (kg):"
TextBox TextBoxBerat Hint: "Contoh: 55", NumbersOnly: true
Label LabelTinggiHint Text: "Tinggi Badan (cm):"
TextBox TextBoxTinggi Hint: "Contoh: 165", NumbersOnly: true
Button TombolHitung Text: "⚡ Hitung BMI", BackgroundColor: Teal, TextColor: White
Label LabelHasil Text: "" (kosong), TextColor: Green, Bold: true
Button TombolReset Text: "🔄 Reset"

Langkah 2 — Logika Blok (Blocks Mode)

Susun blok berikut di Blocks Mode. Klik "Blocks" di kanan atas untuk switch mode.

🔘 Ketika TombolHitung diklik

when TombolHitung.Click do
set berat to TextBoxBerat.Text (as number)
set tinggi_m to TextBoxTinggi.Text / 100 (as number)
set bmi to berat / (tinggi_m × tinggi_m)
if bmi < 18.5 then
set LabelHasil.Text to "BMI: " + bmi + " — Kurus 📉"
else if bmi < 25 then
set LabelHasil.Text to "BMI: " + bmi + " — Normal ✅"
else if bmi < 30 then
set LabelHasil.Text to "BMI: " + bmi + " — Gemuk ⚠️"
else
set LabelHasil.Text to "BMI: " + bmi + " — Obesitas 🔴"

🔄 Ketika TombolReset diklik

when TombolReset.Click do
set TextBoxBerat.Text to ""
set TextBoxTinggi.Text to ""
set LabelHasil.Text to ""

Langkah 3 — Test & Export App

📱 Test Langsung di HP

  1. 1. Install MIT AI2 Companion dari Play Store
  2. 2. Di App Inventor: klik Connect → AI Companion
  3. 3. Scan QR code di HP kamu
  4. 4. App langsung berjalan real-time!

📦 Download APK

  1. 1. Klik Build → Android App (.apk)
  2. 2. Tunggu proses build (1–2 menit)
  3. 3. Download file .apk
  4. 4. Transfer ke HP dan install!

⚠️ Aktifkan "Install dari sumber tidak dikenal" di pengaturan HP

🚀 Tantangan Selanjutnya!

Coba tambahkan fitur-fitur ini untuk upgrade app kamu:

  • 💡 Tambah validasi: kalau input kosong, tampilkan pesan error
  • 💡 Ganti warna LabelHasil sesuai kategori BMI (hijau/kuning/merah)
  • 💡 Tambah komponen TinyDB untuk simpan hasil terakhir
  • 💡 Tambah TextToSpeech agar hasil dibacakan dengan suara
