Robotika Cerdas & Simulasi Fisika Digital

Gabungkan dunia koding software dengan perangkat fisik nyata! Pelajari triad anatomi robot: Sensor (mata/telinga), Mikrokontroler (otak Arduino / micro:bit), dan Aktuator (otot motor DC & servo), serta kuasai algoritma navigasi otonom Obstacle Avoidance dan Line Follower lewat simulasi virtual.

⏱️ Waktu: 45 Menit 🤖 Simulasi: Ultrasonik, Arduino & Motor 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Memahami Anatomi Triad Sistem Robotika

Menjelaskan peran dan interaksi antara Sensor (input lingkungan), Kontroler (pemroses logika), dan Aktuator (penggerak fisik).

02.
Mengenal Jenis Sensor Elektronik

Memahami fungsi Sensor Ultrasonik HC-SR04 (jarak gelombang suara), Sensor Inframerah IR (pendeteksi garis), dan Gyroscope.

03.
Menguasai Logika Navigasi Otonom

Memprogram algoritma pengikut garis (Line Follower) dan robot penghindar tabrakan dinding rintangan (Obstacle Avoidance).

04.
Memanfaatkan Simulator Rangkaian Virtual

Mampu merangkai dan menguji program robotika secara gratis tanpa perangkat keras fisik melalui platform Tinkercad / Wokwi.

1

3 Pilar Anatomi Sistem Robot

Siklus terpadu penginderaan, pemikiran algoritma, dan tindakan fisik mekanis

📡

1. Sensor (Indera Input)

Mata & telinga robot: Sensor ultrasonik (mengukur jarak objek), sensor inframerah (melihat garis hitam), dan sensor sentuh bumper.

🧠

2. Kontroler (Otak Pemroses)

Mikrokontroler mini: Arduino Uno, BBC micro:bit, atau Raspberry Pi yang mengeksekusi logika algoritma koding.

⚙️

3. Aktuator (Otot Output)

Penggerak fisik: Motor DC roda penggerak, Motor Servo pemutar capit capit, lampu indikator LED, dan buzzer nada suara.

2

Algoritma Otonom Navigasi Robot Populer

Dasar kecerdasan gerak robot pembersih lantai dan mobil pintar

1. Obstacle Avoidance (Hindari Halangan):
jarak = sensor_ultrasonik.read_cm()
if jarak < 15:
    robot.mundur()
    robot.belok_kanan(90)
else:
    robot.maju()
2. Line Follower (Ikuti Garis Hitam):
if sensor_kiri == HITAM and sensor_kanan == HITAM:
    robot.maju()
elif sensor_kiri == HITAM:
    robot.belok_kiri()
elif sensor_kanan == HITAM:
    robot.belok_kanan()

Evaluasi Formatif: Robotika & Simulasi

Uji pemahaman triad sensor-kontroler-aktuator dan algoritma otonom (Total Skor: 100)

Target Kelulusan Minimal 70 Poin
Bagian A

Pilihan Ganda (5 Soal · Bobot: 25 Poin)

1. Tiga komponen utama penyusun arsitektur sistem robotika adalah...

2. Sensor yang memanfaatkan pantulan gelombang suara berfrekuensi tinggi untuk mengukur jarak rintangan di depan robot adalah...

3. Komponen aktuator elektromekanik yang dapat diprogram untuk berputar pada sudut derajat tertentu secara sangat presisi (contoh: 0° s.d. 180° untuk capit lengan robot) adalah...

4. Platform simulasi elektronika online berbasis web gratis yang memungkinkan siswa merangkai board Arduino dan sensor secara virtual adalah...

5. Contoh robot otonom berteknologi kecerdasan artifisial yang sudah banyak digunakan di rumah tangga modern saat ini adalah...

Bagian B

Benar atau Salah (5 Soal · Bobot: 25 Poin)

1. Mikrokontroler berfungsi sebagai unit pemroses utama yang menjalankan logika instruksi program koding robot.
2. Robot Line Follower menggunakan sensor inframerah (IR) untuk membedakan kontras warna garis hitam dan latar putih di lantai.
3. Belajar robotika wajib membeli perangkat keras kit mahal dan mustahil dipelajari lewat simulator virtual gratis.
4. Algoritma Pathfinding (seperti A*) digunakan robot untuk menemukan rute jalur terpendek dalam labirin maze.
5. Aktuator adalah perangkat penerima sinyal sensor yang tidak memiliki kemampuan bergerak fisik.
Bagian C

Menjodohkan Perangkat Robotika & Fungsinya (5 Pasangan · Bobot: 25 Poin)

Perangkat Robot:

1. Sensor Ultrasonik
2. Sensor Inframerah (IR)
3. Arduino Uno
4. Motor DC
5. Buzzer

Pilih Fungsi Utama:

Bagian D

Urutan Siklus Siklus Kerja Robot Penghindar Rintangan (Bobot: 25 Poin)

Urutkan proses pengambilan keputusan robot saat mendeteksi rintangan dinding:

A. Sensor ultrasonik memancarkan gelombang suara dan menangani pantulan jarak objek
B. Mikrokontroler Arduino membaca nilai jarak dan mengecek apakah jarak < 15 cm
C. Program memutuskan kondisi darurat dan mengirim perintah berhenti sesaat
D. Driver motor memerintahkan motor kiri mundur dan motor kanan maju untuk berbelok 90°
E. Setelah jalur depan kembali bebas rintangan, kedua motor roda kembali bergerak maju
