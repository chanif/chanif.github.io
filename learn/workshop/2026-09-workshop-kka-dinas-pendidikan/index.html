Vibe Coding MPI & Publish ke GitHub Pages 🚀

Workshop praktis untuk Guru SMP: buat media pembelajaran interaktif (MPI) berbasis web tanpa ngoding menggunakan AI (Gemini / Claude), lalu publish gratis ke internet via GitHub Pages.

🎮 Lihat Contoh Hasil MPI 📋 Mulai dari Langkah 1

📍 Alur Workshop Hari Ini

Lima langkah runut dari nol hingga MPI Anda bisa diakses siapapun di internet:

📁
1. Siapkan Folder
🤖
2. Buat MPI via AI
🐙
3. Buat Akun GitHub
🌐
4. Aktifkan Pages
⬆️
5. Upload Karya
1

📁 Siapkan Folder Kerja

Sebelum buka AI, siapkan dulu bahan-bahannya.

Buat satu folder baru di laptop Anda (misalnya di Desktop), lalu masukkan tiga berkas berikut ke dalamnya:

📁 MPI_MataPelajaran_Materi/
├── logo.png    ← Logo resmi sekolah
├── foto-guru.jpg    ← Foto resmi guru
└── spesifikasi.md    ← Template prompt (diisi & dikirim ke AI)
* File index.html akan ditambahkan setelah AI selesai membuatnya (Langkah 2).
🖼️
logo.png

Logo resmi sekolah Anda. Simpan dengan nama persis logo.png. Bisa minta ke TU atau unduh dari web sekolah.

👤
foto-guru.jpg

Foto resmi Anda. Simpan dengan nama persis foto-guru.jpg. Bisa dari foto ID card atau foto formal lainnya.

📋
spesifikasi.md

Template prompt AI. Isi dengan mata pelajaran, materi, dan nama Anda. Unduh template di sini.

💡

Nama file harus persis: AI akan menulis kode yang mencari file bernama logo.png dan foto-guru.jpg. Jika nama berbeda, foto tidak akan muncul. Jika belum punya foto/logo, tetap lanjutkan — tampilan masih rapi.

2

🤖 Buat MPI via Gemini atau Claude

Isi spesifikasi, kirim ke AI, copy hasilnya.

A

Isi File spesifikasi.md

Buka file spesifikasi.md dengan Notepad, lalu ubah Bagian 1 sesuai mata pelajaran, materi, dan identitas Anda. Bagian 2, 3, dan 4 tidak perlu diubah.

— BAGIAN YANG DIUBAH —
- Mata Pelajaran : IPA
- Fase / Kelas    : Fase D — Kelas VIII
- Materi Pokok   : Tata Surya & Planet
- Tujuan Belajar : Peserta didik mampu menjelaskan urutan planet di tata surya
- Nama Guru      : Budi Santoso, S.Pd.
- Nama Sekolah  : SMP Negeri 1 Lamongan
B

Buka Gemini atau Claude

Pilih salah satu chatbot AI berikut (keduanya gratis, cukup login dengan akun Google):

✦
Google Gemini
gemini.google.com

Login dengan akun Google. Cocok karena terintegrasi dengan akun sekolah.
🔶
Claude (Anthropic)
claude.ai

Daftar dengan email. Unggul untuk hasil kode HTML yang sangat rapi dan lengkap.
C

Salin Seluruh Isi spesifikasi.md → Kirim ke AI

1.Buka file spesifikasi.md → tekan Ctrl+A → Ctrl+C (salin semua)
2.Buka Gemini atau Claude di browser, klik di kotak chat
3.Tekan Ctrl+V (tempel) → tekan Enter
4.Tunggu sekitar 30–90 detik. AI akan membuatkan kode HTML lengkap secara otomatis.
⚠️

Kode terpotong? Ketik di chat yang sama: "Lanjutkan kodenya dari baris terakhir" lalu tekan Enter. Ulangi hingga AI menghasilkan tag penutup </html>.

D

Simpan Kode sebagai index.html

1.Klik tombol "Copy code" atau salin seluruh kode dari balasan AI
2.Buka Notepad (ketik "Notepad" di Start Menu Windows)
3.Tekan Ctrl+V → tempel kode ke Notepad
4.Klik File → Save As → ubah Save as type menjadi All Files (*.*) → beri nama index.html → simpan ke folder tadi
5.Klik ganda file index.html → MPI Anda akan terbuka di browser! 🎉
Struktur folder sekarang:
📁 MPI_MataPelajaran_Materi/
├── logo.png
├── foto-guru.jpg
├── spesifikasi.md
└── index.html  ← Ini yang baru dibuat dari AI ✓
3

🐙 Buat Akun GitHub

Platform gratis untuk menyimpan dan mempublikasikan file web.

GitHub adalah platform penyimpanan file gratis yang juga bisa digunakan untuk mempublikasikan website. Kita akan pakai fitur GitHub Pages agar MPI Anda dapat diakses siapapun via link internet.

1
Buka github.com/signup di browser
2

Isi formulir pendaftaran:

  • • Email: gunakan email aktif Anda
  • • Password: buat password yang kuat
  • • Username: ini akan jadi bagian dari alamat website Anda
⚠️

Username WAJIB huruf kecil semua! Misalnya: budi.santoso atau pak-budi-smpn1. Hindari huruf kapital, spasi, dan karakter khusus selain titik dan strip.

✅

Format username yang baik: nama Anda dengan strip (-) sebagai pemisah. Contoh: budi-santoso, pak-fanani-smpn2

3
Verifikasi email → selesaikan teka-teki (puzzle) keamanan → pilih paket Free → akun selesai dibuat ✓
💡

Alamat website GitHub Pages Anda nantinya akan berformat: username.github.io/nama-repositori/. Itulah mengapa username perlu dipilih dengan baik.

4

🌐 Buat Repositori & Aktifkan GitHub Pages

Siapkan "rumah" untuk file MPI Anda di internet.

Repositori = folder proyek di GitHub. Kita buat satu repositori khusus untuk MPI ini, lalu aktifkan GitHub Pages agar bisa diakses sebagai website.

1
Setelah login, klik tombol + New (pojok kiri atas) atau buka github.com/new
2

Isi form repositori baru:

  • • Repository name: mpi-ipa-tata-surya (gunakan huruf kecil & strip)
  • • Description: opsional, bisa diisi singkat
  • • Pilih Public (wajib agar GitHub Pages bisa aktif)
  • • Centang "Add a README file"
3
Klik "Create repository" → repositori berhasil dibuat ✓
4

Aktifkan GitHub Pages:

  • • Di halaman repositori, klik tab Settings
  • • Di menu kiri, klik Pages
  • • Di bagian Source, ubah dari None menjadi Deploy from a branch
  • • Branch: pilih main → Folder: pilih / (root)
  • • Klik Save
🎉

Setelah save, GitHub akan menampilkan alamat website Anda: https://username.github.io/mpi-ipa-tata-surya/. Alamat ini mungkin butuh 1–5 menit untuk aktif setelah file diupload.

5

⬆️ Upload File MPI ke GitHub

Unggah folder kerja Anda agar bisa diakses semua orang.

Sekarang upload semua file dari folder kerja Anda ke repositori GitHub yang baru dibuat.

1
Di halaman repositori GitHub Anda, klik tombol "Add file" → pilih "Upload files"
2

Seret dan jatuhkan (drag & drop) ketiga file dari folder kerja Anda ke area upload, atau klik "choose your files" untuk pilih manual:

✅ index.html
✅ logo.png
✅ foto-guru.jpg
3
Gulir ke bawah → di bagian Commit changes, tulis keterangan singkat (misal: "Tambah MPI IPA Tata Surya") → klik "Commit changes"
4
Tunggu 1–5 menit, lalu buka alamat website Anda: https://username.github.io/nama-repositori/
🎉
Selamat! MPI Anda Online!

Media pembelajaran interaktif buatan Anda kini dapat diakses oleh siapapun — siswa, orang tua, rekan guru — kapanpun dan dimanapun, hanya dengan link.

🔄

Ingin perbarui MPI? Minta perbaikan ke AI (minta warna berbeda, tambah soal, dll.), simpan ulang sebagai index.html, lalu upload lagi ke GitHub — file lama akan tertimpa otomatis.
