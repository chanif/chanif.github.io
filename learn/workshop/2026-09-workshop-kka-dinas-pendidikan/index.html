1

📁 Siapkan Folder Kerja

Siapkan bahan dan berkas aset pembelajaran sebelum berinteraksi dengan AI.

Buat satu folder kerja baru di komputer atau laptop Anda (misalnya di Desktop dengan nama materi Anda), lalu masukkan berkas-berkas berikut ke dalamnya:

📁 MPI_MataPelajaran_Materi/
├── logo-sekolah.png    ← Berkas logo sekolah (nama file bebas)
├── foto-guru.jpg       ← Foto profil resmi guru (nama file bebas)
├── bg-ruang-kelas.jpg    ← Foto latar belakang (unduh tautan di bawah)
└── spesifikasi.md       ← Berkas acuan prompt (unduh tautan di bawah)
* Berkas index.html akan ditambahkan ke folder ini setelah selesai diunduh dari AI (Langkah 2).
🖼️
Logo Sekolah

Logo resmi instansi/sekolah Anda. Format dan nama berkas bebas (PNG, JPG, dll.).

👤

Foto resmi Anda untuk kartu profil pengembang. Format dan nama berkas bebas.

🏫

📋

💡

Fleksibel & Otomatis: Nama berkas foto dan logo tidak wajib diubah menjadi logo.png atau foto-guru.jpg. Karena seluruh berkas gambar akan diunggah bersamaan ke chat AI, sistem AI akan secara otomatis mendeteksi nama berkas asli Anda dan menyelaraskannya ke dalam kode program MPI.

2

🤖 Buat MPI dengan AI

Lengkapi spesifikasi, unggah berkas ke AI, lalu unduh hasilnya.

A

Sesuaikan Dokumen spesifikasi.md

Buka berkas spesifikasi.md menggunakan Notepad, lalu sesuaikan data pada Bagian 1 berdasarkan mata pelajaran, topik materi, dan identitas Anda. Bagian 2, 3, dan 4 merupakan standar sistem dan tidak perlu diubah.

— CONTOH BAGIAN YANG DISESUAIKAN —
- Mata Pelajaran : IPA
- Fase / Kelas    : Fase D — Kelas VIII
- Materi Pokok   : Sistem Pernapasan Manusia
- Tujuan Belajar : Peserta didik mampu menganalisis sistem pernapasan manusia serta mekanisme pernapasan dada dan perut
- Nama Guru      : Edy Santoso, S.Pd.
- Nama Sekolah  : SMP Negeri 1 Lamongan
B

Pilih Platform AI: Claude (Rekomendasi Utama) atau Gemini

Untuk efisiensi kerja yang maksimal, Claude (Anthropic) sangat disarankan karena menyediakan panel interaktif (Artifacts) yang memungkinkan pratinjau langsung serta fitur unduh berkas .html utuh secara mandiri.

⭐ Rekomendasi Utama
🔶
Claude (Anthropic)
claude.ai

Pilihan Terbaik: Dilengkapi panel Artifacts di sebelah kanan dengan tombol unduh berkas HTML langsung. Menghasilkan kode visual, efek suara Web Audio API, dan simulasi sains interaktif secara utuh.

✦
Google Gemini
gemini.google.com

Alternatif Praktis: Cukup masuk dengan akun Google pribadi Anda. Kode hasil generasi disalin menggunakan tombol Copy code lalu disimpan melalui Notepad.

C

Unggah Berkas spesifikasi.md & Berkas Gambar ke AI

Lampirkan berkas spesifikasi bersama seluruh gambar dari folder kerja Anda secara langsung ke dalam sesi percakapan AI:

1. Akses platform claude.ai (atau Gemini) pada browser Anda.
2. Klik ikon Lampiran (tombol klip kertas 📎 atau tanda tambah +) pada kolom pesan.
3.
Pilih dan unggah bersamaan berkas-berkas dari folder kerja Anda:
📎 spesifikasi.md (panduan acuan MPI)
🖼️ Logo sekolah Anda (format apa pun)
👤 Foto profil guru (format apa pun)
🏫 bg-ruang-kelas.jpg (latar belakang kelas)
4.
Ketikkan prompt instruksi singkat berikut pada kolom chat:
Buatkan media pembelajaran interaktif (MPI) dalam 1 file HTML lengkap berdasarkan spesifikasi.md dan berkas gambar terlampir.
5. Tekan Enter dan tunggu sekitar 30–60 detik selagi AI menyusun aplikasi MPI Anda.
✨

Keuntungan Melampirkan Gambar: Dengan melihat berkas visual Anda secara langsung, AI dapat menentukan skema warna yang harmonis dengan logo sekolah serta memastikan pemanggilan nama berkas di dalam kode HTML presisi secara otomatis.

D

Unduh Berkas HTML → Simpan ke Folder Kerja sebagai index.html

Gunakan alur pengunduhan langsung yang praktis dan terbebas dari kesalahan salin kode:

1. Pada Claude: Panel Artifacts di sebelah kanan layar akan menyajikan pratinjau interaktif MPI Anda. Klik tombol Download (ikon panah unduh 📥 pada sudut atas panel Artifacts). Berkas HTML akan tersimpan di folder Downloads komputer Anda.
2. Buka folder Downloads di laptop Anda, temukan berkas HTML yang baru diunduh, lalu ubah namanya (Rename) menjadi index.html.
3. Pindahkan Berkas: Pindahkan (Cut / Ctrl+X) berkas index.html tersebut ke dalam folder kerja Anda (MPI_MataPelajaran_Materi) berdampingan dengan berkas gambar.
4. (Opsi jika menggunakan Gemini): Klik tombol "Copy code" → buka Notepad → tempel (Ctrl+V) → pilih File → Save As → ubah Save as type menjadi All Files (*.*) → simpan dengan nama index.html ke folder kerja Anda.
5. Uji Coba Hasil: Klik ganda (double-click) berkas index.html pada folder kerja Anda. Aplikasi MPI interaktif Anda akan langsung terbuka dan siap digunakan di browser! 🎉
Struktur folder kerja Anda saat ini:
📁 MPI_MataPelajaran_Materi/
├── [berkas logo sekolah Anda]
├── [berkas foto profil guru]
├── bg-ruang-kelas.jpg
├── spesifikasi.md
└── index.html  ← Berkas MPI utama hasil unduhan dari AI ✓
3

🐙 Buat Akun GitHub

Platform gratis untuk menyimpan dan mempublikasikan file web ke seluruh dunia.

GitHub adalah platform penyimpanan berkas digital gratis nomor satu di dunia yang memiliki fitur GitHub Pages. Dengan GitHub Pages, dokumen web MPI Anda otomatis diubah menjadi website online yang dapat diakses siswa maupun rekan guru melalui tautan internet.

1
Buka github.com/signup di browser laptop Anda.
2

Isi formulir pendaftaran akun:

  • • Email: gunakan email aktif Anda (misalnya akun Google pribadi)
  • • Password: buat kata sandi yang aman dan mudah diingat
  • • Username: ini akan menjadi bagian dari alamat website utama Anda!
⚠️

Username WAJIB huruf kecil semua! Hindari huruf kapital, spasi, dan simbol selain strip (-). Misalnya: edysantoso atau pak-edy-smpn1.

✅

Contoh username yang ideal: nama lengkap atau identitas sekolah Anda. Contoh: edysantoso, pak-fanani-smpn2

3
Verifikasi email → selesaikan puzzle keamanan → pilih paket Free (Gratis) → akun GitHub Anda siap digunakan ✓
💡

Alamat Website Anda: Di langkah berikutnya, kita akan membuat repositori utama bernama <username>.github.io. Dengan format ini, alamat website Anda akan langsung tampil rapi sebagai https://username.github.io/ tanpa subfolder! Contoh jika username Anda edysantoso, maka tautan website Anda adalah https://edysantoso.github.io/.

4

🌐 Buat Repositori <username>.github.io & Aktifkan GitHub Pages

Siapkan repositori User Site di GitHub agar MPI langsung aktif di domain utama.

Sesuai dokumentasi resmi GitHub Pages, setiap pengguna dapat memiliki satu situs utama (User Site) dengan memberi nama repositori persis sesuai username: <username>.github.io.

1
Setelah login ke GitHub, klik tombol + New (di pojok kiri atas) atau langsung buka github.com/new.
2

Isi formulir pembuatan repositori:

  • • Repository name: ketik persis <username>.github.io
  • • Description: opsional, misalnya "Media Pembelajaran Interaktif IPA Sistem Pernapasan Manusia"
  • • Visibility: pilih Public (wajib agar dapat diakses gratis oleh siswa)
  • • Centang "Add a README file"
📌

Penting (Dokumentasi GitHub Pages): Nama repositori harus berupa huruf kecil semua dan sama persis dengan username akun Anda diikuti dengan .github.io. Contoh: jika username Anda adalah edysantoso, maka nama repositorinya WAJIB bernama edysantoso.github.io.

3
Klik tombol hijau "Create repository" di bagian bawah → repositori berhasil dibuat ✓
4

Pengaturan Branch & Aktifkan GitHub Pages:

  • • Di halaman repositori baru Anda, klik tab Settings (menu ikon gerigi di bilah atas)
  • • Pada menu sebelah kiri (kategori Code and automation), klik Pages
  • • Di bagian Build and deployment → Source, pilih Deploy from a branch
  • • Di bagian Branch: pilih main (atau master) → Folder: pilih / (root)
  • • Klik tombol Save
🎉

GitHub Pages kini sudah aktif! Alamat website Anda adalah: https://<username>.github.io/ (contoh: https://edysantoso.github.io/). Halaman akan segera menampilkan MPI Anda begitu berkas diunggah pada Langkah 5.

5

⬆️ Upload File MPI ke GitHub

Unggah seluruh berkas dari folder kerja agar MPI langsung tayang di internet.

Sekarang unggah seluruh berkas dari folder kerja lokal Anda ke dalam repositori <username>.github.io.

1
Di halaman utama repositori GitHub Anda, klik tombol "Add file" (di sebelah tombol hijau Code) → pilih "Upload files".
2

Seret dan jatuhkan (drag & drop) seluruh berkas dari folder kerja Anda ke area upload, atau klik "choose your files":

✅ index.html (halaman utama MPI hasil dari Claude/AI)
✅ logo.png (logo resmi sekolah)
✅ foto-guru.jpg (foto profil guru)
✅ bg-ruang-kelas.jpg (latar belakang ruang kelas)
3
Gulir ke bawah → di bagian Commit changes, beri keterangan singkat (misal: "Upload MPI IPA Sistem Pernapasan Manusia") → klik tombol hijau "Commit changes".
4
Tunggu sekitar 1–3 menit agar server GitHub selesai memproses berkas, lalu buka alamat website Anda: https://<username>.github.io/ (contoh: https://edysantoso.github.io/).
🎉
Selamat! MPI Anda Telah Online di Seluruh Dunia!

Media pembelajaran interaktif buatan Anda kini dapat diakses oleh siapapun — siswa di kelas, orang tua di rumah, maupun rekan guru di sekolah lain — hanya dengan membagikan tautan website Anda.

🔄

Ingin memperbarui atau memperbaiki konten MPI? Cukup minta perbaikan ke chat AI, download dan ubah nama file baru menjadi index.html, lalu upload ulang ke GitHub dengan cara yang sama — file lama akan otomatis tertimpa dan ter-update!

✨ Rekomendasi Pengembangan Mandiri Tingkat Lanjut (Next Level Vibe Coding)

🚀 Kembangkan MPI Mandiri dengan Antigravity IDE

Sudah berhasil membuat MPI pertama via web chat? Untuk pengembangan jangka panjang, bapak/ibu guru dapat beralih ke Antigravity IDE — lingkungan kerja pemrograman modern berbasis Agentic AI yang bekerja langsung pada berkas laptop Anda tanpa perlu download atau copy-paste manual berulang kali.

🤖

AI Agent Mengedit Berkas Langsung

Cukup ketik instruksi bahasa santai (misal: "Tambahkan simulasi interaktif tekanan udara diafragma dan berikan efek suara saat paru-paru mengembang"), Antigravity AI akan langsung membuka file, merencanakan solusi, dan menuliskan kodenya ke index.html secara otomatis.

⚡

Pratinjau Langsung (Live Preview) Seketika

Memiliki browser terintegrasi tepat di sebelah editor kode. Setiap kali AI melakukan perubahan pada animasi visual, tata letak kartu soal, atau efek suara Web Audio API, hasilnya langsung tampil tanpa perlu membuka-tutup atau me-refresh browser secara manual.

📂

Bekerja Utuh pada Folder & Berkas Lokal

Antigravity langsung membaca struktur folder proyek Anda (berkas logo, foto guru, maupun latar belakang kelas). AI dapat mengukur dimensi gambar asli dan memastikan integrasi visual di MPI berjalan sempurna tanpa risiko gambar hilang atau salah path.

🐙

Sinkronisasi GitHub Pages Lebih Cepat

Ingin mengupdate MPI yang sudah online di <username>.github.io? Dengan terminal terintegrasi atau instruksi langsung ke AI agent, Anda dapat melakukan pembaruan ke repositori GitHub hanya dengan satu klik tanpa perlu upload manual lewat browser.

💡 Cara Mulai Mengembangkan MPI dengan Antigravity IDE:
  1. Buka aplikasi Antigravity IDE di laptop Anda.
  2. Pilih menu File → Open Folder, lalu arahkan ke folder proyek MPI Anda (folder yang berisi index.html, gambar, dan spesifikasi.md).
  3. Buka panel chat AI (Agent Mode), lalu sampaikan ide pengembangan lanjutan (contoh: "Buatkan halaman rangkuman materi pernapasan dengan diagram SVG interaktif dan tambahkan kuis bertingkat 5 soal").
  4. Agen AI akan menganalisis kode Anda, menyusun rencana, memperbarui file secara otomatis, dan Anda dapat langsung mengujinya di panel preview bawaan!
