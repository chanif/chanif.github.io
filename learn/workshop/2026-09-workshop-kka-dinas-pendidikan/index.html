# 📋 SPESIFIKASI PROMPT MEDIA PEMBELAJARAN INTERAKTIF (MPI) SMP
# Template Vibe Coding Mandiri — Siap Pakai untuk Semua Mata Pelajaran

---

## 🎯 1. IDENTITAS & MATERI (SESUAIKAN DENGAN KELAS ANDA)
- Mata Pelajaran : [Contoh: IPA / Matematika / Bahasa Indonesia / IPS / Informatika / Bahasa Inggris]
- Fase / Jenjang   : [Contoh: Fase D — Kelas VII / VIII / IX SMP]
- Materi Pokok    : [Contoh: Sistem Respirasi (Mekanisme Pernapasan) / Teorema Pythagoras / Teks Prosedur]
- Tujuan Singkat  : [Contoh: Peserta didik mampu menganalisis mekanisme inspirasi-ekspirasi serta fungsi diafragma]
- Nama Guru       : [Contoh: Ach. Chanifuddin Fanani, S.Pd.]
- Nama Sekolah    : [Contoh: SMP Negeri 2 Lamongan]
- File Logo       : logo-smp-negeri-2-lamongan.png (atau logo.png)
- File Foto Guru  : fanani.jpg (atau foto-guru.jpg)

---

## 🎨 2. ESTETIKA, TIPOGRAFI, & ATURAN TEKNIS (WAJIB DIPATUHI AI)
1. Wajib HANYA 1 file tunggal `index.html` lengkap (HTML, CSS di dalam <style>, dan JavaScript di dalam <script>). DILARANG memecah berkas .css atau .js terpisah.
2. UKURAN FONT WAJIB BESAR & TERBACA JELAS DI LAYAR PROYEKTOR:
   - Teks isi dan deskripsi minimal 14px–16px (text-sm hingga text-base).
   - Judul halaman & kartu minimal 20px–36px (text-xl hingga text-4xl).
   - Tombol dan pilihan kuis minimal 16px (text-base atau text-lg, tebal dan nyaman disentuh).
   - DILARANG KERAS memakai teks terlalu kecil (hindari text-[10px], text-[11px], atau text-xs untuk konten inti).
3. Tema visual cerah ceria (latar putih bersih, aksen pastel cerah: sky blue, mint, coral, amber). HINDARI tema gelap/dark mode yang kusam.
4. Perkaya simbol visual: emoji tematik yang variatif (🫁 🌬️ 👃 🎋 🌿 🍇 🛡️ 🧬 📖 🎯 📝 👨‍🏫 💡), kartu-kartu berbingkai cerah, dan ilustrasi SVG terintegrasi.
5. Efek suara WAJIB disintesis murni menggunakan Web Audio API (bunyi klik, napas, benar, salah, selesai). DILARANG memakai file MP3 eksternal.
6. Logo & Foto didukung dengan fallback otomatis:
   - Logo di Cover: <img src="logo-smp-negeri-2-lamongan.png" alt="Logo" onerror="this.src='logo.png'; this.onerror=function(){this.style.display='none';};">
   - Foto di Profil: <img src="fanani.jpg" alt="Foto Guru" onerror="this.src='foto-guru.jpg'; this.onerror=function(){this.src='data:image/svg+xml,...';};">
7. Tampilan dikunci dalam kontainer rasio 16:9 lanskap responsif (aspect-ratio: 16/9, fit to viewport).
8. Standar Cover Profesional Kemendikdasmen: Bilah logo sekolah di kiri, lencana kurikulum di kanan, kartu ringkasan samping, judul 3D sticker outline dengan subjudul oranye, serta tombol ikonik '▶ MULAI' berpendar.

---

## 📱 3. STRUKTUR ALUR MEDIA (SPA 7 BAGIAN)
1. Cover (Standar Direktorat SMP: Logo sekolah, lencana kurikulum, judul 3D sticker outline, tombol '▶ MULAI' berpendar, dan kredit nama guru).
2. Menu Utama (6 Kartu 3D membal: Petunjuk, Organ, Simulator 'Wah', Evaluasi Multi-Format, Profil Guru, Fakta Sains).
3. Petunjuk & Tujuan Pembelajaran (Capaian belajar jelas dan langkah eksplorasi).
4. Materi Organ Pernapasan (6 Kartu organ visual dengan penjelasan mendalam).
5. Simulasi Interaktif Berdampak "WAH" (Animasi real-time Tarik/Hembus napas, pergerakan diafragma, suara napas Web Audio, telemetri sains, dan mode otomatis).
6. Evaluasi Multi-Format Lengkap:
   - Bagian A: Pilihan Ganda (PG berhuruf besar, 30 poin).
   - Bagian B: Menjodohkan Organ & Fungsi dengan animasi garis penghubung SVG interaktif (40 poin).
   - Bagian C: Benar / Salah cepat (30 poin).
   - Halaman Hasil & Rekapitulasi: Skor total skala 100, rincian skor tiap bagian, dan tombol reset.
7. Profil Guru Pengembang (Foto guru, identitas, sekolah, kata motivasi belajar).

---

## 💻 4. PERINTAH INSTRUKSI KEPADA AI
"Tolong buatkan kode program lengkap untuk Media Pembelajaran Interaktif (MPI) di atas sekarang. Tuliskan kodenya secara utuh dalam 1 blok kode HTML lengkap tanpa terpotong, dikunci dalam rasio 16:9 lanskap responsif, dengan warna cerah ceria, huruf BESAR DAN TERBACA JELAS (font minimal 14px-16px, judul 24px-44px), cover profesional standar Kemendikdasmen dengan judul 3D sticker outline dan tombol '▶ MULAI' berpendar, simulator visual paru-paru interaktif 'wah' bersuara sintetis, serta evaluasi multi-format lengkap!"
