🎯 Konsep: Berpikir Kritis & Argumentasi · 2 JP

4

Produksi Media via Claude AI

10.45–12.00 · Dari prompt ke media HTML interaktif, instan

Peserta membuka Claude AI, salin salah satu prompt dari "Bank Prompt" di bawah, sesuaikan materi & identitasnya, lalu jalankan. Hasilnya langsung berupa halaman HTML interaktif siap pakai — tidak perlu coding.

✏️ Sebelum Mulai: Siapkan Identitas

👤 Identitas

Nama guru & nama sekolah

📁 Nama File

Jika menyebut nama file (foto/logo) di prompt, hindari spasi & karakter khusus — gunakan tanda hubung. cth: logo-sekolah.png, bukan "Logo Sekolah (1).png"

🎮

Media Materi & Kuis Terintegrasi

Bertindaklah sebagai Expert Web Developer dan Pendidik Profesional. Buatkan 1 file HTML tunggal (HTML, Tailwind CSS via CDN, dan Vanilla JS) berupa Media Pembelajaran Interaktif Utuh untuk mata pelajaran KKA (Koding & Kecerdasan Artifisial) target Siswa Kelas 5 SD.

Topik: 4 Pilar Berpikir Komputasional.
Struktur Wajib: Terdiri dari 2 bagian utama yang bisa dinavigasi: 1) 'Ruang Belajar' berisi ringkasan materi bergambar/kartu informasi yang mudah dipahami anak SD (tamilkan detail materi dan contoh kontekstual ketika card di-klik, gunakan sistem show-hide element). 2) 'Tantangan Kuis' berisi 5 soal evaluasi pilihan ganda dari materi tersebut.
Fitur & UI/UX: Sistem skor *real-time*, efek animasi benar/salah, tombol 'Main Lagi'. Desain gamifikasi ramah anak (warna-warni, *rounded corners*), 100% responsif di HP. Penting: Jangan gunakan alert() browser, buat navigasi perpindahan halaman antar materi dan kuis secara dinamis (Single Page Application).
🃏

Simulasi Klasifikasi AI

Sebagai Expert Web Developer, buatkan media interaktif 1 file HTML tunggal (Tailwind CSS & Vanilla JS) untuk Kelas 6 SD, mapel KKA, materi: 'Literasi AI - Mengenali Pola'.

Buat simulasi 'Latih Model AI-mu'. Alur: Siswa memasukkan 'Data Latih' dengan mengeklik tombol pemilah (misal: mengelompokkan ciri-ciri Apel vs Jeruk).

PENTING (Logika Utama): JavaScript harus *benar-benar* menghitung dan mencatat data klik dari pengguna. Jika siswa sengaja melatih AI dengan data yang salah/terbalik (misal: ciri jeruk diklik sebagai apel), maka hasil tebakan AI di akhir wajib ikut salah sesuai data latih tersebut. Tunjukkan prinsip fundamental AI yaitu 'Garbage In, Garbage Out'. Setelah input data selesai, beri animasi *progress bar* 'AI Belajar', lalu uji coba tebakannya. Berikan penjelasan singkat konsep *Machine Learning* dan UI futuristik ramah anak.
🔁

Game Drag-and-Drop Algoritma

Tuliskan kode untuk 1 file HTML utuh (menggunakan Tailwind CSS & Vanilla JS) untuk Game Drag-and-Drop. Target: Siswa Kelas 5 SD, Mata Pelajaran KKA.

Misi Pemain: Menyusun urutan langkah Algoritma yang teracak (dalam aplikasi ada 3 tema yang tampil secara acak ketika game dimulai: 'Langkah Robot Membuat Teh Manis', 'Algoritma Memasak Nasi', dan 'Urutan Langkah Memasak Mie') ke dalam kotak urutan yang benar (1 sampai 5(atau lebih)).
Spesifikasi Teknis: Interaksi *drag-and-drop* harus mulus dan wajib mendukung sentuhan di layar HP (*touch events*). Tambahkan validasi (Benar/Salah) di setiap langkah, dan munculkan efek konfeti (*confetti animation*) saat semua urutan tepat. Desain menggunakan tata letak *grid/flex* yang rapi seperti aplikasi *mobile* modern.
🏫

+ Tambahan: Prompt Personalisasi

Pilih 1 prompt dari Bank Prompt di atas, lalu tambahkan kalimat berikut di akhir prompt tersebut agar hasilnya terasa lebih profesional dan custom milik sekolahmu sendiri:

...Penting: Pastikan seluruh kode digabung ke dalam 1 file HTML tunggal (single file HTML). Pada bagian header, tambahkan judul 'Media KKA - [Nama Sekolah Bapak/Ibu]' berdampingan dengan logonya menggunakan tag <img src="../logo-sekolah.png">. Di bagian footer, tuliskan 'Dikembangkan oleh: [Nama Bapak/Ibu]' beserta foto menggunakan tag <img src="../foto-guru.jpg">. Buat agar desainnya rapi dan profesional.
📁

Catatan Penting: Setelah file media HTML diunduh/disimpan, pastikan file gambar (logo dan foto) diletakkan di dalam satu folder yang persis sama dengan file HTML tersebut agar gambar bisa tampil di layar.
