Materi 1: Sistem Komputer & Segitiga Emas

🖥️ 1. Apa Itu Sistem Komputer?

Sistem Komputer adalah kesatuan utuh yang terdiri dari Hardware, Software, dan Brainware yang bekerja sama mengolah data menjadi informasi.

📱 HP-mu adalah komputer! Yuk buktikan →

🔺 2. Segitiga Emas Sistem Komputer

Komputer hanya berfungsi sempurna jika ketiga unsur ini ada secara bersamaan:

💻
Hardware — Raga / Fisik
Semua komponen yang bisa disentuh: layar, chip, baterai, kamera, tombol power.
💿
Software — Pikiran / Logika
Program yang tidak bisa disentuh: Android/iOS, WhatsApp, game, aplikasi sekolah.
🧑‍💻
Brainware — Akal / Tujuan
Manusia yang mengoperasikan dan menentukan tujuan: kamu, guru, programmer, desainer.

📱 3. Analogi: Tubuh Manusia = Komputer!

💡 Bandingkan komputer dengan dirimu:

  • Hardware = Tubuhmu (tangan, mata, otak fisik, jantung)
  • Software = Pikiranmu (cara berpikir, pengetahuan, bahasa)
  • Brainware = Tujuan hidupmu (ingin jadi apa, mau ngapain)

➡️ Tubuh tanpa pikiran = robot mati. Pikiran tanpa tujuan = sia-sia. Ketiganya harus ada!

🌍 4. Berbagai Contoh Sistem Komputer

Perangkat Hardware Software
📱 HP Layar, chip, kamera Android, WhatsApp
💻 Laptop CPU, RAM, keyboard Windows 11, Word
🏧 ATM Layar, tombol, printer Sistem perbankan
📺 Smart TV Panel OLED, remote Android TV, YouTube

💬 Ingat: Tanpa salah satu dari tiga unsur ini, sistem komputer tidak akan berfungsi sempurna. Kita akan mempelajari masing-masing lebih dalam di materi berikutnya!

Materi 2: Perangkat Keras — 4 Pilar & Motherboard

📦 1. Empat Pilar Perangkat Keras

Semua perangkat keras komputer dikelompokkan ke dalam 4 fungsi utama:

⌨️ Masukan (Input)

Menerima data & perintah pengguna (Keyboard, Mouse, Layar Sentuh, Mikrofon, Kamera).

🧠 Pemroses (CPU)

Otak pemroses instruksi berkecepatan miliaran siklus/detik (GHz), dilindungi pendingin heatsink.

💾 Penyimpanan (Storage)

RAM (kerja cepat & sementara) serta SSD/HDD (penyimpan file data permanen).

🖥️ Keluaran (Output)

Menyajikan hasil pemrosesan informasi ke pengguna (Monitor, Speaker, Printer, Proyektor).

💡 Analogi HP: Layar Sentuh (Input) ➔ Chipset (CPU) ➔ RAM & Memori ➔ Layar AMOLED & Speaker (Output).

🔌 2. Motherboard: Tulang Punggung

Papan sirkuit utama tempat semua komponen terpasang dan saling bertukar data:

🔧 Soket CPU & Pendingin

Dudukan presisi prosesor dengan sistem pengunci khusus dan kipas pendingin (heatsink-fan).

💾 Slot RAM (DDR4 / DDR5)

Jalur transfer data memori cepat dengan lekukan pengaman (notch) agar tidak salah pasang.

⚡ Slot M.2 NVMe & PCIe x16 (GPU)

Jalur ekspansi kilat untuk SSD penyimpanan super cepat dan Kartu Grafis (GPU) pengolah visual game/video.

🧠 Kolaborasi CPU & GPU: CPU adalah otak utama serba bisa, sedangkan GPU adalah spesialis memproses ribuan piksel grafis game & video secara paralel.

Materi 3: Cara Kerja Komputer — Dari Tombol ke Layar

⚡ 1. Perjalanan Sebuah Huruf "A"

Saat kamu mengetik huruf "A" di keyboard, apa yang terjadi dalam seperseribu detik di dalam CPU?

📥 1. FETCH — Jemput Instruksi:

CU mengambil kode instruksi "tampilkan huruf A" dari RAM ke dalam CPU melalui bus data.

🔍 2. DECODE — Terjemahkan:

CU menguraikan kode biner menjadi sinyal: "petakan titik-titik pixel membentuk huruf A di koordinat tertentu."

⚡ 3. EXECUTE — Eksekusi ALU:

ALU menghitung posisi dan warna setiap piksel huruf A dalam hitungan nanodetik.

💾 4. STORE — Simpan & Tampilkan:

Hasil dikirim ke GPU → VRAM → Monitor. Huruf "A" muncul di layarmu! Siklus ini berulang miliaran kali per detik.

🧠 2. Tiga Komponen Inti CPU

🧮 ALU (Arithmetic Logic Unit):

Kalkulator internal: penjumlahan, pengurangan, dan logika biner (AND, OR, NOT).

🚦 CU (Control Unit):

Dirigen yang mengatur irama (Clock Speed ~3–5 GHz = 3–5 miliar siklus/detik!).

⚡ Register & Cache (L1/L2/L3):

Memori ultra-cepat di dalam chip. Hierarki: Register > Cache > RAM > SSD

🛠️ 3. Diagnostik Booting: POST BIOS

Saat tombol Power ditekan, BIOS/UEFI memeriksa hardware secara berurutan:
1. CPU ➜ 2. RAM (DRAM) ➜ 3. GPU (VGA) ➜ 4. SSD (BOOT)

🔔 Kode Beep: 1 beep pendek = normal. Beep panjang berulang = RAM bermasalah!
Jika semua lolos, OS dimuat dari SSD ke RAM → komputer siap dipakai.

Materi 4: Sistem Operasi — Jiwa yang Menyatukan Segalanya

⚙️ 1. Empat Peran Kunci Sistem Operasi (OS)

OS adalah jembatan penghubung utama antara Hardware, Aplikasi, dan Brainware:

🎛️ 1. Manajemen Proses (Multitasking)

Membagi giliran kerja CPU agar puluhan aplikasi bisa berjalan serentak tanpa saling mengganggu.

💾 2. Manajemen Memori (Virtual Memory)

Mengatur jatah RAM dan meminjam ruang SSD sebagai memori darurat saat RAM hampir penuh.

🖼️ 3. Antarmuka Pengguna (GUI vs CLI)

Menyediakan tampilan klik visual yang ramah (GUI) maupun baris teks perintah (CLI).

🔌 4. Pengendali Perangkat (Device Driver)

Penerjemah komunikasi antara OS dan perangkat keras tambahan (printer, GPU, kamera).

📱 OS Sehari-hari: Windows 11 (Laptop) · Android 14 (HP) · iOS (iPhone) · macOS (MacBook).

🔺 2. Harmoni Segitiga Emas dalam Aksi

Setiap aktivitas komputasi melibatkan ketiga unsur Segitiga Emas secara serentak:

🎵 Contoh Nyata: Memutar Lagu di HP
🧑‍💻 Brainware: Kamu memilih lagu favorit dan mengetuk tombol Play.
💿 Software (OS): Android membuka aplikasi, menjadwalkan CPU, & menyiapkan driver audio.
💻 Hardware: CPU mendekode file musik, lalu speaker bergetar menghasilkan gelombang suara!

🔬 Tips Task Manager: Tekan Ctrl+Shift+Esc di Windows untuk memantau pemakaian CPU & RAM, serta menutup paksa aplikasi yang macet.

💡 Intisari Akhir: Hardware adalah raga fisik, Software adalah akal & logika, dan Brainware adalah jiwa penentu tujuan. Ketiganya bersatu membentuk Sistem Komputer!

✅❌ Bagian B — Benar / Salah (5 Soal)
1. Saat komputer dimatikan tiba-tiba, seluruh data dan instruksi yang berada di dalam RAM akan hilang (volatil).
2. Motherboard berfungsi untuk memproses semua komputasi logika secara mandiri tanpa memerlukan CPU.
3. Sistem Operasi (seperti Windows, Linux, atau Android) bertugas mengatur alokasi memori kerja dan waktu prosesor bagi aplikasi yang aktif.
4. Media penyimpanan sekunder SSD memiliki kecepatan transfer data yang lebih tinggi dibandingkan memori kerja RAM.
5. Control Unit (CU) bertugas menjemput instruksi dari RAM dan mengoordinasikan eksekusi data di CPU.

⚡ 4. RAM vs SSD: Apa Bedanya?

Karakteristik RAM (Memori Kerja) SSD (Penyimpanan)
Sifat Data Volatile (Sementara) ⚡ Non-Volatile (Permanen) 🔒
Mati Listrik Data terhapus bersih ❌ Data tersimpan aman ✅
Kecepatan Sangat cepat (nanodetik) Cepat (mikrodetik)

⚙️ 5. Peran Kunci Sistem Operasi (OS)

🎛️Manajemen Proses: Penjadwalan CPU agar multitasking berjalan lancar
💾Manajemen Memori: Alokasi RAM & Virtual Memory darurat (paging)
🖼️Antarmuka (GUI/CLI): Visual interaktif pengguna vs terminal programmer
🔌Device Driver: Bahasa penghubung antara sistem operasi dan hardware
💭 Refleksi 2: Mengapa data di RAM hilang saat laptop dimatikan, sedangkan tugasmu di SSD tetap aman? Kaitkan dengan konsep volatile!
