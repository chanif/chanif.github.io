# Teknologi Informasi dan Komunikasi (TIK)

## Deskripsi
Modul yang membekali siswa dengan keterampilan praktis menggunakan perangkat lunak produktivitas dan tools digital untuk berkarya. TIK bukan hanya "belajar komputer", tetapi bagaimana memanfaatkan teknologi secara efektif dan kreatif.

## Capaian Pembelajaran (CP)
- Menggunakan perangkat lunak produktivitas (pengolah kata, spreadsheet, presentasi) secara efektif
- Mengelola dokumen digital dengan format dan struktur yang baik
- Membuat presentasi yang efektif dan menarik
- Memanfaatkan layanan cloud untuk kolaborasi
- Menggunakan tools desain grafis untuk membuat konten visual sederhana

## Daftar Sub-Materi

### 01. Perangkat Lunak Produktivitas
- **Tujuan Pembelajaran**: Siswa mengenal dan mampu menggunakan berbagai perangkat lunak produktivitas.
- **Materi Pokok**:
  - Kategori perangkat lunak: sistem operasi, utilitas, aplikasi
  - Suite office: Microsoft Office vs Google Workspace vs LibreOffice
  - Pengolah kata (Word/Docs): formatting, styles, table of contents
  - Spreadsheet (Excel/Sheets): formula dasar, tabel, sorting/filtering
  - Presentasi (PowerPoint/Slides): layout, transisi, animasi
  - Tools pendukung: PDF reader, browser, file manager
  - Memilih tools yang tepat untuk tugas yang tepat
- **Aktivitas**:
  - [ ] Plugged: Buat dokumen laporan terstruktur (judul, daftar isi, bab, footer)
  - [ ] Plugged: Buat spreadsheet sederhana untuk menghitung uang saku bulanan
  - [ ] Plugged: Eksplorasi 3 aplikasi produktivitas baru, buat review singkat
- **Evaluasi / Quiz**:
  - [ ] Quiz: Identifikasi fitur dan kegunaan perangkat lunak (10 soal)
  - [ ] Praktik: Buat dokumen formal dengan format yang benar

### 02. Pengolahan Dokumen Digital
- **Tujuan Pembelajaran**: Siswa mampu membuat, mengedit, dan mengelola dokumen digital secara profesional.
- **Materi Pokok**:
  - Tipe file dokumen: .docx, .pdf, .odt, .txt, .rtf
  - Formatting dokumen: heading, paragraph, indentasi, spacing
  - Fitur lanjutan: mail merge, track changes, comments
  - Manajemen file: penamaan file yang baik, struktur folder
  - Konversi antar format: Word → PDF, PDF → Word
  - Tips menulis dokumen digital yang rapi dan profesional
- **Aktivitas**:
  - [ ] Plugged: Buat surat resmi dengan format yang benar (kop surat, tanggal, lampiran)
  - [ ] Plugged: Latihan mail merge untuk membuat surat massal (undangan)
  - [ ] Plugged: Organisasi file: buat struktur folder untuk proyek sekolah
- **Evaluasi / Quiz**:
  - [ ] Praktik: Diberikan dokumen berantakan, rapikan formatnya
  - [ ] Quiz: Identifikasi format file dan kegunaannya (8 soal)

### 03. Presentasi Efektif
- **Tujuan Pembelajaran**: Siswa mampu membuat dan menyampaikan presentasi yang informatif, menarik, dan efektif.
- **Materi Pokok**:
  - Prinsip desain slide: kesederhanaan, kontras, konsistensi
  - Aturan 10-20-30 (Guy Kawasaki) dan prinsip slide minimalis
  - Tipografi: memilih font yang tepat, ukuran teks optimal
  - Penggunaan gambar, ikon, dan diagram (bukan clipart!)
  - Animasi dan transisi: kapan menggunakan, kapan menghindari
  - Teknik presentasi: kontak mata, gestur, suara
  - Tools presentasi alternatif: Canva, Prezi, Google Slides
- **Aktivitas**:
  - [ ] Plugged: "Slide Makeover" — diberikan slide yang buruk, perbaiki desainnya
  - [ ] Plugged: Buat presentasi 5 slide tentang hobi/passion dengan desain menarik
  - [ ] Unplugged: Latihan presentasi di depan kelas (3 menit per siswa)
- **Evaluasi / Quiz**:
  - [ ] Quiz: Identifikasi kesalahan desain presentasi (10 soal visual)
  - [ ] Proyek: Buat dan presentasikan topik bebas dengan slide berkualitas

### 04. Kolaborasi Cloud
- **Tujuan Pembelajaran**: Siswa mampu menggunakan layanan cloud untuk menyimpan, berbagi, dan berkolaborasi secara real-time.
- **Materi Pokok**:
  - Apa itu cloud computing? Analogi: listrik dari PLN vs generator sendiri
  - Layanan cloud populer: Google Drive, OneDrive, Dropbox
  - Google Workspace for Education:
    - Google Docs: kolaborasi dokumen real-time
    - Google Sheets: kolaborasi spreadsheet
    - Google Slides: kolaborasi presentasi
    - Google Forms: membuat survei dan kuis
  - Berbagi file: link sharing, permission (view/edit/comment)
  - Version history: melihat dan mengembalikan versi sebelumnya
  - Tips keamanan cloud: password kuat, 2FA, jangan share link sembarangan
- **Aktivitas**:
  - [ ] Plugged: Kolaborasi real-time — seluruh kelas mengedit 1 dokumen Google Docs bersamaan
  - [ ] Plugged: Buat survei kelas menggunakan Google Forms, kumpulkan dan analisis hasilnya
  - [ ] Plugged: Upload tugas ke Google Drive dengan struktur folder rapi
- **Evaluasi / Quiz**:
  - [ ] Quiz: Konsep cloud computing dan fitur kolaborasi (8 soal)
  - [ ] Praktik: Buat folder bersama kelas di Google Drive, isi dengan dokumen kolaboratif

### 05. Desain Grafis Dasar
- **Tujuan Pembelajaran**: Siswa mampu membuat konten visual sederhana menggunakan tools desain grafis.
- **Materi Pokok**:
  - Prinsip dasar desain: proximity, alignment, repetition, contrast (PARC)
  - Teori warna: roda warna, harmoni warna, psikologi warna
  - Tipografi dalam desain: serif vs sans-serif, hierarki visual
  - Tools desain gratis:
    - Canva: membuat poster, infografis, social media post
    - Figma (gratis): desain UI sederhana
    - GIMP: editing foto dasar
  - Format file gambar: JPG, PNG, SVG, GIF — kapan menggunakan yang mana
  - Resolusi dan ukuran gambar: DPI, pixel, rasio aspek
- **Aktivitas**:
  - [ ] Plugged: Buat poster acara sekolah menggunakan Canva
  - [ ] Plugged: Buat infografis "Fakta Menarik tentang [Topik]" 
  - [ ] Plugged: Edit foto sederhana: crop, resize, tambah teks
- **Evaluasi / Quiz**:
  - [ ] Quiz: Prinsip desain dan identifikasi kesalahan desain (10 soal)
  - [ ] Proyek: Buat 3 desain berbeda (poster, infografis, social media post)
- **Game Interaktif**:
  - [ ] Color picker challenge: Padankan warna yang harmonis
  - [ ] Spot the design error: Temukan kesalahan desain dalam gambar
