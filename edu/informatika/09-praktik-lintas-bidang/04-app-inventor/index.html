Membuat Aplikasi Android dengan MIT App Inventor

Tidak perlu pusing menghafal ribuan baris sintaks Java atau Kotlin! Dengan platform visual MIT App Inventor, kamu dapat merancang tampilan aplikasi ponsel, memprogram kecerdasan sensor guncangan, suara Text-to-Speech, hingga database lokal, lalu mengekspornya menjadi berkas APK nyata!

⏱️ Waktu: 45 Menit 🤖 Platform: MIT App Inventor 2 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Memahami Arsitektur MIT App Inventor

Mengenali lingkungan kerja berbasis web dari MIT untuk mengembangkan aplikasi mobile Android dengan pemrograman blok visual.

02.
Menguasai Designer View & Blocks Editor

Menata komponen antarmuka di Palette/Viewer dan menyusun logika blok penanganan kejadian (Event-Driven Programming).

03.
Memanfaatkan Sensor & Basis Data Lokal

Mengintegrasikan sensor Accelerometer, pemroses suara TextToSpeech, serta komponen penyimpanan data permanen TinyDB.

04.
Menguji Live & Mengompilasi Berkas APK

Menghubungkan proyek ke smartphone melalui AI Companion serta mengekspor berkas paket .apk untuk instalasi langsung.

📱

1. Dua Ruang Kerja Utama: Designer & Blocks Editor

Pemisahan antara perancangan tampilan visual (UI) dan logika perilaku aplikasi (Logic)

🎨

A. Designer View (Tampilan Antarmuka)

Tempat menyusun tata letak visual aplikasi dengan cara menyeret komponen (drag & drop):

1. Palette: Gudang komponen (Button, TextBox, Label, Image, Slider, Layout, Media, Sensors).
2. Viewer: Layar mock smartphone tiruan tempat melihat letak komponen saat aplikasi berjalan.
3. Properties: Panel pengatur properti detail (warna latar, ukuran font, lebar/tinggi, teks tombol).
🧩

B. Blocks Editor (Logika Pemrograman)

Tempat memberikan nyawa pada aplikasi menggunakan blok warna-warni yang saling mengunci:

1. Event Blocks (Kuning Emas): Pemicu aksi, misalnya: when Button1.Click do (Saat tombol diklik).
2. Method / Call Blocks (Ungu): Perintah aksi, misalnya: call Sound1.Play atau call TextToSpeech1.Speak.
3. Setter & Getter (Hijau): Mengambil atau mengubah isi teks/warna: set Label1.Text to "Halo!".
🧭

2. Menjelajahi Sensor Pintar & Database Lokal TinyDB

Kekuatan unik aplikasi mobile dibandingkan website desktop biasa

📳

AccelerometerSensor

Mendeteksi percepatan dan guncangan fisik gawai. Sangat populer untuk membuat game dadu kocok dengan event when AccelerometerSensor1.Shaking do.

🗣️

TextToSpeech & Mic

Mengubah kalimat teks menjadi suara artikulasi manusia asli dalam bahasa Indonesia. Cocok untuk aplikasi penerjemah pintar atau kamus berbicara bagi tunanetra.

💾

TinyDB (Penyimpanan Lokal)

Database lokal berbentuk pasangan Tag dan Value (contoh Tag: "SkorTertinggi", Value: 100). Data tetap tersimpan abadi di memori HP meski aplikasi telah ditutup.

Unduh aplikasi MIT AI2 Companion gratis dari Google Play Store di ponselmu, pilih menu Connect → AI Companion di laptop, lalu scan QR Code!

Evaluasi Formatif: MIT App Inventor

Total 20 Soal (Skor Maksimal 100 poin) · Syarat Tuntas KKM: 70

20 Soal · 4 Bagian
Bagian A: Pilihan Ganda Konseptual 8 Soal · 40 Poin

1. MIT App Inventor adalah platform pemrograman visual yang ditujukan untuk membuat aplikasi sistem operasi...

2. Bagian ruang kerja di MIT App Inventor yang digunakan untuk merancang tata letak tombol, teks, dan gambar adalah...

3. Jenis blok berwarna kuning emas yang memulai sebuah alur program saat terjadi sentuhan pengguna (misal: when Button1.Click) adalah blok...

4. Komponen sensor yang dapat mendeteksi guncangan atau goyangan fisik gawai smartphone adalah...

5. Komponen yang digunakan untuk menyimpan data secara permanen di memori lokal smartphone sehingga tidak hilang saat aplikasi ditutup adalah...

6. Format ekstensi berkas paket instalasi aplikasi yang dihasilkan oleh App Inventor untuk dipasang di smartphone Android adalah...

7. Aplikasi pendamping di smartphone Android yang digunakan untuk mencoba jalannya proyek secara langsung melalui pindai QR Code bernama...

8. Komponen yang bertugas mengeluarkan bunyi suara ucapan manusia berdasarkan teks yang diberikan adalah...

Bagian B: Analisis Pernyataan (Benar / Salah) 4 Soal · 20 Poin

9. Untuk membuat aplikasi di MIT App Inventor, siswa wajib menguasai sintaks bahasa pemrograman teks tingkat tinggi seperti C++.

10. Komponen non-visible seperti Accelerometer dan TinyDB tidak akan tampak di layar aplikasi saat dijalankan pengguna.

11. TinyDB menyimpan data secara online di cloud server internet, sehingga membutuhkan kuota data aktif untuk membaca nilai.

12. Berkas APK yang telah selesai diekspor dari App Inventor dapat dibagikan dan dipasang langsung pada smartphone teman sekelas.

Rangkuman Materi & Refleksi Belajar

Tuliskan pemahaman dan pengalaman belajarmu pada materi ini

1. Dari Konsumen Menjadi Pencipta: Dengan App Inventor, setiap siswa SMP mampu bertransformasi dari sekadar pengguna game menjadi pembuat aplikasi Android yang fungsional.

3. Solusi Masalah Sekitar: Manfaatkan sensor smartphone untuk membuat aplikasi absensi kelas, kuis interaktif, maupun pengingat jadwal belajar harian.
