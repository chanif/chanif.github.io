Membuat Website Pertamamu dengan HTML5

Setiap situs web di internet — dari Google, Wikipedia, hingga platform sekolah ini — tersusun dari kerangka HTML. Kuasai bahasa pondasi web modern ini, pahami tag semantik, tata tabel, sematkan gambar, dan saksikan kreasimu langsung terbit di browser!

⏱️ Waktu: 45 Menit 🧱 Sintaks: Standar HTML5 W3C 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah menyelesaikan modul ini

01.
Memahami Peran HTML dalam Web

Mengenali HTML (HyperText Markup Language) sebagai struktur kerangka konten situs web yang dibaca oleh web browser.

02.
Menyusun Struktur Dokumen Standar

Menulis dokumen lengkap dengan deklarasi DOCTYPE, elemen html, head, title, meta viewport, dan pembungkus body.

03.
Menggunakan Tag Konten & Multimedia

Membuat heading hierarkis h1-h6, paragraf, penomoran list (ul/ol), hyperlink <a>, dan gambar <img> beratribut alt.

04.
Menerapkan Tag Semantik Modern

Menata halaman rapi ramah mesin pencari (SEO) menggunakan header, nav, main, section, article, aside, dan footer.

1. Konsep & Anatomi Elemen HTML

Mengenal susunan batu bata penyusun halaman situs web

🏠 Analogi Tiga Serangkai Teknologi Web Modern:

1. HTML (Kerangka Rumah)

Menentukan struktur pondasi, tiang, dinding kamar, dan letak pintu jendela (isi teks, gambar, tabel).

2. CSS (Dekorasi & Cat)

Memberikan warna dinding cat, jenis lantai keramik, tata letak furnitur, dan ukuran estetika jendela.

3. JavaScript (Kelistrikan)

Menyalakan lampu saat sakelar ditekan, pintu otomatis membuka, dan sistem keamanan pintar (interaktivitas dinamis).

Anatomi Tag HTML

<a href="https://sekolah.id" target="_blank">Kunjungi Sekolah</a>
  • <a> = Tag Pembuka (Opening tag).
  • href="..." = Atribut (informasi tambahan alamat tujuan link).
  • Kunjungi Sekolah = Konten yang tampil dan bisa diklik oleh user.
  • </a> = Tag Penutup (Closing tag) ditandai garis miring /.

Kerangka Dasar Dokumen Wajib

<!DOCTYPE html>
<html lang="id">
<head>
    <meta charset="UTF-8">
    <title>Halaman Pertamaku</title>
</head>
<body>
    <h1>Halo Dunia!</h1>
    <p>Saya siap belajar web.</p>
</body>
</html>

<head> menyimpan informasi tak kasat mata di tab (meta, title, style), sedangkan seluruh konten yang tampak di layar browser diletakkan di dalam <body>.

2. Tag Esensial & Elemen Semantik HTML5

Menyusun struktur konten yang bermakna bagi browser dan mesin telusur

<h1> s.d. <h6> Heading Hierarkis

Judul topik utama (h1), subjudul bab (h2), hingga sub-poin terkecil (h6). Halaman web yang baik hanya memiliki satu h1 sebagai judul pokok.

<p> & <strong> Paragraf & Penegasan

Tag <p> membungkus alinea teks dengan jarak spasi otomatis. Gunakan <strong> untuk tebal penting dan <em> untuk miring.

<ul>, <ol>, <li> Daftar Poin & Nomor

<ul> untuk poin bulat tak berurut (bullet list), <ol> untuk urutan nomor 1-2-3 (ordered list), dan <li> sebagai setiap butir daftarnya.

<img src="..." alt="..."> Penyematan Gambar

Tag tanpa penutup (self-closing). Atribut src berisi URL berkas gambar dan atribut alt wajib diisi deskripsi teks bagi tuna netra dan jika gambar gagal dimuat.

<table>, <tr>, <td> Tabel Data Grid

Menyajikan jadwal atau data nilai. <tr> adalah baris tabel (table row), <th> adalah sel judul kolom tebal, dan <td> adalah sel isi data (table data).

<form> & <input> Formulir Interaktif

Menerima masukan dari pengunjung web: input teks nama, password, radio button pilihan ganda, checkbox centang, dan tombol submit.

Mengapa Harus Menggunakan Tag Semantik HTML5?

Di era HTML lama, pengembang membungkus semua elemen dengan <div> yang tidak memiliki arti spesifik. HTML5 menghadirkan tag semantik yang memberi makna jelas bagi Googlebot dan pembaca layar (screen reader tuna netra):

<header>Kop / Kepala Web
<nav>Menu Navigasi
<main> & <article>Konten Inti Artikel
<footer>Hak Cipta / Kaki Web

Rangkuman Materi & Refleksi Belajar

Tuliskan pemahaman dan pengalaman belajarmu pada materi ini
