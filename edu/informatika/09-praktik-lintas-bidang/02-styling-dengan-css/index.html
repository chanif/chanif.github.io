Mempercantik Tampilan Web dengan CSS Modern

Bila HTML adalah kerangka bata, maka CSS adalah desainer interior yang menyulapnya menjadi hunian mewah penuh warna! Pelajari selektor CSS, rahasia jarak Box Model (Margin & Padding), tata letak Flexbox modern, dan animasi transisi dinamis.

Memahami Peran & Metode Penulisan CSS

1. Sintaks Dasar & Ragam Selektor CSS

Bagaimana browser menghubungkan instruksi gaya dengan elemen HTML

// Format Aturan CSS (CSS Rule):
h1 {
color: #4f46e5;
font-size: 28px;
text-align: center;
}
🎯 Selector: h1 (target) 🏷️ Property: color, font-size (sifat yang diubah) 💎 Value: #4f46e5, 28px (nilai perubahan)
Tag Selector

p { color: gray; }

Mengubah seluruh tag <p> di seluruh halaman tanpa terkecuali.

Class Selector (.)

.tombol-beli { background: green; }

Dapat diterapkan pada banyak elemen berbeda menggunakan atribut class="tombol-beli".

ID Selector (#)

#navigasi-utama { height: 60px; }

Bersifat unik, hanya boleh ada satu elemen yang memiliki id="navigasi-utama" di satu halaman.

📦

2. Konsep Kunci: CSS Box Model

Semua elemen di halaman web diperlakukan oleh browser sebagai sebuah kotak berlapis

MARGIN (Jarak luar pemisah antar kotak tetangga)
BORDER (Garis batas bingkai terluar elemen)
PADDING (Bantalan ruang kosong di dalam kotak)
CONTENT (Teks atau Gambar Inti)
1. Content

Ukuran lebar (width) dan tinggi (height) teks/gambar yang sebenarnya.

2. Padding

Jarak rongga udara antara konten dengan garis bingkai tepi.

3. Border

Ketebalan, warna, dan gaya garis bingkai (solid, dashed, dotted).

4. Margin

Jarak spasi transparan di luar bingkai yang memisahkan dari kotak lain.

📐

3. Menata Layout Fleksibel dengan CSS Flexbox

Teknik tata letak 1 dimensi modern untuk website responsif semua ukuran layar

Properti Utama Flex Container

Cukup tambahkan display: flex; pada elemen pembungkus (parent), maka anak-anaknya seketika berbaris rapi secara horisontal:

flex-direction: row | column; Menentukan arah barisan (ke samping atau menurun).
justify-content: center | space-between; Mengatur posisi anak elemen di sepanjang sumbu utama.
align-items: center; Meratakan posisi anak elemen secara vertikal di tengah.
gap: 16px; Memberi jarak spasi seragam antar anak elemen tanpa repot hitung margin.

Efek Hover & Transisi Animasi

Situs web interaktif memberikan umpan balik visual saat kursor mouse diarahkan ke tombol:

.btn {
background: #4f46e5;
transition: all 0.3s ease;
}
.btn:hover {
background: #4338ca;
transform: scale(1.05);
}

Atribut transition membuat perubahan warna dan ukuran membesar (scale) terjadi secara mulus dan memanjakan mata pengunjung.
