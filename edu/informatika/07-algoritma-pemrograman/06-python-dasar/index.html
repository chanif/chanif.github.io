Jembatan Bahasa: Blok Scratch vs Sintaks Python

Logika komputasinya 100% sama, hanya cara mengekspresikannya yang berubah menjadi teks!

Fungsi Logika Blok Visual Scratch Kode Teks Python Catatan Penting
Cetak Teks say [Halo Dunia!] print("Halo Dunia!") Teks wajib diapit tanda petik (" atau ')
Minta Masukan ask [Namamu?] and wait nama = input("Namamu? ") Hasil input() selalu bertipe string (teks)
Simpan Nilai set [skor] to (100) skor = 100 Tanda = adalah operator penugasan (*assignment*)
Percabangan if <skor > 75> then if skor > 75:
    print("Lulus")		 Wajib diakhiri tanda titik-dua (:) dan indentasi 4 spasi!
2

Operasi Input Dinamis & Formatted String (F-String)

Cara elegan menggabungkan teks dengan nilai variabel dalam satu kalimat rapi

Konversi Tipe Data (Type Casting)

Fungsi input() selalu menghasilkan teks. Jika kamu ingin menggunakannya untuk operasi matematika penjumlahan, kamu wajib membungkusnya dengan int()!

# Mengambil angka bulat:
panjang = int(input("Masukkan panjang: "))
lebar = int(input("Masukkan lebar: "))
luas = panjang * lebar
Kekuatan F-String (Formatted String)

Cukup tambahkan huruf f sebelum tanda petik, lalu masukkan nama variabel di dalam kurung kurawal {variabel}!

nama = "Fanani"
skor = 95
print(f"Hebat, {nama}! Nilai ujianmu adalah {skor}.")
# Output: Hebat, Fanani! Nilai ujianmu adalah 95.

Struktur Data Python: List & Dictionary

Menyimpan banyak data sekaligus dalam satu wadah variabel cerdas

📋 List [Kurung Siku] Indeks Mulai dari 0

Kumpulan item berurutan yang dapat diubah nilainya (*mutable*).

buah = ["Apel", "Jeruk", "Mangga"]
print(buah[0])  # Output: "Apel" (Elemen ke-1)
buah.append("Pisang")  # Menambah item baru
print(len(buah))  # Output: 4 (Banyak elemen)
📖 Dictionary {Kurung Kurawal} Pasangan Kunci : Nilai

Menyimpan data terstruktur layaknya buku profil atau kartu tanda pelajar.

siswa = {
    "nama": "Ahmad Budi",
    "kelas": 8,
    "nilai_it": 90
}
print(siswa["nama"])  # Output: "Ahmad Budi"

Menjadi Detektif Bug: Mengenal 4 Jenis Galat Umum

Jangan panik saat melihat teks merah di terminal! Pesan error adalah sahabat yang memberitahu lokasi kesalahan

SyntaxError

Ada kesalahan tata bahasa: lupa tanda kurung tutup ), tanda petik tidak sepasang, atau lupa tanda titik-dua :.

NameError

Memanggil nama variabel atau fungsi yang salah ketik (typo) atau belum pernah dibuat sebelumnya.

TypeError

Mencampur operasi tipe data yang tidak cocok, misal menjumlahkan teks string dengan angka int: "5" + 10.

IndexError

Mencoba mengakses nomor indeks yang berada di luar kapasitas panjang List (misal List ada 3 item, tapi minta item ke-10).
