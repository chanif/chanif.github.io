Pondasi Logika Pemrograman: Algoritma, Flowchart & Pseudocode

Sebelum seorang programmer mengetik baris kode di komputer, ia harus merancang alur logika solusinya terlebih dahulu. Tanpa algoritma yang matang, aplikasi secanggih apa pun akan penuh dengan bug dan kebocoran logika. Mari pelajari standar simbol diagram alir internasional dan teknik penelusuran (*dry run*)!

⏱️ Waktu: 45 Menit 📐 Diagram: Standar Simbol ISO 📝 Evaluasi: 20 Soal (4 Bagian)
🎯

Tujuan Pembelajaran

Kompetensi yang akan kamu kuasai setelah mempelajari modul ini

01.
Memahami Hakikat & 5 Sifat Algoritma

Menjelaskan syarat algoritma menurut Donald Knuth: keterbatasan langkah (*finiteness*), kepastian (*definiteness*), masukan, keluaran, dan efektivitas.

02.
Menulis Notasi Pseudocode Terstruktur

Menyusun instruksi menggunakan kata kunci universal (INPUT, OUTPUT, IF-THEN-ELSE, WHILE) dengan indentasi spasi yang rapi.

03.
Menguasai Simbol Standar ISO Flowchart

Menggambar diagram alir dengan bentuk terminal, proses aritmatika, belah ketupat keputusan, dan jajaran genjang I/O.

04.
Melakukan Uji Coba Kertas (Dry Run)

Menelusuri tabel pelacakan (*trace table*) nilai variabel langkah-demi-langkah untuk membuktikan kebenaran logika algoritma.

1

Apa Itu Algoritma? Asal-Usul & 5 Sifat Wajib

Berasal dari nama ilmuwan muslim legendaris: Muhammad ibn Musa al-Khwarizmi

Algoritma adalah urutan instruksi logis, terstruktur, dan terbatas yang disusun secara bertahap untuk menyelesaikan suatu masalah komputasi atau mencapai tujuan tertentu. Menurut ilmuwan komputer legendaris Donald Knuth, sebuah algoritma yang valid harus memenuhi 5 kriteria utama:

1. Finiteness Ada Titik Berhenti

Algoritma harus berakhir setelah sejumlah langkah terhingga, tidak boleh berputar selamanya (*infinite loop*).

2. Definiteness Tidak Ambigu

Setiap instruksi harus bermakna tunggal dan jelas, tidak boleh bermakna ganda (ambigu).

3. Input Ada Masukan

Menerima nol atau lebih data dari pengguna atau sensor untuk diproses.

4. Output Ada Keluaran

Harus menghasilkan minimal satu solusi hasil nyata (teks, angka, aksi).

5. Effectiveness Langkah Wajar

Setiap instruksi harus cukup sederhana sehingga dapat dieksekusi oleh mesin atau manusia.

2

3 Bentuk Penyajian Algoritma: Bahasa Alami, Pseudocode & Flowchart

Membandingkan satu studi kasus yang sama dalam 3 bentuk bahasa yang berbeda

Bentuk 1: Deskriptif (Bahasa Alami)

Ditulis menggunakan bahasa manusia sehari-hari (Bahasa Indonesia) berupa langkah-langkah bernomor.

1. Minta siswa memasukkan nilai ujian.
2. Periksa apakah nilai ≥ 75.
3. Jika ya, cetak "LULUS".
4. Jika tidak, cetak "REMIDI".
5. Selesai.
Bentuk 2: Pseudocode (Kode Semu)

Menyerupai struktur bahasa pemrograman resmi tanpa terikat aturan sintaks ketat. Memakai indentasi.

START
  INPUT nilai
  IF nilai >= 75 THEN
    OUTPUT "LULUS"
  ELSE
    OUTPUT "REMIDI"
  ENDIF
END
Bentuk 3: Flowchart (Diagram Alir)

Penyajian visual grafis menggunakan simbol geometris baku yang dihubungkan garis panah arah aliran data.

Mulai (Oval)
↓
Input Nilai (Jajaran Genjang)
↓
Nilai ≥ 75? (Belah Ketupat)
↓
Selesai (Oval)
3

Kamus Simbol Standar ISO Flowchart

Masing-masing bentuk geometris memiliki makna fungsi yang tidak boleh tertukar

Terminal
Terminator (Oval)

Menandai awal program (Mulai/Start) atau akhir alur (Selesai/Stop).

Input / Output
Input / Output (Jajaran Genjang)

Operasi membaca data masukan dari keyboard atau menampilkan keluaran ke layar monitor.

Proses
Process (Persegi Panjang)

Langkah kalkulasi matematika, pengisian nilai variabel (assignment), atau manipulasi data.

Decision?
Decision (Belah Ketupat)

Titik percabangan logika dengan dua jalur keluaran: Ya (True) atau Tidak (False).

Teknik Dry Run: Melacak Variabel di Atas Kertas

Cara menguji algoritma tanpa komputer untuk memastikan tidak ada kesalahan logika

Dry Run (atau Desk Checking) adalah metode manual di mana kita berperan sebagai komputer, mengeksekusi instruksi demi instruksi menggunakan pensil dan tabel pelacakan (*Trace Table*).

Contoh Kasus: Menghitung Jumlah Angka 1 sampai 3
Baris InstruksiVariabel 'i'Variabel 'total'Kondisi (i ≤ 3)Aksi / Catatan
Inisialisasi10-Mulai dari i=1, total=0
Iterasi 111 (0+1)TRUEtotal = 0 + 1
Iterasi 223 (1+2)TRUEtotal = 1 + 2
Iterasi 336 (3+3)TRUEtotal = 3 + 3

Rangkuman Kunci & Refleksi Belajar

  • Algoritma adalah peta jalan instruksi terstruktur untuk memecahkan persoalan komputasi.
  • 5 kriteria Knuth: Finiteness (ada batas akhir), Definiteness (jelas/pasti), Input, Output, dan Effectiveness.
  • Bisa disajikan dalam 3 cara: Deskriptif (bahasa alami), Pseudocode (kode semu), dan Flowchart (diagram alir grafis ISO).
  • Simbol utama flowchart: Oval (Terminator), Persegi Panjang (Proses), Jajaran Genjang (I/O), dan Belah Ketupat (Keputusan).
  • Gunakan teknik Dry Run untuk melacak variabel sebelum menulis kode di komputer.
