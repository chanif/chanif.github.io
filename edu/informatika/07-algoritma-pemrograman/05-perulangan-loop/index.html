1

For Loop & Rahasia Parameter Fungsi range()

Struktur perulangan pasti (*counted loop*) saat jumlah putaran sudah diketahui sebelumnya

Dalam Python, for loop selalu berpasangan dengan fungsi range() untuk menghasilkan deretan angka berurutan. Ingat aturan kunci: angka akhir (stop) bersifat eksklusif (tidak diikutsertakan)!

1. range(stop)

Mulai dari 0 hingga stop-1.

for i in range(5):
    print(i)
# Output: 0, 1, 2, 3, 4
2. range(start, stop)

Mulai dari nilai awal spesifik.

for i in range(1, 6):
    print(i)
# Output: 1, 2, 3, 4, 5
3. range(start, stop, step)

Dengan lompatan langkah tertentu.

for i in range(2, 11, 2):
    print(i)
# Output Genap: 2, 4, 6, 8, 10
2

While Loop: Perulangan Berbasis Kondisi & Bahaya Infinite Loop

Berputar selama kondisi bernilai Benar (*True*) dan berhenti seketika saat Salah (*False*)

Struktur While Loop yang Benar

Wajib memiliki 3 elemen: (1) Inisialisasi awal, (2) Syarat kondisi, dan (3) Pembaruan counter penambah.

nyawa = 3
while nyawa > 0:
    print(f"Bermain game! Sisa nyawa: {nyawa}")
    nyawa -= 1  # Wajib ada agar tidak macet!
print("Game Over!")
⚠️ Bahaya Infinite Loop (Macet Permanen)

Jika kamu lupa menuliskan baris penambah nilai counter (i += 1), maka nilai kondisi akan selalu True selamanya. Program akan macet, browser membeku, dan CPU komputer bekerja 100%!

i = 1
while i <= 5:
    print(i) # Nilai i tetap 1 selamanya! MACET!
3

Perintah Pengendali: break vs continue

Dua tombol darurat untuk memotong atau melompati jalannya siklus perulangan

1. Perintah break (Berhenti Total)

Menghentikan dan keluar dari loop secara paksa saat itu juga, tanpa menyelesaikan putaran yang tersisa.

for i in range(1, 10):
    if i == 5:
        break # Langsung keluar saat i=5
    print(i)
# Output hanya: 1, 2, 3, 4
2. Perintah continue (Lewati Putaran Ini)

Hanya melewati instruksi di bawahnya pada putaran saat ini, lalu langsung melompat ke putaran berikutnya.

for i in range(1, 6):
    if i == 3:
        continue # Lewati angka 3
    print(i)
# Output: 1, 2, 4, 5 (angka 3 hilang)

Rangkuman Kunci & Refleksi Belajar

  • Looping mengotomasi pengeksekusian kode berulang kali sehingga program lebih hemat baris dan efisien.
  • Gunakan for i in range(stop) untuk putaran pasti; angka stop tidak diikutsertakan (eksklusif).
  • Gunakan while kondisi: untuk putaran yang bergantung pada syarat logika; pastikan selalu ada kenaikan counter.
  • Gunakan break untuk menghentikan loop seketika dan continue untuk melewati satu putaran.
