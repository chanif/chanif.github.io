Kamus Ringan untuk Bapak/Ibu Guru

Istilah teknologi yang sering terdengar rumit, sebenarnya sangat sederhana:

🤖 Antigravity AI

Aplikasi di laptop kita tempat mengobrol dengan asisten AI yang bertugas menuliskan seluruh kode program secara otomatis.

💬 Prompt

Kalimat perintah dalam bahasa Indonesia biasa yang kita ketikkan untuk meminta AI membuatkan halaman web atau kuis.

📁 GitHub (Repo)

"Brankas online" di internet untuk mencadangkan file website kita agar aman dan tidak hilang jika laptop rusak.

⚡ Cloudflare Pages

Penyedia server gratis nomor 1 di dunia yang menyulap file kita menjadi alamat web resmi (`.pages.dev`) yang bisa dibuka murid di HP.

🎁 3 Hasil Karya yang Dibawa Pulang Bapak/Ibu Guru

1

Web Portofolio Guru

Halaman pembuka (`index.html`) yang menampilkan foto guru, sambutan hangat, mata pelajaran yang diampu, riwayat prestasi, dan kartu menuju media ajar.

Media Pembelajaran 1: BK

Halaman materi Berpikir Komputasional (`materi-bk.html`) lengkap dengan analogi 4 pilar, simulasi interaktif seru, dan kuis pilihan ganda dengan skor otomatis.

Halaman materi Pemanfaatan AI atau Sistem Komputer (`materi-ai.html`) dengan visualisasi menarik, panduan prompting etis siswa, serta uji pemahaman.

Panduan Praktik Bertahap

Langkah demi Langkah Praktik Pembuatan Web

Ikuti langkah-langkah mudah di bawah ini satu per satu. Jangan ragu bertanya kepada fasilitator jika menemui kendala.

1

Tahap 1: Siapkan Folder di Laptop & Foto Guru

Fondasi awal yang rapi sebelum memanggil AI

1. Buka File Explorer di laptop Bapak/Ibu (misal di drive D: atau di Desktop).

2. Buat satu folder baru dengan nama singkat tanpa spasi, misalnya: portofolio-guru.

3. Masukkan 2 file gambar ke dalam folder tersebut:

  • foto.jpg : Foto profil Bapak/Ibu Guru yang rapi dan ramah.
  • logo.png : Logo sekolah masing-masing atau logo Tut Wuri Handayani.
💡 Tips: Menggunakan nama file huruf kecil sederhana seperti foto.jpg memudahkan AI mengenali gambar tanpa salah ketik!
2

Tahap 2: Buka Antigravity AI & Arahkan ke Folder

Membuka lembar kerja editor pintar

1. Buka aplikasi Antigravity IDE di laptop Bapak/Ibu.

2. Klik menu File ➔ Open Folder... (atau pintasan tombol Ctrl + K, Ctrl + O).

3. Pilih folder portofolio-guru yang telah kita buat pada Tahap 1.

4. Buka jendela obrolan AI (Chat Assistant) yang ada di sisi samping layar. Sekarang asisten AI siap menerima perintah kita!

3

Tahap 3: Perintah Sakti (Prompt) ke Antigravity AI

Salin prompt di bawah ini lalu kirimkan ke chat AI

Bapak/Ibu cukup menyalin (*copy*) prompt di bawah ini. Ubah teks di dalam kurung siku [...] sesuai nama dan sekolah Bapak/Ibu, lalu tekan Enter di Antigravity!

📌 Prompt 1: Halaman Depan Portofolio (`index.html`)
Halo Antigravity AI! Tolong buatkan saya satu file halaman depan website portofolio guru yang sangat indah, modern, dan ramah siswa dengan nama file: "index.html". Spesifikasi konten: 1. Identitas Guru: - Nama Guru: [Ach. Chanifuddin Fanani, S.Pd.] - Guru Mata Pelajaran: [Informatika & Koding/AI (KKA)] - Nama Sekolah: [SMP Negeri 2 Lamongan] - Pasang foto profil dari file lokal: "foto.jpg" (buat bentuk bulat elegan dengan border warna cerah). - Pasang logo sekolah dari file lokal: "logo.png" di bagian header navigasi. 2. Desain & Tampilan: - Gunakan Tailwind CSS (via CDN) dan Google Fonts Quicksand + Inter. - Pilihan warna: Latar belakang bersih lembut (#F8FAFC) dengan aksen Indigo & Teal. - Tuliskan pesan sambutan yang memotivasi siswa untuk giat belajar di era digital. 3. Menu & Kartu Akses Media Ajar: - Tampilkan 2 buah kartu pilihan media pembelajaran interaktif yang mencolok: * Kartu 1: "Media Pembelajaran 1: Berpikir Komputasional (BK)" yang memiliki tombol menuju "materi-bk.html". * Kartu 2: "Media Pembelajaran 2: Pemanfaatan Kecerdasan Artifisial (AI)" yang memiliki tombol menuju "materi-ai.html". 4. Bagian Kontak & Footer: - Tambahkan tombol kirim pesan WhatsApp dan tautan email guru. - Cantumkan hak cipta tahun 2026 nama guru dan sekolah. Buatkan kode HTML lengkap siap pakai langsung disimpan ke file index.html!
📌 Prompt 2: Media Belajar 1 — Berpikir Komputasional (`materi-bk.html`)
Halo Antigravity AI! Sekarang tolong buatkan file media pembelajaran pertama dengan nama: "materi-bk.html". Halaman ini harus memiliki navigasi atas dengan tombol "← Kembali ke Portofolio Guru" yang mengarah ke "index.html". Spesifikasi materi & fitur interaktif: 1. Judul Materi: "Petualangan Berpikir Komputasional (BK) — 4 Pilar Memecahkan Masalah". 2. Bagian Konsep: - Jelaskan 4 Pilar BK dengan bahasa yang sangat seru dan contoh nyata kehidupan sehari-hari (Dekomposisi, Pengenalan Pola, Abstraksi, dan Perancangan Algoritma). - Gunakan kotak kartu warna-warni yang menarik untuk masing-masing pilar. 3. Bagian Simulasi Interaktif: - Buatkan simulasi mini interaktif sederhana berbasis JavaScript (misal: simulasi memilih langkah algoritma membuat sarapan atau simulasi deteksi pola angka). 4. Bagian Kuis Evaluasi Mandiri: - Sediakan 5 soal kuis pilihan ganda yang seru. - Siswa bisa memilih jawaban (A, B, C, D). - Terdapat tombol "Periksa Nilai Saya": begitu diklik, otomatis menghitung skor (0 - 100), memberikan bintang (⭐), dan memunculkan animasi pujian (misal: "Luar Biasa!" jika nilai 100). 5. Desain: - Konsisten dengan tema index.html (Tailwind CSS, Quicksand, mobile-friendly nyaman dibuka di HP). Buatkan kode HTML lengkap dan tuliskan langsung ke file materi-bk.html!
📌 Prompt 3: Media Belajar 2 — Pemanfaatan AI (`materi-ai.html`)
Halo Antigravity AI! Terakhir, tolong buatkan file media pembelajaran kedua dengan nama: "materi-ai.html". Halaman ini juga memiliki tombol navigasi "← Kembali ke Portofolio Guru" menuju "index.html". Spesifikasi materi & fitur: 1. Judul Materi: "Mengenal Kecerdasan Artifisial (AI) & Etika Penggunaannya". 2. Bagian Materi Edukatif: - Apa itu AI dan bagaimana AI membantu manusia dalam kehidupan sehari-hari. - Cara membuat prompt yang baik untuk belajar (*Prompt Engineering sederhana untuk siswa*). - 3 Etika Penting: Kejujuran akademik, tidak menyebarkan hoax/deepfake, dan perlindungan privasi data pribadi. 3. Studio Latihan Prompt Interaktif: - Sediakan area latihan di mana siswa bisa memilih template prompt belajar, lalu menekan tombol "Uji Prompt" untuk melihat contoh tanggapan cerdas AI. 4. Kuis Tantangan Detektif AI: - 5 pertanyaan tebak kasus (Benar atau Salah / Pilihan Ganda) mengenai mana perilaku beretika dan mana yang melanggar aturan saat memakai AI. - Skor otomatis dihitung dengan tombol "Cek Hasil Evaluasi". 5. Desain: - Estetik nuansa ungu-cyan modern, responsif, dan rapi. Buatkan kode HTML lengkap dan simpan ke file materi-ai.html!
4

Tahap 4: Uji Coba Langsung di Laptop (Offline Testing)

Melihat hasil karya di browser sebelum diunggah ke internet

1. Buka kembali folder portofolio-guru di laptop Bapak/Ibu.

2. Pastikan sekarang sudah ada 5 file di dalamnya:

├── foto.jpg
├── logo.png
├── index.html
├── materi-bk.html
└── materi-ai.html

3. Klik 2 kali pada file index.html. Halaman portofolio Bapak/Ibu akan langsung terbuka di Google Chrome / browser laptop!

4. Cobalah klik tombol menuju Materi 1 dan Materi 2, kerjakan kuisnya, dan klik tombol kembali. Jika ada teks yang ingin diganti (misal ada gelar atau nomor kontak yang keliru), cukup minta Antigravity AI memperbaikinya!

5

Tahap 5: Simpan File ke GitHub (Brankas Online)

Mencadangkan file agar siap dihubungkan ke Cloudflare

1. Buka situs github.com dan masuk menggunakan akun masing-masing (atau daftar gratis jika belum punya).

2. Klik tombol hijau "New" (atau ikon + di pojok kanan atas ➔ New repository).

3. Beri nama gudang/repository Bapak/Ibu, contoh: portofolio-guru. Pastikan pilih status Public, lalu klik tombol hijau "Create repository".

4. Di halaman baru yang muncul, klik tulisan tautan kecil: "uploading an existing file".

5. Buka folder laptop Bapak/Ibu, pilih dan seret (drag & drop) kelima file (foto.jpg, logo.png, index.html, materi-bk.html, materi-ai.html) ke kotak unggah di GitHub.

6. Klik tombol hijau "Commit changes" di bagian bawah. Selamat! File karya Bapak/Ibu sekarang sudah tersimpan aman di awan!

6

Tahap 6: Terbitkan Website dengan Cloudflare Pages

Menjadikan website online aktif dan super cepat gratis selamanya

1. Buka situs dash.cloudflare.com dan buat akun gratis (hanya butuh email).

2. Pada menu panel sebelah kiri, klik Compute (Workers & Pages).

3. Klik tombol "Create application" di pojok kanan atas, lalu pilih tab "Pages".

4. Pilih opsi "Connect to Git" ➔ pilih akun GitHub Bapak/Ibu ➔ pilih repositori portofolio-guru yang tadi dibuat.

5. Klik tombol "Begin setup". Di bagian pengaturan build, biarkan semua pengaturan default kosong, lalu klik tombol "Save and Deploy".

🎉 Hore! Website Bapak/Ibu Sudah Resmi Online!

Dalam 30 detik, Cloudflare akan memberikan alamat website resmi aktif, misalnya:
https://portofolio-guru-xyz.pages.dev

Alamat ini bisa langsung dibagikan lewat grup WhatsApp kelas dan dibuka oleh seluruh murid!

Materi Pengayaan

Langkah Lanjutan: Simpan Nilai Kuis Siswa dengan Cloudflare Worker & D1

Jika Bapak/Ibu ingin agar skor kuis yang dikerjakan murid di rumah **otomatis masuk ke rekap nilai guru**, kita bisa menambahkan fitur backend gratis dari Cloudflare:

⚡ Cloudflare Worker (`*.workers.dev`)

Bertindak sebagai kurir pintar penerima data nama murid dan skor evaluasi dari website.

🗄️ Database Cloudflare D1

Buku nilai digital otomatis berbasis SQL yang menyimpan rekap nilai siswa secara permanen dan aman.

*Materi pengayaan ini akan dibimbing langsung oleh instruktur di sesi akhir bagi guru yang ingin eksplorasi lebih dalam.

❓ Tanya Jawab Seputar Pembuatan Web Guru (FAQ)

Q: "Apakah saya harus bisa koding bahasa pemrograman dulu?"

Jawab: Sama sekali tidak! Zaman sekarang koding sudah dibantu AI. Tugas Bapak/Ibu adalah sebagai konseptor materi (menentukan topik pembelajaran, isi kuis, dan tampilan yang diinginkan). Penulisan kodenya 100% dikerjakan oleh Antigravity AI.

Q: "Apakah nanti ada tagihan biaya bulanan atau perpanjangan domain?"

Jawab: Nol rupiah (100% Gratis)! Baik akun GitHub maupun Cloudflare Pages menyediakan kuota gratis tanpa batas waktu (free tier permanen) yang sangat cukup untuk melayani ribuan murid sekolah setiap hari.

Q: "Bagaimana jika suatu hari materi pembelajarannya ingin saya tambah atau perbarui?"

Jawab: Sangat mudah! Cukup buka kembali Antigravity AI, minta AI menambah materi baru, lalu upload file terbaru ke GitHub. Cloudflare Pages akan otomatis mendeteksi dan memperbarui website Bapak/Ibu secara otomatis dalam hitungan detik (*auto-deploy*)!
