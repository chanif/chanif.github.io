Pengembangan Personal Website Pendidik & Media Pembelajaran Interaktif Terintegrasi Cloudflare Workers

Panduan terstruktur perancangan portal personal website pendidik yang memuat minimal 1 Media Pembelajaran Interaktif (MPI) terintegrasi: dikembangkan menggunakan Antigravity IDE (Standalone) mengacu pada berkas spesifikasi teknis, dipublikasikan pada infrastruktur komputasi awan Cloudflare Workers, serta terhubung langsung ke basis data relasional Cloudflare D1 SQL Database untuk pencatatan evaluasi siswa secara real-time.

📥 1. Unduh Antigravity IDE (Standalone) 📋 Buka specification.md ↗
📐 Landasan Konseptual

Tujuan Pengembangan & Arsitektur Ekosistem Cloudflare Workers

Pengenalan ekosistem komputasi awan nir-server (*serverless*) modern yang digunakan untuk merilis website portofolio serta mengelola transaksi data evaluasi siswa:

👨‍🏫

1. Personal Website Guru & Hub Multi-MPI

Luaran utama workshop ini adalah sebuah Personal Website resmi pendidik yang berfungsi sebagai representasi profesional guru di internet (profil, mata pelajaran yang diampu, dan visi pembelajaran) serta menjadi portal pusat yang memuat minimal 1 Media Pembelajaran Interaktif (MPI) yang dapat terus ditambah di masa mendatang (*scalable multi-MPI*).

🌐

2. Cloudflare Workers (Infrastruktur Hosting & Edge Network)

Cloudflare Workers merupakan platform komputasi awan terdistribusi global yang melayani hosting aset antarmuka web (*static assets*) dengan latensi rendah (< 30ms) dan enkripsi SSL/HTTPS otomatis. Guru tidak memerlukan biaya sewa server atau panel hosting konvensional; website dapat langsung aktif dan diakses dari seluruh dunia.

⚡

3. Cloudflare Workers Backend API

Menjalankan fungsi API nir-server (*serverless endpoint*) yang bertugas menerima data kiriman hasil evaluasi siswa (nama, kelas, skor, dan identitas media) melalui protokol HTTP POST, melakukan validasi struktur data, serta mengeksekusi kueri penulisan ke basis data relasional secara aman.

🗄️

4. Cloudflare D1 SQL Database & Penampil Data Visual

Layanan basis data relasional berbasis SQLite yang terintegrasi secara *native* di dalam Cloudflare. Dilengkapi penampil data visual bawaan di dashboard (antarmuka tab *Explore/Data* yang mirip fungsionalitas phpMyAdmin), memudahkan pendidik memantau rekap skor siswa secara terstruktur per materi.

🗄️ Inisialisasi Basis Data Cloudflare D1 & Skema Multi-MPI

Membangun basis data SQL serverless dengan struktur tabel yang dirancang fleksibel untuk mendukung banyak materi pembelajaran.

Setiap pendidik dapat menentukan nama database secara mandiri (misalnya: mgmp, db_sekolah, atau portofolio_guru). Skema tabel dirancang lengkap dengan kolom identitas media (media_id) agar basis data yang sama siap menampung hasil kuis dari materi-materi pembelajaran berikutnya tanpa perlu membuat tabel baru:

1
Buka portal Cloudflare pada peramban web di tautan dash.cloudflare.com dan masuk ke akun Anda.
2

Membuat Database D1 Baru:

Pada bilah menu kiri, pilih Storage & Databases ➔ klik D1 SQL Database ➔ klik tombol "Create database" ➔ tentukan nama database (misalnya: mgmp atau nama pilihan Anda) ➔ klik tombol Create.

3

Mengeksekusi Skema Tabel `nilai_evaluasi` (Siap Multi-MPI):

Buka database yang baru dibuat ➔ pilih tab Console (atau Query) ➔ salin dan jalankan kueri SQL penciptaan tabel berikut:

CREATE TABLE IF NOT EXISTS nilai_evaluasi ( id INTEGER PRIMARY KEY AUTOINCREMENT, media_id TEXT NOT NULL, judul_materi TEXT NOT NULL, nama_siswa TEXT NOT NULL, kelas TEXT NOT NULL, skor INTEGER NOT NULL, waktu DATETIME DEFAULT CURRENT_TIMESTAMP );
💡

Antarmuka Visual Terintegrasi: Pada tab Explore / Data, tabel nilai_evaluasi dapat dilihat langsung dalam bentuk baris dan kolom yang interaktif layaknya phpMyAdmin, memudahkan pengelompokan dan peninjauan nilai secara instan.

💬 Generasi Personal Website, Halaman Rekapitulasi, & Backend API via AI

Mengeksekusi instruksi langsung berbasis acuan berkas specification.md yang telah disiapkan untuk Cloudflare Workers.

Karena seluruh rincian kurikulum, desain antarmuka, dan integrasi API Cloudflare Workers telah terdefinisi di dalam dokumen specification.md, Anda cukup memberikan instruksi lugas ke panel AI Agent Antigravity IDE:

Perintah Tunggal di Panel AI Agent

Prompt yang Dikirimkan ke Antigravity IDE:

Buatkan personal website guru (index.html), modul media pembelajaran interaktif Berpikir Komputasional, halaman dashboard rekapitulasi nilai publik (rekap.html), dan backend API Cloudflare Workers (functions/api/evaluasi.js) sesuai panduan specification.md, foto-guru.jpg, dan logo-sekolah.png yang ada di folder ini.

* Tekan Enter pada panel AI Agent. Antigravity akan menyusun berkas frontend index.html, rekap.html, dan backend functions/api/evaluasi.js secara utuh di folder kerja Anda dalam waktu singkat.

OUTPUT BERKAS UTAMA YANG DIHASILKAN OLEH AI:
📄 index.html
  • ✓ Profil resmi guru & sekolah.
  • ✓ Modul 4 Pilar Berpikir Komputasional.
  • ✓ Mini-simulator logika interaktif.
  • ✓ Evaluasi 5 kuis skor 0–100.
  • ✓ Kirim nilai ke /api/evaluasi.
📊 rekap.html
  • ✓ Halaman publik tanpa login.
  • ✓ 3 Kartu KPI: Total, Rata-rata, Top.
  • ✓ Tabel data real-time asinkron.

  • ✓ Tombol "Refresh Data" instan.

  • ✓ Serverless Cloudflare Worker API.
  • ✓ POST: simpan nilai ke D1 (env.DB).

  • ✓ Mandiri di domain proyek guru.

Validasi Tampilan Lokal: Buka tab Integrated Browser Preview di Antigravity IDE (atau klik ganda berkas index.html dan rekap.html di File Explorer). Pastikan seluruh elemen interaktif, mini-simulator, formulir kuis, dan tabel rekapitulasi tampil proporsional sebelum diunggah ke internet.

4

🚀 Publikasi Aset Web ke Jaringan Cloudflare Workers

Mendistribusikan folder proyek ke edge network Cloudflare melalui metode Direct Upload tanpa perantara pihak ketiga.

Pengunggahan langsung (*Direct Upload*) memungkinkan direktori proyek lokal diunggah secara instan ke infrastruktur Cloudflare:

1
Pada dashboard Cloudflare, buka menu Workers & Pages di bilah navigasi kiri ➔ klik tombol "Create application".
2

Inisialisasi Proyek Direct Upload:

Pilih tab Pages ➔ klik opsi "Upload assets" ➔ tentukan nama proyek (contoh: guru-informatika-smpn2) ➔ klik tombol Create project.

3

Unggah Direktori Proyek:

Seret (*drag and drop*) folder kerja Web_Guru_Informatika dari Windows Explorer ke area upload pada browser. Sistem Cloudflare akan memvalidasi seluruh berkas secara otomatis.

4

Penyelesaian Deployment:

Klik tombol "Deploy site". Dalam hitungan beberapa detik, situs resmi Anda telah terbit secara daring dengan sertifikat SSL/HTTPS aktif:

https://guru-informatika-smpn2.pages.dev
5

Hubungkan Binding Basis Data D1 ke Pages Functions:

Agar backend Worker /api/evaluasi dapat membaca dan menulis data ke database D1 Anda, buka proyek Pages Anda di dashboard Cloudflare ➔ pilih menu Settings ➔ Functions ➔ D1 database bindings ➔ Add binding ➔ ketik Variable name: DB ➔ pilih D1 Database Anda (misalnya: mgmp) ➔ klik Save.

🎉
Personal Website & Media Belajar Interaktif Resmi Aktif Secara Daring!

Website Anda kini terhubung ke jaringan edge global Cloudflare dan siap diakses secara serentak oleh peserta didik di laboratorium komputer sekolah maupun perangkat seluler mandiri.

📊 Pengujian Alur Data & Pemantauan Rekap Nilai di D1 Dashboard

Memverifikasi masuknya transaksi data hasil kuis siswa ke tabel database melalui penampil visual bawaan.

Lakukan simulasi pengerjaan evaluasi untuk memverifikasi keterhubungan *end-to-end* antara antarmuka web, backend Worker API, dan penyimpanan basis data D1:

1
Buka tautan website Anda yang telah aktif di tab baru atau melalui peramban ponsel cerdas. Lengkapi formulir evaluasi siswa pada modul Berpikir Komputasional, jawab kuis, lalu klik tombol "Periksa & Kirim Nilai ke Database Guru".
2
Pemantauan via Dashboard Publik (rekap.html): Buka tautan https://[nama-proyek].pages.dev/rekap.html. Halaman ini bersifat publik tanpa perlu login—data nilai siswa yang baru saja dikirimkan langsung tampil pada tabel dan memperbarui ringkasan statistik (rata-rata dan nilai tertinggi) secara real-time.
3
Pemantauan via Cloudflare D1 Dashboard: Buka dashboard Cloudflare: akses menu Storage & Databases ➔ D1 SQL Database ➔ [nama database Anda] ➔ Tab Explore / Data untuk memeriksa tabel data mentah secara visual layaknya phpMyAdmin.
